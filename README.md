# OS Developer Field Guide

A field guide to open-source hardware in the wild. It covers microcontrollers, dev kits, single-board computers, AI boards, FPGA boards, robots, cameras, audio, wearables, and radios.

This repository holds the generated static site. It is an AI-assisted experiment by Jeremy Riel, PhD, UIC TRAILblazer Lab (https://www.trailblazerlab.org). Some content was written with generative AI and may contain errors. Prices are estimates and can change at any time. Price and availability vary by vendor.

Planned home: osdeveloper.org.
