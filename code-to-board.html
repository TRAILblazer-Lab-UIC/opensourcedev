How Code Gets onto a Board

Code is a list of instructions. You write it on your laptop. Then you send it to the board over a USB cable. The board keeps it and runs it every time it gets power. This sending step is called uploading or flashing.

The three common paths

PathHow it feelsGood first boards
BlocksSnap puzzle pieces together in a web pageBBC micro:bit, many robot kits
PythonType short, readable lines of codeRaspberry Pi Pico, CircuitPython boards
Arduino C++Type code in the Arduino app and press uploadArduino boards, ESP32 boards

Many boards support more than one path. Start with the easiest one. Move to the next one as you grow.

Your first upload, step by step

  1. Install a free coding app. Thonny, Mu, MakeCode, and the Arduino IDE are common choices.
  2. Plug the board into your laptop with a USB cable. Make sure the cable carries data. Some cheap cables only charge.
  3. Pick your board in the app's board menu.
  4. Open the "Blink" example. Blink is the "hello world" of hardware. It flashes a tiny light on the board.
  5. Press upload or run.
  6. Watch the light blink. You just programmed a computer chip.

A few handy words

  • An IDE is the app where you write and upload code.
  • Firmware is the main program stored on a board.
  • A library is ready-made code that someone shared. It saves you work.
  • A bootloader is a tiny helper program that accepts new code.
  • The serial monitor is a window that shows messages from your board.

Ready-made firmware

Some projects need no coding at all. You flash a finished program onto the board and set it up in a phone app. Meshtastic radios and many smart-home gadgets work this way. These are a great first step for people who do not code yet.

Single-board computers are different

A single-board computer runs a full operating system. You first copy that system onto a microSD card. The Raspberry Pi Imager app does this in a few clicks. Then the board starts up like a regular computer. You write code right on it, or you connect from your laptop.

Getting unstuck

Every tinkerer gets stuck. It is part of the hobby.

  • Try a different USB cable first. Bad cables cause most upload problems.
  • Check that the right board is picked in the app.
  • Read the red error text. Paste it into a search engine.
  • Ask in the board's forum. Open-source communities like to help newcomers.
