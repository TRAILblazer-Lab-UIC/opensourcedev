Arduino Alvik

Overview

Arduino Alvik is a small two-wheel robot made for classrooms. An Arduino Nano ESP32 board rides on top and runs your code. A second chip inside handles the motors and sensors for you. It suits students, teachers, and families who want a ready robot with a free MicroPython course.

Good fit or not?

Good for

  • Learning to code a robot in MicroPython
  • Classroom lessons on sensors, driving, and line following
  • Mechanical add-ons with LEGO Technic holes and plug-in Grove and Qwiic ports
  • Wi-Fi and Bluetooth remote control projects

Not great for

  • Camera or vision projects, as it has no camera
  • Showing messages, as it has no screen
  • Tight budgets, as it costs more than many small hobby robots
  • Rough outdoor ground, as its wheels are small

Specs in plain words

  • The 8 by 8 distance sensor sees up to about three and a half meters. It can tell where things sit to the left, right or ahead.
  • A color sensor, a motion sensor, and three line sensors let it react to the floor and to bumps.
  • The 2500 mAh battery is a swappable 18650 cell. It charges through the same USB-C cable you code with.
  • Top speed is about 13 centimeters per second. That is a gentle crawl, about turtle speed.
  • 8 MB of extra memory gives room for longer programs and logged data.
  • It weighs about 192 grams. That is close to a smartphone.
Full spec sheet
ProcessorEspressif ESP32-S3 (Xtensa LX7) on Arduino Nano ESP32, plus STM32F411RC (Arm Cortex-M4) co-processor, 2 cores at 240 MHz
Memory512 KB plus 8 MB extra (PSRAM)
Storage16 MB
Ways to connect partsI2C, Serial (UART), USB device
RadiosWi-Fi, Bluetooth Low Energy
ConnectorsUSB-C, Grove, Qwiic or STEMMA QT, Servo ports, Battery plug
Built inmotion sensor, light sensor, buttons, color LED, motor driver, battery charger
Power18650 Li-Ion battery (2500 mAh), charged over USB-C on the Nano ESP32
Size96 x 95 x 37 mm

Core specs are for the Nano ESP32 main controller (ESP32-S3 up to 240 MHz, 512 KB SRAM, 8 MB PSRAM, 16 MB flash). The STM32F411RC co-processor handles the sensors, motor driver (MAX22211), battery gauge (MAX17332) and protection (LTC4360). GPIO and ADC counts are not listed for the robot as a whole. Most Nano pins are used by the carrier. Weight is 192 g and wheels are 34 mm in diameter. Motors are 6 V DC with a 96 rpm no-load speed. The color sensor is listed as APDS-9960 in tech specs. The ToF sensor is a VL53L7CX.

Things you could build

16 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • First drive in a square

    Run the starter MicroPython example and send the robot in a square. Change the numbers to draw a triangle next.

    Uses: Drives motors.

  • Wall-shy explorer

    Read the distance sensor and turn away before a wall. The robot wanders a room without bumping into things.

    Uses: Drives motors, Sensors built in.

  • Line-following race track

    Tape a black loop on the floor and follow it with the three line sensors. Hold a class race for the fastest lap.

    Uses: Drives motors, Sensors built in. Add: black electrical tape.

  • Color sorting game

    Hold colored cards under the color sensor. The robot spins, backs up, or lights its LEDs to match each color.

    Uses: Sensors built in. Add: colored paper cards.

  • Touch button dance party

    Map each touch button to a different LED color and a little dance move. Kids make up their own routines.

    Uses: Sensors built in, Drives motors.

  • Tilt alarm guard

    Use the motion sensor to notice a lift or a tip. The robot flashes red to catch a sneaky sibling.

    Uses: Sensors built in.

Builder ideas

  • Phone remote control

    Drive the robot from a phone over Bluetooth. Add a button for a spin and a button for a wave.

    Uses: Bluetooth, Drives motors.

  • Wi-Fi web joystick

    Serve a small web page from the robot over Wi-Fi. Steer it from any laptop in the classroom.

    Uses: Wi-Fi, Drives motors.

  • Garden path patrol

    Add a soil moisture sensor on a Grove cable. The robot rolls between pots and reports which ones look dry.

    Uses: Plug-in connectors, Drives motors, Wi-Fi. Add: soil moisture sensor.

  • Room temperature mapper

    Plug in a temperature sensor and drive a grid across the floor. Log warm and cool spots for a science lesson.

    Uses: Plug-in connectors, Drives motors. Add: temperature sensor.

  • Servo flag waver

    Attach a small servo with a paper flag. The robot waves hello each time someone steps in front of it.

    Uses: Plug-in connectors, Sensors built in. Add: servo motor, paper flag.

  • LEGO crane add-on

    Build a little arm from LEGO Technic parts on the mounting holes. Drive a servo to pick up light blocks.

    Uses: Plug-in connectors, Drives motors. Add: LEGO Technic pieces, servo motor.

  • Sunlight seeker

    Read the light level as the robot turns. It parks in the brightest spot like a cat on a windowsill.

    Uses: Sensors built in, Drives motors.

Expert ideas

  • Maze solver

    Use the 8 by 8 distance sensor to see openings ahead. Write a program that finds its way out of a cardboard maze.

    Uses: Sensors built in, Drives motors. Add: cardboard boxes.

  • Pet follow-me buddy

    Track the closest object with the multizone distance sensor. The robot trails a person or a rolling ball.

    Uses: Sensors built in, Drives motors.

  • Robot data logger

    Send speed, tilt, and distance readings to a laptop over Wi-Fi. Graph a run and talk about what the robot sensed.

    Uses: Wi-Fi, Sensors built in.

How open is it?

Open Code

The MicroPython library, the Arduino library, and the motor chip firmware are open code under the MPL-2.0 license. Arduino shares 3D models of the robot, but no schematic or board layout was found. The chips are closed, and the Wi-Fi and Bluetooth parts rely on closed Espressif code.
