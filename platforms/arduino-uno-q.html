Arduino UNO Q

Arduino

An Arduino UNO with a Linux computer and a microcontroller on one board.

Overview

The Arduino UNO Q looks like a classic UNO but has two brains. A Qualcomm processor runs Debian Linux, and an STM32 microcontroller runs Arduino sketches for timing work. The free App Lab software comes preinstalled and links Python apps to sketches. It suits makers who want AI, vision, or web apps alongside the familiar UNO pins and shields.

Good fit or not?

Good for

  • Projects that mix Linux apps with real-time pin control
  • Reusing UNO shields and Qwiic sensors
  • Camera and voice AI demos with ready-made Bricks
  • Wi-Fi and Bluetooth gadgets that also show a web page
  • Stepping up from a plain UNO to a small computer

Not great for

  • Battery projects that need to sleep for months
  • Plugging in a screen or keyboard with no extra dongle
  • Absolute beginners who want a single-chip Arduino with one cable
  • Heavy desktop use on the 2 GB model

Specs in plain words

  • The four-core 2.0 GHz processor runs a full Linux system with Python.
  • 2 GB of memory handles small apps and AI demos. The 4 GB model suits desktop use.
  • 16 GB of built-in storage holds the operating system, your apps and many photos.
  • The 160 MHz microcontroller handles fast, steady jobs like motors and blinking lights.
  • 47 pins and six analog inputs give lots of room for sensors and buttons.
  • The board is about 7 by 5 centimeters, roughly the size of a credit card.
Full spec sheet
ProcessorQualcomm Dragonwing QRB2210 (4x Cortex-A53, 2.0 GHz) plus STM32U585 MCU (Cortex-M33, 160 MHz), 4 cores at 2 GHz
Memory2 GB
Storage16 GB
AI chipAdreno 702 GPU, DSP and dual ISP
Pins47 pins, 6 analog inputs
Ways to connect partsI2C, CAN bus, USB host, Camera port (MIPI CSI), Display port (MIPI DSI)
RadiosWi-Fi, Bluetooth Low Energy
ConnectorsUSB-C, Qwiic or STEMMA QT, Pin headers
Built inLED grid, color LED
Power5 V up to 3 A over USB-C, or 7 to 24 V on VIN
Size68.58 x 53.34 mm

Core, clock and RAM values are for the Qualcomm MPU. RAM and eMMC are for the 2 GB base model. The 4 GB model has 4 GB RAM and 32 GB eMMC. The STM32U585 has 2 MB flash and 786 KB SRAM. GPIO count of 47 and six analog inputs come from the DigiKey highlight page and CNX Software. MIPI CSI and DSI are reached through bottom high-speed connectors on a carrier board. USB host use (keyboard, mouse, HDMI, Ethernet) needs a USB-C dongle. SPI and UART are expected on the UNO headers but were not confirmed on a page I read.

Things you could build

15 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Scrolling message badge

    Write a short sketch that scrolls words across the built-in LED grid. Show a name, a score, or a daily quote.

  • Plug-and-play weather station

    Snap a temperature and humidity sensor onto the Qwiic port. A Python app shows the readings on a web page.

    Uses: Plug-in connectors, Wi-Fi, Runs Linux. Add: temperature and humidity sensor, Qwiic cable.

  • Phone-controlled desk lamp

    Drive a relay from the Arduino pins and serve a simple web page from Linux. Tap a button on your phone to switch the lamp.

    Uses: Wi-Fi, Runs Linux. Add: relay module.

  • Science fair data logger

    Read a light sensor and a temperature sensor on the analog pins. Python saves the values to a spreadsheet file.

    Uses: Runs Linux. Add: light sensor, temperature sensor, jumper wires.

Builder ideas

  • Object spotting camera

    Plug in a USB webcam and run a ready-made vision Brick in App Lab. The board names the things it sees and lights the LED grid.

    Uses: Camera, Plugs in USB gadgets, Runs Linux. Add: USB webcam, USB-C dongle.

  • Bird feeder visitor log

    Point a camera at a feeder and let a vision model count birds. Each visit goes into a log with a photo.

    Uses: Camera, Plugs in USB gadgets, Runs Linux. Add: USB webcam, USB-C dongle, weatherproof box.

  • Smart plant waterer

    Read a soil sensor with the microcontroller and run a small pump. Linux keeps a watering diary you can view on Wi-Fi.

    Uses: Runs Linux, Wi-Fi. Add: soil moisture sensor, small water pump, relay module.

  • Tiny desktop computer for class

    Connect a screen, keyboard, and mouse through a USB-C dongle. Students browse, write code, and test circuits on one board.

    Uses: Screen, Plugs in USB gadgets, Runs Linux. Add: USB-C dongle, HDMI screen, keyboard, mouse.

  • Shield-based music box

    Stack an audio shield on the UNO headers and trigger sounds with buttons. Python can pick the next song from a playlist.

    Uses: Runs Linux. Add: audio shield, push buttons, small speaker.

  • Home dashboard on a screen

    Show the weather, the bus times, and your calendar on a monitor. Update it over Wi-Fi each minute.

    Uses: Screen, Wi-Fi, Runs Linux, Plugs in USB gadgets. Add: USB-C dongle, HDMI screen.

  • Servo puppet controlled from the web

    Wire two servos to the pins and move them from sliders on a web page. Friends can make the puppet wave from a phone.

    Uses: Wi-Fi, Runs Linux. Add: servo motors, jumper wires.

Expert ideas

  • Spoken command robot car

    Use a USB microphone and a keyword model to give voice orders. The microcontroller drives the wheels on each word.

    Uses: Plugs in USB gadgets, Runs Linux. Add: USB microphone, motor driver shield, small robot car chassis, battery pack.

  • Hand gesture light show

    Watch your hand through a webcam and track simple poses. Each pose sets a different color on an LED strip.

    Uses: Camera, Plugs in USB gadgets, Runs Linux. Add: USB webcam, USB-C dongle, LED strip.

  • Bluetooth sensor hub

    Collect readings from nearby Bluetooth tags around the house. Linux stores them and draws simple charts.

    Uses: Bluetooth, Runs Linux. Add: Bluetooth sensor tags.

  • Door greeter with a face counter

    Count how many people pass a doorway with a camera model. The LED grid shows the total for the day.

    Uses: Camera, Plugs in USB gadgets, Runs Linux. Add: USB webcam, USB-C dongle.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseOpen license
  • Coding toolsMostly open
  • The chip itselfClosed chip design

Arduino publishes the schematics, board layout, and Gerber files under CC BY-SA 4.0. App Lab and the App CLI use GPL-3.0, and the Zephyr core is Apache-2.0. The Qualcomm graphics, signal, and Wi-Fi parts likely need closed firmware. The board is not on the OSHWA certified list.

Key terms on this page

Short definitions of words used above and below. Select a term for the full glossary entry.

ADC
An ADC turns a smooth analog signal into a number.
Analog
An analog signal can take any value in a range.
Binary blob
A binary blob is a piece of closed code shipped without its source.
CC BY-SA
CC BY-SA is a Creative Commons license that asks for credit and sharing alike.
Gerber files
Gerber files are the standard files sent to a PCB factory.
Microcontroller
A microcontroller is a tiny computer on a single chip.
Operating system
An operating system is the main software that runs a computer.
OSHWA certification
OSHWA certification is a free check run by the Open Source Hardware Association.
Qwiic
Qwiic is a small four-pin plug system from SparkFun.
Shield
A shield is an add-on board that stacks on top of an Arduino-shaped board.
Sketch
A sketch is the Arduino name for a program.
Zephyr
Zephyr is an open-source RTOS backed by the Linux Foundation.
