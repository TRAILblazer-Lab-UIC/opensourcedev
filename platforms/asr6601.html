Overview

The ASR6601 is a chip from ASR Microelectronics that puts a LoRa radio and a small processor together. LoRa sends tiny messages over long distances on little power. Most people meet the chip inside Ai-Thinker Ra-08 modules and kits. It suits experienced makers who build low-cost LoRaWAN sensor nodes in C.

How the scores work

Good fit or not?

Good for

  • Long-range sensor nodes that send small readings
  • Battery projects that sleep most of the time
  • LoRaWAN networks in many world regions
  • Cheap radio modems driven by AT commands

Not great for

  • Beginners, as there is no Arduino core and setup is fiddly
  • Big programs, as the common version has only 16 KB of working memory
  • Sending photos, sound, or other large data over the radio
  • Finding help, as the community is small and the SDK is no longer updated

Specs in plain words

  • 48 MHz is plenty for reading a sensor and sending a message.
  • 128 KB of storage holds a LoRaWAN program with a little room to spare.
  • 16 KB of working memory fits a simple sensor program and the radio stack.
  • The radio covers 150 to 960 MHz, but each kit is tuned for one band.
  • Deep sleep of about 1.3 microamps lets a small battery last a very long time.
  • Built-in encryption engines keep radio messages private.

Memory values are for the ASR6601CB used in the Ra-08 and Ra-08H modules. The ASR6601SE has 256 KB flash and 64 KB SRAM in an 8 x 8 mm QFN68. Size is the Ra-08 SMD-18 module. ASR lists QSPI, I2C, an LCD driver up to 8 COM x 20 SEG and three op-amps. CNX Software lists GPIO, I2C, I2S, UART, LPUART, SWD, SPI and QSPI for the Ra-08. Chip GPIO and ADC counts were not found in a fetched source. The Ra-08 module datasheet claims 0.9 uA deep sleep. Kit connectors and buttons are inferred from the ASR quick start guide (download-mode button SW3 and serial download) and were not confirmed from the kit spec PDF. ASR's quick start names the core as STAR-MC1. By contrast, Ai-Thinker and CNX call it Cortex-M4.

Builder ideas

  • Garden soil moisture reporter

    Read a soil sensor every hour and send the value over LoRa. Check a far-off vegetable bed from the house.

    Uses: LoRa long range radio, Sips power. Add: soil moisture sensor, LoRa antenna, battery pack.

  • Mailbox alert

    Sense the mailbox door with a magnet switch and send a LoRa message. Know the mail came without a walk to the street.

    Uses: LoRa long range radio, Sips power. Add: magnetic door switch, LoRa antenna, battery pack.

  • Two-way text pager

    Pair two kits and send short typed messages between them over a serial terminal. Talk across a campsite with no phone signal.

    Uses: LoRa long range radio. Add: second kit, two LoRa antennas.

  • Livestock gate monitor

    Report whether a field gate is open or closed over LoRa. Farmers skip a long drive to check.

    Uses: LoRa long range radio, Sips power. Add: magnetic door switch, LoRa antenna, battery pack.

  • Range test science lab

    Send numbered packets while walking away from a base station. Students map how far the signal reaches.

    Uses: LoRa long range radio. Add: second kit, two LoRa antennas, battery pack.

  • Bike shed motion alarm

    Sense motion in a bike shed and send a LoRa alert to the house. The chip stays asleep until something moves.

    Uses: LoRa long range radio, Sips power. Add: motion sensor, LoRa antenna, battery pack.

Expert ideas

  • Weather station node

    Log temperature and humidity and send readings to a LoRaWAN gateway. The chip sleeps between readings to save its battery.

    Uses: LoRa long range radio, Sips power. Add: temperature and humidity sensor, LoRa antenna, battery pack.

  • Water tank level meter

    Measure the water level in a rain barrel and report it over LoRa. Get a heads-up before the tank runs dry.

    Uses: LoRa long range radio, Sips power. Add: water level sensor, LoRa antenna, battery pack.

  • Segment display thermometer

    Drive a simple segment LCD with the built-in driver and show the temperature. It runs for a long time on small batteries.

    Uses: Screen, Sips power. Add: segment LCD, temperature sensor, coin cell holder.

  • Smoke sensor experiment

    Use the built-in op-amps to read an infrared smoke sensing circuit. Send a LoRa alert from a shed or barn.

    Uses: LoRa long range radio. Add: infrared LED, photodiode, LoRa antenna.

  • Community air sensor network

    Place several nodes around a neighborhood to report dust levels. A shared LoRaWAN gateway collects every reading.

    Uses: LoRa long range radio, Mesh messaging, Sips power. Add: dust sensor, LoRa antenna, weatherproof box.

Ai-Thinker shares schematics, footprints, and spec sheets for the Ra-08 modules and kits. No layout files or hardware license were found. ASR's SDK is public on GitHub and builds with open GCC tools, but it has no license file and ships a closed crypto library. The chip is a closed design.
