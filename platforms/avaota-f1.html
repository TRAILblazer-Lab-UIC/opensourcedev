Avaota F1

Avaota (YuzukiHD / AvaotaSBC)

A coin-sized RISC-V Linux board for tiny Wi-Fi cameras.

Overview

The Avaota F1 is a tiny Linux camera board about the size of a large coin. It runs on an Allwinner V821 chip with RISC-V cores and built-in Wi-Fi. It has a camera connector, a microphone, and a memory card slot. It suits experienced tinkerers who want a cheap open Wi-Fi camera.

Good fit or not?

Good for

  • Tiny Wi-Fi cameras and time-lapse rigs
  • Learning how Linux boots on RISC-V chips
  • Studying a fully open board layout
  • Small screen projects with a camera feed

Not great for

  • Beginners, as no ready-made system image was found
  • Readers who need English software guides, as the SDK docs are in Chinese
  • Face or object recognition, as the chip has no AI engine
  • Bluetooth gadgets, as the board has no Bluetooth

Specs in plain words

  • The 1.2 GHz main core runs a small Linux system.
  • A second 600 MHz core looks after the Wi-Fi.
  • 64 MB of memory is enough for a lean Linux and a camera stream, but not a desktop.
  • 32 MB of flash holds a small system image, and a memory card adds space for photos.
  • The camera records 1080p video and compresses it with H.264.
  • At 35 by 22 millimeters, the board is about the size of a postage stamp.

RAM is 64 MB DDR2 inside the SoC. flash_kb is the 32 MB PY25Q256 SPI NOR. The board has one user LED, a FEL button and an EA3036 PMIC. The ISP handles a 1080p15 plus 480p15 dual stream and the encoder is H.264 only, with no H.265. There is no Bluetooth. JTAG is reached through the microSD slot. The 600 MHz MCU handles Wi-Fi and an optional 4G module. i2c and lcd are inferred from header pin functions and SPI screen support. Check the pinout.

Builder ideas

  • Window time-lapse camera

    Snap a photo every few minutes and save it to a memory card. Stitch a week of clouds or a growing seedling into a short video.

    Uses: Camera, Runs Linux. Add: GC2083 camera module, microSD card, USB-C power supply.

  • Pocket voice memo recorder

    Record notes through the onboard microphone and save them to the memory card. Copy them to a computer over Wi-Fi.

    Uses: Hears sound, Sensors built in, Runs Linux. Add: microSD card, push button, battery pack.

  • Noise level meter

    Measure room loudness with the onboard microphone. A small screen shows a bar that grows with the noise.

    Uses: Hears sound, Screen. Add: small SPI screen.

  • Wi-Fi photo frame

    Show pictures on a small screen. New photos arrive over Wi-Fi from a shared folder.

    Uses: Screen, Wi-Fi, Runs Linux. Add: 3.5 inch SPI screen.

  • Room sensor web page

    Wire a temperature sensor to the header pins. The board serves a tiny web page with the readings on your network.

    Uses: Wi-Fi, Runs Linux. Add: temperature and humidity sensor.

  • Science experiment camera

    Film a slow chemistry reaction or melting ice at set times. Students measure the change frame by frame.

    Uses: Camera, Runs Linux. Add: GC2083 camera module, microSD card.

  • Design a camera case

    Use the open 3D model files to design a snug printed case. Share it with others who build the board.

    Add: 3D printer filament.

Expert ideas

  • Wi-Fi bird box camera

    Mount the tiny board inside a bird box with the camera. Watch the live view on your phone over home Wi-Fi.

    Uses: Camera, Wi-Fi, Runs Linux. Add: GC2083 camera module, weatherproof box, USB-C power supply.

  • Garden watch camera

    Aim the camera at a vegetable bed. Record short clips to the memory card to see what visits at night.

    Uses: Camera, Runs Linux. Add: GC2083 camera module, microSD card, weatherproof box, infrared light.

  • Tiny doorbell viewer

    Pair the camera with a small screen inside the door. A button press shows who is outside.

    Uses: Camera, Screen, Runs Linux. Add: GC2083 camera module, small SPI screen, push button.

  • Classroom document camera

    Point the camera down at a desk and stream the view over Wi-Fi. A teacher shows worksheets on a projector screen.

    Uses: Camera, Wi-Fi, Runs Linux. Add: GC2083 camera module, small stand.

  • Learn RISC-V Linux booting

    Flash the RustSBI boot package with the open xfel tool. Watch each boot stage on a serial console.

    Uses: Runs Linux. Add: USB serial adapter.

How open is it?

Openness level

Level 2 of 3. Wild Open shares the most.

  • The chip itselfClosed chip design

The full board design is on GitHub under CERN-OHL-S-2.0, with a schematic, PCB project, Gerbers, and 3D files. Linux and U-Boot are GPL-2.0, but the Tina Linux SDK terms are unclear. The Wi-Fi firmware and media libraries may be closed vendor files. The V821 chip itself is a closed Allwinner design.
