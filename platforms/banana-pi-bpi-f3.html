Banana Pi BPI-F3

Banana Pi

An eight-core RISC-V single board computer with built-in AI help.

Overview

The Banana Pi BPI-F3 is a single board computer with an eight-core RISC-V chip. It suits Linux tinkerers who want to explore a newer kind of processor. It packs two network ports, four USB 3.0 ports and slots for fast storage. Built-in AI instructions help it run small models.

Specs in plain words

  • Eight cores at about 1.6 GHz share the work of many small tasks at once.
  • Two to sixteen gigabytes of memory set how many apps it can juggle.
  • Two TOPS of AI compute is enough for small image and sound models.
  • The M.2 slot takes a fast SSD for storage that beats a memory card.
  • Two camera connectors let it watch with one or two cameras.
  • The board is about 148 by 100 millimeters, close to the size of a large postcard.

RAM and eMMC come in four combinations (2+8, 4+16, 8+32 and 16+128 GB), and the values shown are the 4 GB plus 16 GB version. Clock speed is not on the Banana Pi pages. 1.6 GHz comes from the postmarketOS wiki, which lists 1.6 / 2.0 GHz. The 26-pin header carries I2C, SPI, UART and about 10 GPIO pins. Optional 4 MB SPI NOR and 32 MB SPI NAND are listed. The docs list Wi-Fi 6 and Bluetooth 5.2. By contrast, CNX Software listed Wi-Fi 5 and Bluetooth 4.2 for the same RTL8852BS module. The four USB 3.0 ports share one VL817 hub, per CNX Software. The board also has a mini PCIe slot with a SIM slot, a speaker header, an IR receiver, a fan header and a DIP switch for boot selection. Bluetooth Classic support is unclear. As a result, only ble is listed.

How open is it?

Open Board

Banana Pi publishes a PDF schematic and a board outline. No hardware license is stated. The Linux kernel, U-Boot and OpenSBI sources are public, but the boot code uses some closed blobs. The graphics and Wi-Fi parts rely on closed firmware or drivers, and the chip design itself is closed.

Hardware license: None stated · Software license: Linux kernel GPL-2.0 (pi-linux repo has no license file set)
