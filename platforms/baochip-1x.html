Overview

The Baochip-1x is a RISC-V microcontroller led by hardware hacker Andrew "bunnie" Huang. It runs a 350 MHz main core plus four small BIO cores for custom input and output timing. Most of the chip's design files are published under an open license, which is rare for a production chip. The low-cost Dabao board makes it easy to try, but the tools suit experienced coders.

Good fit or not?

Good for

  • Security projects with crypto engines, a key store, and a random number source
  • Learning how a real chip works from its open design files
  • Rust developers using the Xous operating system
  • Custom timing tricks with the BIO cores

Not great for

  • Beginners, as it needs Rust or C and has no Arduino or MicroPython support yet
  • Wireless projects, as it has no radio
  • Analog sensors today, as the ADC driver was still in progress
  • Quick buys, as stock was mostly pre-order in 2026

Specs in plain words

  • 350 MHz is fast for a microcontroller, about three times a basic Pico board.
  • 2 MiB of memory is room for small games, graphics, and big data buffers.
  • 4 MiB of built-in storage holds your program and some saved files on the chip itself.
  • The four 700 MHz BIO cores act like tiny helpers that wiggle pins with exact timing.
  • 20 pins on the Dabao connect sensors, screens, and buttons.
  • The Dabao board is about the size of a stick of gum.

cores counts the main application CPU. The four 700 MHz BIO cores are a separate I/O coprocessor. ram_kb is the 2 MiB system SRAM. There is also 256 KiB of I/O SRAM. flash_kb is the 4 MiB on-chip ReRAM. gpio is the 20 I/Os broken out on the Dabao's two 16-pin headers. The chip's full pin count was not confirmed. A JLCPCB snippet lists the part as WLCSP-72. The peripheral register docs list four UARTs, four SPI hosts, two SPI devices, four I2C, I2S, SDIO, a camera interface, PWM and an ADC. CNX reports ADC and SD card drivers were still in development. The camera interface type was not confirmed. Size, connectors and buttons (reset and prog) are for the Dabao board. No external PSRAM or flash on the Dabao was confirmed.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blink and button first program

    Build the C SDK blink example and flash it over USB. Add a button press that changes the speed.

    Add: push button, jumper wires.

  • Custom LED strip driver

    Use the four BIO cores to send exact timing signals to a strip of color LEDs. Light up a shelf or a costume.

    Add: LED strip, 5 V power supply.

  • Random number dice for games

    Roll fair dice with the true random number generator. Show each roll on a tiny screen for board game night.

    Add: small I2C OLED screen.

  • Digital audio tone player

    Send sound out through the I2S port to a small amplifier. Play chimes or simple tunes.

    Uses: Makes sound. Add: I2S amplifier board, small speaker.

  • Sound level meter

    Read a digital microphone over I2S and show how loud a room is. Use it to check noise in a classroom.

    Uses: Hears sound. Add: I2S microphone, small I2C OLED screen.

  • Weather sensor logger

    Read temperature and humidity over I2C and print the values to your computer over USB.

    Add: temperature and humidity sensor, jumper wires.

Expert ideas

  • Hardware password vault

    Keep passwords inside the chip's key store and type them out over USB on demand. The crypto engines guard the secrets.

  • Retro DOOM port

    Run the community DOOM port on the Dabao. It shows how much a microcontroller with 2 MiB of memory can do.

    Add: small SPI display, push buttons.

  • Signed message stamper

    Sign short messages with the chip's elliptic curve engine. Friends can check that a note really came from you.

  • Xous secure OS experiments

    Write Rust apps for the Xous operating system that ran on the Precursor phone. Learn how apps stay walled off from each other.

  • Chip design study with the RTL

    Read the open Verilog for the CPU and run it in the Verilator model. Compare the simulation with the real chip.

  • Old protocol revival

    Teach the BIO cores to speak an old game controller or keyboard protocol. Connect vintage gear to a modern computer.

    Add: vintage controller, connector breakout.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 3 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseOpen license
  • Coding toolsFully open
  • The chip itselfOpen chip design

The chip's RTL, including the CPU and BIO cores, is published under CERN-OHL-W-2.0. Some blocks stay closed, such as the bus fabric and analog parts like the PLL, USB, and ADC. The Dabao board has full KiCad files under CERN-OHL-W-2.0, and the software is Apache-2.0.

Hardware license: CERN-OHL-W-2.0 (chip RTL and Dabao board) · Software license: Apache-2.0 (Xous, Dabao C SDK, BIO tools)
