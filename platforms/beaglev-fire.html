BeagleV-Fire

BeagleBoard.org

A RISC-V Linux computer with a reprogrammable FPGA chip built right in.

Field marks: BeagleV-Fire keeps the classic BeagleBone headers and tucks a RISC-V chip plus an FPGA underneath, giving old capes a new job and you two toolchains to learn.

Overview

BeagleV-Fire is a small Linux computer from BeagleBoard.org with an FPGA inside its main chip. An FPGA is a chip you can rewire with code to become custom digital circuits. Five RISC-V processor cores run Ubuntu next to that reprogrammable logic. It suits engineers, students, and advanced makers who want to mix Linux software with their own hardware designs.

How the scores work

Good fit or not?

Good for

  • Learning how Linux and custom FPGA logic work together
  • Experimenting with RISC-V computers
  • Reusing BeagleBone capes on a newer board
  • Fast, precise control jobs such as motors or camera pipelines

Not great for

  • Complete beginners, as the FPGA side needs hardware languages and expert tools
  • A fast everyday Linux computer, as its cores run slower than cheaper boards
  • Fully open FPGA work, as custom logic needs Microchip's closed Libero tools
  • Wireless projects out of the box, as Wi-Fi needs an extra M.2 module

Specs in plain words

  • Four main RISC-V cores at 667 MHz run Linux, with a fifth small core watching over the system.
  • About 23 thousand logic elements give room for a small extra processor plus some custom circuits.
  • 2 GB of memory is enough for a light Linux system with a few programs open.
  • 16 GB of built-in storage holds the operating system and lots of project files, and a microSD slot adds more.
  • Gigabit Ethernet gives a fast wired network link.
  • The board is about the size of a credit card and runs on 5 V over USB-C.

Specs from the BeagleBoard product page, the README in the OpenBeagle hardware repo and the docs design chapter. cores counts the four application cores plus the monitor core. clock_mhz is the listed Fmax of 667 MHz. flash_kb is the 16 GB Kingston eMMC. There is also 128 Mbit SPI flash, 128 KB eNVM and 56 KB sNVM. PCB is 86.38 x 54.6 mm, 12 layers, max height 18.8 mm, net weight 45.8 g. The CSI connector is listed as a 22-pin CSI / low-speed FFC expansion connector. pcie and sdio refer to the M.2 E-key socket. usb_device and usb_host reflect the dual-role 480 Mbps USB-C port. JTAG is a Tag-Connect footprint. The cape headers carry I2C, SPI and UART per BeagleBone convention, but the exact GPIO count and ADC channel count were not stated on the pages read. Docs list a user button, a reset button, user LEDs and a power LED. CNX Software gave the SoC as MPFS250T in one spot. The official page, repo README and Hackaday all say MPFS025T.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Explore RISC-V Linux

    Boot the Ubuntu system that comes on the board and try everyday Linux commands. You get a feel for computers built on the open RISC-V design.

    Uses: Runs Linux.

  • Blink an LED from Python

    Wire an LED to the cape header and switch it on and off with a short Python script. It is a gentle first step with the pins.

    Uses: Runs Linux. Add: LED, resistor, jumper wires.

Builder ideas

  • Classroom RISC-V lab server

    Plug the board into the school network and let students log in remotely. They can practice RISC-V programs on real hardware.

    Uses: Runs Linux, Wired network. Add: network cable.

  • Home file and backup box

    Share a USB drive with the computers in your home over the wired network. Family photos get a safe second home.

    Uses: Runs Linux, Wired network, Plugs in USB gadgets. Add: USB drive, network cable.

  • Weather station web page

    Read a temperature and humidity sensor on the header pins. Show the readings on a small web page anyone at home can open.

    Uses: Runs Linux, Wired network. Add: temperature and humidity sensor, jumper wires.

  • Precise light meter

    Read a light sensor with the board's fine-grained analog converter. Track how sunlight changes across a day for science class.

    Uses: Runs Linux. Add: light sensor, jumper wires.

  • Stack a cape add-on

    Press a BeagleBone-style cape onto the headers to add relays, displays or motor drivers. Many older capes fit this board.

    Uses: Runs Linux. Add: cape add-on board.

Expert ideas

  • Garden time-lapse camera

    Attach a camera module and snap a photo of your garden every hour. Turn the photos into a video of plants growing.

    Uses: Runs Linux, Camera. Add: camera module, ribbon cable.

  • Run a soft processor in the FPGA

    Follow the official PicoRV tutorial to build a tiny extra processor out of FPGA logic. It shows how chips are made from simple parts.

  • Hardware motor controller

    Design motor control logic in the FPGA for very steady timing. Linux on the main cores can send it simple speed commands.

    Uses: Runs Linux. Add: motor driver board, DC motor, power supply.

  • LED strip light show

    Generate the fast data signal for a color LED strip in FPGA logic. Program patterns for a stage, a party, or an art piece.

    Add: LED strip, 5 V power supply, jumper wires.

  • Homemade logic analyzer

    Turn the FPGA into a tool that records very fast signals on several pins. Use it to debug other gadgets on your bench.

    Uses: Runs Linux. Add: jumper wires.

  • Camera image filter in hardware

    Process camera frames in FPGA logic to find edges or motion. Linux then saves or shares the results.

    Uses: Runs Linux, Camera. Add: camera module, ribbon cable.

  • Robot brain with a game controller

    Read a USB game controller in Linux and drive motors through the header pins. Build a small rover for a school club.

    Uses: Runs Linux, Plugs in USB gadgets. Add: USB game controller, motor driver board, DC motors, battery pack.

The board files are open. Schematics, board layout files, Gerbers, and the parts list are published under CC-BY-4.0, and the board is OSHWA certified. Linux runs on open tools, but custom FPGA logic needs Microchip's closed Libero tools, and the PolarFire chip itself is closed.
