Overview

The BL616 is a small RISC-V microcontroller chip from Bouffalo Lab. It packs Wi-Fi 6, Bluetooth, and a Zigbee and Thread radio onto one chip. Boards built on it cost about four to five dollars. It suits tinkerers who are comfortable with C and want a cheap smart home or USB gadget brain.

Good fit or not?

Good for

  • Matter, Zigbee, and Thread smart home experiments
  • Wi-Fi 6 sensors on a tight budget
  • USB gadgets such as game pads and custom keyboards
  • Small screen and camera projects with plenty of built-in interfaces
  • Battery gadgets that sleep for long stretches

Not great for

  • First-time coders, as the main tools are C based
  • Arduino-style projects, as the Arduino core is still experimental
  • Readers who need English guides, as many docs appear in Chinese first
  • Fully open wireless code, as the Wi-Fi part ships as closed libraries

Specs in plain words

  • 320 MHz is a fast speed for a chip this small. It can redraw a little screen smoothly.
  • 480 KB of working memory holds a small screen image and a Wi-Fi connection at once.
  • 4 MB of flash on most boards stores your program plus pictures and sounds.
  • Wi-Fi 6 is the newer Wi-Fi standard. It copes better in busy homes full of gadgets.
  • High-speed USB lets the board act as a keyboard or read a USB device.
  • Hibernate uses under one microamp. A battery can last a very long time between wake-ups.

The datasheet v1.5 lists 532 KB SRAM, which includes 4 KB HBN RAM and 48 KB of cache RAM. As a result, CNX and Sipeed quote 480 KB usable. Zephyr's board files use 320 KiB. GPIO is 19 for the BL616 and 35 for the BL618. The 12 ADC channels are the external GPADC inputs. Flash is 4 MB on the Sipeed M0S and Ai-M62-12F. PSRAM is 0 on those boards. The BL618-based Sipeed M0P has 4 MB PSRAM and 8 MB flash. Low power is the datasheet's hibernate figure, listed as under 1 uA. Connectors, onboard parts and size are for the Ai-Thinker Ai-M62-12F-Kit, which has an RGB LED and two user LEDs. Some boards overclock the core to 384 or 480 MHz. 320 MHz is the datasheet maximum. Early coverage said Bluetooth 5.2. The datasheet v1.5 says Bluetooth 5.3.

Expert ideas

  • Matter smart plug brain

    Drive a relay from the board and join it to a Matter smart home. Switch a lamp from your phone app.

    Uses: Wi-Fi, Thread or Zigbee. Add: relay module, 5 volt power supply.

  • Zigbee door sensor

    Wire a door switch and report each opening over Zigbee. The board sleeps between events to save power.

    Uses: Thread or Zigbee, Sips power. Add: door switch, battery pack.

  • Thread mesh garden node

    Put a soil moisture sensor in a pot. The reading hops across a Thread mesh to your home hub.

    Uses: Thread or Zigbee, Mesh messaging, Sips power. Add: soil moisture sensor, battery pack.

  • Snapshot camera for the bird feeder

    Connect a small camera to the camera port and save compressed photos. Check which birds came to visit.

    Uses: Camera, Wi-Fi. Add: small camera module, 5 volt power supply.

  • USB keyboard reader

    Plug a USB keyboard into the board's USB host port. Turn key presses into commands for a robot or a light show.

    Uses: Plugs in USB gadgets. Add: USB keyboard, USB OTG adapter.

  • Wired network sensor hub

    Add an Ethernet jack and read several sensors in a shed or workshop. Data flows over a cable with no Wi-Fi needed.

    Uses: Wired network. Add: Ethernet jack module, temperature sensor.

The Bouffalo SDK is open code under the Apache 2.0 license. Sipeed publishes schematics for its modules and docks, but no board layout files or hardware license were found. The Wi-Fi driver ships as closed libraries, and the chip design and its RISC-V core stay closed.

Quick facts

Made byBouffalo Lab
KindMicrocontrollers
Code you need*Lots of code
Real projects use the Bouffalo C SDK or Zephyr, and the Arduino core is still marked experimental.
Ease of use*2 of 5
Beginners must install a C SDK and a RISC-V compiler and then flash over a serial link with a boot button.
Effort to get going*Moderate
The board costs about four dollars but toolchain setup and flashing take one to three hours.
Docs quality*2 of 5
The datasheet and SDK examples exist, but many guides are in Chinese first and readers complained about the docs at launch.
Community*Small
The main SDK repo has about 500 stars and most help comes from a few forums and one toolchain guide.
