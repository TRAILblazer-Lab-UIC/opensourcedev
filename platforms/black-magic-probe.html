Overview

The Black Magic Probe is a small debugger for microcontrollers. It plugs into your computer over USB and into a project board through a ribbon cable. It has a GDB server built into its own firmware. You need no extra helper software on the computer.

Not great for

  • Building gadgets on its own
  • Using a schematic of the current board, which is still unpublished

Specs in plain words

  • The probe's own brain is a 72 MHz Arm chip with 20 KB of memory. That is plenty for its one job of talking to your board.
  • It works with boards that run anywhere from 1.7 to 5 volts. Most hobby boards fall in that range.
  • It can power a small target board with 3.3 volts at up to 100 milliamps. That covers a simple board and an LED or two.
  • The newest version adds 16 MB of extra storage. Recent firmware can treat it as a chip to test on.
  • It draws about 120 milliamps and runs a little warm. That is normal.

The probe is a tool. As a result, specs describe its onboard brain. The firmware build uses the STM32F1 platform, and its linker script sets 128 KB flash and 20 KB RAM. The exact STM32F1 part on V2.3 was not confirmed. 72 MHz is the STM32F1 maximum and was not stated on a fetched page. V2.3 adds 16 MB of SPI flash (the firmware can expose it as a target since v2.1.0) that is not counted in flash_kb. Target side uses a 0.05 inch 10-pin Arm Cortex debug connector and a UART cable, which are not in the connector vocabulary. The AUX connector carries SPI. Adafruit lists 35 x 15 x 12 mm and 2.7 g, but those figures may date from the smaller V2.1. V2.3 is described as slightly larger. As a result, size_mm is left blank. Power draw is about 120 mA, and Adafruit notes the probe gets warm. There is one button for forcing DFU mode and three status LEDs.

  • Pause a blinking light program

  • Read messages from a music project

Builder ideas

  • Rescue a stuck board

    Reflash a board whose own loader no longer works. The probe writes new code straight into the chip.

  • Classroom bug hunt

    Plant small bugs in a class program and let students hunt them down. Breakpoints show exactly where things go wrong.

    Add: microcontroller board, LED.

  • Live weather station readings

    Stream temperature readings to your computer with RTT. The board keeps running at full speed during the stream.

    Add: microcontroller board, temperature sensor.

  • Print messages from a tiny board

    Use semihosting to send text from a board with no screen to your computer. It is handy for early tests.

  • Flash badges for a workshop

    Add: badge boards with debug connectors.

Expert ideas

  • Catch a game score glitch

    Set a watchpoint on the score in a handheld game. The probe stops the code the instant something changes it.

    Add: microcontroller board, small display, buttons.

  • Find a battery drain in a garden sensor

    Step through the sleep code of a plant monitor. Spot the line that keeps the chip awake too long.

    Add: microcontroller board, soil moisture sensor, battery pack.

  • Trace an LED light show

    Add: microcontroller board, LED strip.

How open is it?

Level 2 of 3. Wild Open shares the most.

The Black Magic Debug firmware is open under GPL-3.0, and the bmputil tool uses Apache-2.0. Schematics for older probes are published, but the current V2.3 schematic is still missing. No hardware license is stated, and the STM32 chip inside is closed.
