Overview

The Bus Pirate 5 is a pocket tool for talking to chips. You type commands in a serial terminal, and it speaks I2C, SPI, UART, 1-Wire, MIDI, and LED strip signals for you. A color screen labels every pin and shows live voltages. It suits hackers, makers, and curious learners who want to poke at real hardware.

Specs in plain words

  • A Raspberry Pi RP2040 chip runs the show at 125 MHz with 264 KB of memory. That is lots of room for a tool like this.
  • Eight protected pins work with chips from 1.2 to 5 volts. It can talk to most hobby parts safely.
  • The built-in power supply gives 1 to 5 volts with a limit up to 500 milliamps. A mistake trips the limit and spares your parts.
  • About 100 MB of storage shows up as a USB drive. You can keep settings and saved chip copies there.
  • The 240 by 320 color screen is about the size of a postage stamp. It shows pin names and voltages live.

Memory264 KB
Storage16 MB
Pins8 pins, 8 analog inputs
Ways to connect partsI2C, SPI, Serial (UART), USB device, Debug port

Built inscreen, color LED, buttons
Power5 V over USB-C

Values are for the BP5 REV10. The 5XL uses an RP2350A and the 6 uses an RP2350B, both dual Cortex-M33 at 133 MHz with 512 KB RAM and 12 PIO state machines. The 1 Gbit NAND (about 100 MB usable) is storage and is not counted in flash_kb. gpio counts the eight buffered user I/O pins. The analog mux measures voltage on all eight pins. As a result, adc_channels is 8. The main connector is a keyed 2.54 mm 10-pin header. There is also a 1 mm 9-pin auxiliary connector and a 3-pin SWD debug header on the bottom. Docs list "18 RGB LEDs" and also "16 SK6812 RGB LEDs". There is one button. Protocols include 1-Wire, I2C, SPI, UART, MIDI and serial LEDs. 1-Wire and MIDI are not in the interface vocabulary. The BP6 replaces the 74HC595 shift registers with extra RP2350B pins and adds an 8-pin look-behind buffer described as an always-running logic analyzer. Board dimensions were not found.

Things you could build

15 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Say hello to a temperature sensor

    Switch to I2C mode and ask a sensor for the temperature. The reply shows up in your terminal right away.

    Add: temperature sensor board.

  • Test a sensor before you build

    Check that a new sensor works before you wire it into a project. It saves a lot of guessing later.

    Add: sensor board.

  • Light up an LED strip by command

    Type colors into the serial LED mode and watch a strip change. It is a fun first taste of how LEDs get their orders.

    Add: LED strip.

  • Mini volt meter on screen

    Read the voltage on each pin from the color screen. Students can see a battery or sensor output at a glance.

    Uses: Screen. Add: jumper wires.

  • Safe power for a small circuit

    Feed a breadboard circuit from the built-in supply with a current limit. The screen shows how much current it draws.

    Uses: Screen. Add: breadboard, LEDs, resistors.

  • Garden soil temperature probe

    Read a waterproof 1-Wire temperature probe pushed into a garden bed. Compare sunny and shady spots.

    Add: waterproof temperature probe.

Builder ideas

  • Classroom protocol lab

    Let students send bytes to a chip and watch the pin labels on the screen. They learn how gadgets talk to each other.

    Uses: Screen. Add: sensor board, jumper wires.

  • Find hidden chips on an old gadget

    Scan the I2C bus inside a broken toy or appliance. The tool lists every chip that answers.

    Add: probe clips.

  • Back up a flash memory chip

    Read the contents of a flash chip from an old router or game board. Save a copy on the built-in storage.

    Add: chip test clip.

  • Read an old toy's memory

    Dump the small EEPROM inside a toy or device. You can see the settings it remembers.

    Add: chip test clip.

  • Listen to a mystery serial port

    Connect to the UART pins on an unknown board and read its startup messages. Many gadgets reveal their secrets this way.

    Add: jumper wires.

  • Send notes to a synthesizer

    Use MIDI mode to send note messages to a keyboard or synth. It is a neat way to test music gear.

    Add: MIDI connector adapter, synthesizer.

  • Check a small screen before soldering

    Send setup bytes over SPI to a tiny display and check that it lights up. Test it first and solder it after.

    Add: small SPI display.

  • Science fair light readings

    Ask a light sensor for readings at different times of day. Copy the numbers from the terminal into a chart.

    Add: light sensor board.

Expert ideas

  • Write your own mode

    Add a new command or protocol to the open firmware in C. Share it with the Bus Pirate forum.
