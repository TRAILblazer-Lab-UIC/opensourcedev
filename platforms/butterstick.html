Overview

ButterStick is a small FPGA development board made by Greg Davill. It pairs a Lattice ECP5-5G chip with 1 GB of memory, gigabit Ethernet, and fast USB over USB-C. Its full design is open and OSHWA certified. It suits experienced FPGA hobbyists who want fast network and USB projects.

Good fit or not?

Good for

  • Network and USB experiments in hardware

  • High-speed interface tests with the transceiver port

Not great for

  • Beginners, as it needs hardware languages such as Verilog
  • Quick buying, as known listings are sold out
  • Plug-and-play add-ons, as SYZYGY parts are less common than hobby headers
  • Wireless projects, as the board has no radio

Specs in plain words

  • An FPGA is a chip you rewire with code into almost any digital circuit.
  • 1 GB of DDR3L memory is large for an FPGA board and fits video buffers or a soft computer.
  • 128 Mbit of flash stores your design and some extra data.
  • Up to 82 I/O pins across three SYZYGY ports connect to add-on boards.
  • The board is 80 by 49 millimeters, about the size of a business card.
  • 5 Gbps lanes move data faster than a typical USB 3 port.

Values are for the ButterStick-r1.0-8G-85F, the configuration sold in the GroupGets campaign. The 2G variants have 256 MB DDR3L. The 25F variant has only 2 SERDES lanes and drops two SYZYGY C pins. ram_kb is the 1 GB DDR3L. flash_kb is the 128 Mbit QSPI flash for bitstreams and user data. clock_mhz is the 30 MHz oscillator in the README. The campaign page says 60 MHz. A 25 MHz oscillator drives the RGMII PHY. gpio is the campaign figure of up to 82 I/O across the three SYZYGY ports. VCCIO is adjustable from 1.2 to 3.3 V. JTAG is a 0.1 inch connector, recorded as swd_jtag. USB uses an external High Speed PHY.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blink the RGB LEDs

    Build the official blink example and flash it over USB with no programmer. It is the classic first FPGA project.

  • Button light show

    Design logic that plays a new color pattern on the seven LEDs each time you press a button. It teaches counters and state machines.

Expert ideas

  • Soft RISC-V computer

    Use LiteX to build a small RISC-V processor inside the FPGA. Run C programs on a computer you designed yourself.

  • Wired network packet counter

    Count network packets passing through the Ethernet port. Show the busiest moments on the LEDs.

    Uses: Wired network. Add: network cable.

  • Tiny web server in hardware

    Run a LiteX system with Ethernet and serve a simple status page. Check it from any computer on your network.

    Uses: Wired network. Add: network cable.

  • Custom USB gadget

    Build a USB device in gateware that shows up as a keyboard or serial port. Learn how USB talks at full speed.

  • Logic analyzer for other boards

    Turn the board into a fast logic analyzer through a SYZYGY breakout. Watch signals from other gadgets on your computer.

    Add: SYZYGY breakout board, jumper wires.

  • Retro video game console

    Build a soft game console with video output through a SYZYGY add-on. Recreate a classic arcade game.

    Add: SYZYGY video output board, monitor, game controller.

  • Audio synthesizer

    Design a sound synthesizer in hardware and play notes through an audio add-on. Each button can be a different instrument.

    Add: audio output board, small speaker.

  • High-speed link experiments

    Use the 5 Gbps transceiver lanes to send data between two boards. It is a deep dive into fast serial links.

    Add: second ButterStick, SYZYGY transceiver cable.

  • SD card data recorder

    Save sensor readings to the microSD card from a soft processor. Read the file later on a laptop.

    Add: microSD card, sensor breakout board.

  • Build your own board from files

    Order the bare circuit board or the open Gerbers and assemble a ButterStick yourself. It is a serious lesson in fine-pitch soldering.

    Add: bare circuit board, reflow oven, solder paste.

The full KiCad design, Gerbers, and parts list are published under CERN OHL v1.2. OSHWA lists the board as AU000016. The bootloader and examples are BSD-2-Clause, and the toolchain is fully open. The ECP5 chip itself is closed silicon.
