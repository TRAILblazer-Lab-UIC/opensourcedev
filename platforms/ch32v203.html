CH32V203

WCH (Nanjing Qinheng Microelectronics)

A fast, low-cost RISC-V chip with two USB ports.

Field marks: This RISC-V chip costs about as much as a coffee, runs at 144 MHz, and copies the STM32F103 closely enough to move into Blue Pill clones unannounced.

Overview

The CH32V203 is a fast, low-cost 32-bit chip from WCH. It uses the open RISC-V instruction set and runs up to 144 MHz. Its parts list echoes the popular STM32F103, and it often fills Blue Pill style boards. Adafruit sells it on the tiny QT Py board for under five dollars.

How the scores work

Good fit or not?

Good for

  • USB gadgets such as keyboards, MIDI devices, and adapters
  • Reading USB devices with its second USB port
  • Plug-in sensor projects on boards with STEMMA QT
  • Motor control and fast timing jobs
  • Learning RISC-V on a very cheap board

Not great for

  • Wireless projects, as the chip has no radio
  • Python users, as CircuitPython and MicroPython do not run on it
  • Complete beginners, with thin and early Arduino support
  • Large programs, which slow down past the fast part of flash

Specs in plain words

  • 144 MHz is quick for a small chip. It can juggle a few jobs at once.
  • 64 KB of fast flash holds a program of a few thousand lines.
  • 20 KB of working memory fits a small screen buffer or a batch of sensor readings.
  • Two USB ports let it act as a USB gadget and also talk to other USB devices.
  • CAN is the wiring language of cars and machines. Add a small module to listen in.
  • Standby uses half a microamp. Batteries last a long time on a sleeping board.

Chip values are for the LQFP48 CH32V203C8T6 used on the WCH EVT and WeAct BluePill Plus, per the openwch README and datasheet V3.0. The G6 part on the Adafruit QT Py and Phyx LANA TNY has 32 KB of fast flash, 224 KB of slower flash and 10 KB of SRAM. The datasheet says all parts carry 224 KB of code flash split into a zero-wait area and a slower area. Larger RB parts reach 64 KB of SRAM and 16 ADC inputs. Connectors and onboard parts describe the QT Py CH32V203, which has USB-C, STEMMA QT, a NeoPixel, and reset and boot buttons. The RV32IMAC subset comes from the wagiminator board README. Debug uses WCH's two-wire SDI on PA13 and PA14.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Rainbow LED blinker

    Make the onboard color LED cycle through a rainbow. It is a quick first test of your setup.

  • Custom macro keypad

    Wire a few keys and make the board act as a USB keyboard. Each key types a shortcut or a whole phrase.

    Add: mechanical key switches, keycaps.

  • E-ink desk calendar

    Drive a small e-paper screen that shows the date and time. Adafruit has a full guide for this build.

    Uses: Sips power. Add: e-paper screen, real-time clock module.

  • Plug-in sensor station

    Snap a temperature sensor onto the STEMMA QT port with no soldering. Readings stream to your computer over USB.

    Uses: Plug-in connectors. Add: STEMMA QT temperature sensor, STEMMA QT cable.

  • Touch pad music box

    Use the touch-key inputs on copper pads. Each pad plays a different note on a buzzer.

    Add: copper tape, piezo buzzer.

  • Weather logger for the window

    Read a pressure and humidity sensor every few minutes. Save the readings and graph the week in a spreadsheet.

    Uses: Plug-in connectors, Sips power. Add: STEMMA QT pressure and humidity sensor, SD card module.

Expert ideas

  • USB MIDI chiptune instrument

    Turn the board into a USB MIDI device that plays retro beeps. The open beepmidi project shows the way.

    Add: small speaker, transistor.

  • Old keyboard to new tricks

    Use the USB host port to read a USB keyboard. The board can remap keys or log typing practice.

    Uses: Plugs in USB gadgets. Add: USB-A socket breakout, USB keyboard.

  • Homemade debug probe

    Load the open DAPLink port onto a board. It becomes a tool for programming other chips.

    Add: jumper wires.

  • Robot motor controller

    Drive two motors with a driver board and read wheel sensors. The fast core keeps the robot on a straight path.

    Add: motor driver, small DC motors, wheel encoders, battery pack.

  • Car and machine CAN listener

    Add a CAN transceiver and watch messages on a test bench network. It is a hands-on way to learn how machines talk.

    Add: CAN transceiver module.

  • Game controller adapter

    Read an old game pad and send its buttons to a computer as a USB device. Retro games get a classic feel.

    Add: old game pad, connector socket.

Openness level

Level 3 of 3. Wild Open shares the most.

Adafruit publishes the QT Py design files under CC BY-SA 3.0, and the board is certified open hardware by OSHWA. The Phyx LANA TNY is also certified, and its files use the MIT license. The ch32fun SDK is MIT, and Zephyr and the Rust support use Apache-2.0. The RISC-V instruction set is open, but WCH keeps the chip's core design closed.
