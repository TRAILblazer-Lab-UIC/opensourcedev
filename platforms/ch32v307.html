CH32V307

WCH (Nanjing Qinheng Microelectronics)

A fast, low-cost RISC-V chip with wired network and high-speed USB built in.

Field marks: Look for a blue evaluation board with a network jack, two USB-C ports and a row of eight serial headers, like a hub that forgot to stop growing.

Overview

The CH32V307 is a 32-bit RISC-V microcontroller from WCH. It runs at up to 144 MHz and has a math unit for decimal numbers. It stands out for its wired network port and high-speed USB at a very low price. It suits hobbyists who already know some C and want a cheap step up from simpler boards.

Good fit or not?

Good for

  • Gadgets that talk over a wired network
  • Projects that juggle many serial devices at once
  • Fast USB gadgets and USB host projects
  • Learning RISC-V on a cheap evaluation board
  • Robots and vehicles that use a CAN bus

Not great for

  • Wireless projects, with no Wi-Fi or Bluetooth on board
  • First-time coders who want a guided path
  • Shields that expect 5 volt pins on its 3.3 volt headers
  • Python fans, with tools limited to C, Arduino and Rust

Specs in plain words

  • A 144 MHz clock means it does roughly 144 million small steps each second.
  • 64 KB of working memory holds a few thousand sensor readings at once.
  • 256 KB of program storage fits large programs with room for a small web page.
  • The network port links the board to a home router with a plain cable.
  • High-speed USB moves data about forty times faster than the slower USB port.
  • Up to 80 pins give you plenty of spots for buttons, lights and sensors.

Chip values come from the openwch README. The 64 KB SRAM and 256 KB flash are the default split. Zephyr lists 480 KiB of total flash and RAM options from 32 to 192 KiB. As a result, the split is configurable. GPIO is 80 on the LQFP100 CH32V307VCT6. The CH32V317 variant has 70 I/O and a 10/100 PHY. The lcd entry reflects the FSMC parallel bus, which can drive parallel LCDs. Programming uses WCH's serial 2-wire debug interface (SDI/SWIO), which is not standard SWD or JTAG. Connectors and onboard parts are for the WCH CH32V307V-EVT-R1. Its dimensions were not found. Standby current was not read in the datasheet.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Network blinky light

    Turn an LED on and off from a web page on your home network. It is a friendly first test of the wired network port.

    Uses: Wired network. Add: network cable, LED.

  • Classroom weather station

    Read temperature and humidity and serve the numbers over the school network. Anyone on the network can check the readings.

    Uses: Wired network. Add: temperature and humidity sensor, network cable.

  • Greenhouse watering controller

    Check soil moisture and switch a small pump on for a set time. Log each watering to a computer on the network.

    Uses: Wired network. Add: soil moisture sensor, small water pump, relay module.

  • Garden status screen

    Show soil, light, and temperature readings on a small color screen by the back door. You can see the garden mood at a glance.

    Uses: Screen. Add: small color screen, soil moisture sensor, light sensor.

  • Simple tone synthesizer

    Play notes on a speaker from a row of touch pads. The built-in sound outputs make smooth tones for a music class.

    Uses: Makes sound. Add: small speaker, amplifier board, copper tape.

  • Sound level meter

    Measure how loud a room is with a microphone and show it on a bar of LEDs. Classrooms can watch the noise level live.

    Uses: Hears sound. Add: microphone module, LED strip.

  • Science lab data recorder

    Sample several sensors many times a second and stream the numbers to a laptop over USB. Students can graph the results in a spreadsheet.

    Add: light sensor, temperature sensor.

Expert ideas

  • Serial ports over the network

    Connect up to eight old serial gadgets and reach each one through a network cable. Lab gear and old printers get a new life.

    Uses: Wired network. Add: network cable, serial adapter cables.

  • Bird feeder snapshot camera

    Grab still pictures from a small camera module pointed at a feeder. Save them to a memory card for later bird spotting.

    Uses: Camera. Add: small camera module, microSD card.

  • USB keyboard to network bridge

    Plug a USB keyboard into the board and send each key press to another computer over the network. It makes a handy remote control.

    Uses: Plugs in USB gadgets, Wired network. Add: USB keyboard, network cable.

  • USB flash drive data logger

    Write sensor readings to a USB flash drive plugged straight into the board. Pull the drive out and open the file on any computer.

    Uses: Plugs in USB gadgets. Add: USB flash drive, temperature sensor.

  • Retro game console

    Draw a simple block game on a parallel color screen and play it with buttons. The fast chip keeps the screen moving smoothly.

    Uses: Screen. Add: parallel color screen, push buttons, small speaker.

  • Car and robot CAN listener

    Read messages from a CAN bus in a robot kit or a hobby vehicle. Print each message on your computer to learn how the parts talk.

    Add: CAN transceiver board.

  • Motor control for a small robot

    Drive two motors and read wheel speed sensors to keep a robot rolling straight. The hardware math unit handles the steering sums.

    Add: motor driver board, two small motors with encoders, battery pack.

WCH publishes the evaluation board design files on GitHub, but the repo has no license file. Code can be written and flashed with open tools such as the MIT licensed ch32fun SDK, Zephyr and the Apache licensed Rust HAL. The chip core design stays closed.
