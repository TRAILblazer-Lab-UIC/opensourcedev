Overview

The CH570 is a tiny RISC-V microcontroller from WCH. WCH calls it the cheapest chip of its kind, at about ten cents. It has a 2.4 GHz radio and a USB port that can act as a host or a device. It suits makers who already know some C and want very cheap wireless gadgets.

How the scores work

Good fit or not?

Good for

  • Wireless mice, keyboards, and USB dongles
  • Tiny battery sensors that sleep most of the time
  • Very cheap projects that need a radio and USB
  • Learning low-level RISC-V programming

Not great for

  • Beginners who want Arduino or Python
  • Projects with many sensors, a screen, or big programs
  • Analog sensors. The chip has no true ADC.
  • Phone apps. The plain CH570 has no Bluetooth.

Specs in plain words

  • A 100 MHz processor is quick enough for one simple job at a time.
  • 12 KB of memory is very small. It holds a short list of readings and little else.
  • 240 KB of flash stores your program. That is room for a modest C program.
  • The 2.4 GHz radio talks to another CH570 board. The CH572 twin adds Bluetooth LE 5.0 for phones.
  • Sleep current starts at 0.46 microamps. A coin cell can last a very long time on that.
  • The QFN20 version has 12 pins for buttons, lights, and sensors. The smallest versions have only 3 or 5.

Values are for the QFN20 CH570D and CH572D. The DFN10 CH570Q has 5 GPIO and the SOP8 CH570E has 3. The CH570 radio is a proprietary 2.4 GHz GFSK mode, which the radios list cannot express. As a result, radios is left empty. The CH572 adds BLE 5.0. There is no true ADC. A comparator with a 16-step reference acts like a 4-bit ADC. As a result, adc_channels is 0. Flash is user code flash. Total flash is 256 KB including the bootloader and info areas. Connectors and onboard parts are for the MuseLab nanoCH57x. Its size was not published. Debug uses WCH's 2-wire SWD-like interface on PA0 and PA1.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink the user LED

    Flash a short C program that blinks the LED on a small dev board. It proves your tools and board work.

  • Motion night light

    Turn on a few LEDs for a minute after someone walks by. It lights a dark hallway at night.

    Add: motion sensor, small LEDs.

Builder ideas

  • USB macro keypad

    Build a few buttons that act like a USB keyboard. Each button can type a shortcut or a whole phrase.

    Add: push buttons.

  • USB MIDI foot pedal

    Make a pedal that tells music software to start, stop, or change sounds. Your hands stay on your instrument.

    Add: foot switch.

  • Wireless doorbell button

    Pair two boards over the 2.4 GHz radio. One button press makes a buzzer sound across the house.

    Uses: Sips power. Add: push button, coin cell holder, buzzer.

  • Classroom quiz buzzers

    Give each team a radio button and a light. A base board shows which team pressed first.

    Add: push buttons, LEDs.

  • Door open alert

    Send a radio message each time a door or gate opens. The chip sleeps on tiny power the rest of the time.

    Uses: Sips power. Add: reed switch, magnet, battery holder.

  • Garden temperature sender

    Read a digital temperature sensor every few minutes and radio the value indoors. A coin cell can run it for a long time.

    Uses: Sips power. Add: digital temperature sensor, battery holder.

  • Tiny Bluetooth beacon

    Use the CH572 twin to broadcast a Bluetooth signal that phones can see. Tag a room, a bag, or a bike.

    Uses: Sips power. Add: coin cell holder.

Expert ideas

  • Homemade wireless mouse

    Combine a mouse sensor, buttons, and the fast 2.4 GHz radio. A second board plugs into the computer as the receiver.

    Add: optical mouse sensor, push buttons, battery holder.

  • USB keyboard radio bridge

    Plug an old USB keyboard into the board's host port. The board sends each key press over the radio to another computer.

    Uses: Plugs in USB gadgets.

  • Raw radio experiments

    Use the community iSLER project to send and receive raw radio frames. It skips WCH's closed radio library.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseNot confirmed
  • Coding toolsMostly open
  • The chip itselfClosed chip design

WCH publishes schematic and PCB files for its evaluation boards in its GitHub repo. The repo carries an Apache-2.0 license. Its reach over the board files is unclear. The SDK is Apache-2.0, and the ch32fun toolkit is MIT. The radio and Bluetooth stacks ship as closed libraries, and the chip design itself is closed.
