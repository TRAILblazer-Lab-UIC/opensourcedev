Overview

The Colorlight i9 began life as a receiver card for LED video walls. Hobbyists found a mid-size Lattice ECP5 FPGA, 8 MB of memory, and two gigabit Ethernet chips on it. The community mapped its pins and built an extension board with a programmer and HDMI. It suits people who want to learn FPGA design with fully open tools.

Specs in plain words

  • The ECP5 45F is a mid-size FPGA. It is a chip you rewire with code to build your own circuits.
  • 8 MB of memory holds a small soft processor's programs and data.
  • 8 MB of flash stores your FPGA design. The board loads it at power-up.
  • Two gigabit Ethernet ports move data as fast as a good home network.
  • The 200-pin edge connector looks like a laptop memory stick. It needs a carrier board to use.
  • The extension board's HDMI port sends video out only.

Values are for the i9 v7.2 module per the wuxx repo. clock_mhz is the 25 MHz oscillator on pin P3. ram_kb is the M12L64322A 8 MB SDRAM. Flash_kb is the W25Q64JVSIQ 8 MB SPI flash. The 45F logic size (LUTs, block RAM, multipliers) was not read from the Lattice datasheet in this pass. gpio is left null: Tom Verbeure counts 106 GPIOs on the SODIMM for the i5, and the i9 shares that pinout, but no i9 count was published. HDMI, UART (via the DAPLink) and the expansion headers live on the Muse Lab extension board. It is not the module. The extension board USB connector type was not confirmed. v7.1 and v7.2 share the same GPIO layout. The i9plus is a different Artix-7 card.

Starter ideas

Builder ideas

  • Hello from a serial port

    Build a design that sends a message to your computer through the extension board's programmer. Watch it appear in a terminal.

    Add: extension board.

  • HDMI test pattern

    Make swirling patterns that change with time and show them on a big screen. It makes a lively gallery or party display.

    Uses: Screen. Add: extension board, monitor, HDMI cable.

Expert ideas

  • Network scoreboard for gym class

    Send scores from a laptop over Ethernet and show them on a monitor. Everyone in the gym can follow the game.

    Uses: Wired network, Screen. Add: extension board, monitor, network cable.

  • Build your own RISC-V computer

    Use LiteX to build a small RISC-V processor inside the FPGA with memory and Ethernet. Then run C programs on the computer you made.

    Add: extension board.

  • Retro game console

    Recreate a simple classic game system in logic and play it on a monitor. It teaches how old consoles worked.

    Uses: Screen. Add: extension board, monitor, game controller.

  • Gigabit packet counter

    Count and sort network traffic at full gigabit speed. It shows how busy a home network really is.

    Uses: Wired network. Add: extension board, network cables.

  • Audio over Ethernet

    Send and receive studio audio over a network cable with a community AES67 design. Link speakers and mixers across a room.

    Uses: Wired network. Add: extension board, audio codec board, network cable.

  • Tempo sync box for musicians

    Join an Ableton Link session over the network. Keep drum machines and laptops on the same beat.

    Uses: Wired network. Add: extension board, network cable.

  • Fast science data logger

    Sample a sensor millions of times per second and stream the data over Ethernet. A laptop saves it for later study.

    Uses: Wired network. Add: extension board, fast analog-to-digital converter board, network cable.

  • Logic analyzer for other gadgets

    Watch the signals on another board's pins and send them to your computer. It helps you find wiring bugs.

    Add: extension board, jumper wires.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansSchematics only
  • Hardware licenseNot confirmed
  • Coding toolsFully open
  • The chip itselfClosed chip design

The i9 module is a closed commercial card with no published schematic. The community reverse-engineered its pinout. The extension board schematic is a PDF under Apache-2.0. The whole toolchain is open, including Yosys, nextpnr, and LiteX. The ECP5 chip itself is closed.

Hardware license: none for the Colorlight module, the community repo (pinout docs and extension-board schematic PDF) is Apache-2.0 · Software license: Apache-2.0 (wuxx/Colorlight-FPGA-Projects), ISC (Yosys, nextpnr), BSD-2-Clause (LiteX)
