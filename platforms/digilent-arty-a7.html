Overview

The Arty A7 is an FPGA board from Digilent built around an AMD Artix-7 chip. An FPGA is a chip you rewire with code to become almost any digital circuit. Digilent paired it with lots of memory and an Ethernet jack. It suits students and engineers who want to build soft processors and network projects.

Good fit or not?

Good for

  • Building soft processors such as MicroBlaze or RISC-V cores
  • Running Linux on a processor you assembled yourself
  • Wired network experiments over Ethernet
  • Learning Verilog or VHDL on a roomy chip
  • Trying the open openXC7 toolchain

Not great for

  • Complete beginners, as it needs hardware languages
  • Wireless projects, as it has no radio
  • Small budgets, as it costs about 300 US dollars
  • Classic 5 V Arduino shields, as they can damage the chip

Specs in plain words

  • About 63,000 lookup tables is room for a full soft processor plus many extra circuits.
  • 256 MB of memory gives a soft processor enough room to run a small Linux.
  • 16 MB of flash keeps your design stored after the power goes off.
  • A 100 MHz clock ticks one hundred million times each second.
  • Four Pmod ports and Arduino-style headers take plug-in add-ons and sensors.
  • One micro-USB cable handles power, uploads, and a serial link to your computer.

Values are for the current Arty A7-100T. The retired Arty A7-35T used an XC7A35TICSG324-1L with 5,200 slices, 1,800 Kbit block RAM, 90 DSP slices and 5 CMTs. The 100T has 15,850 slices (four 6-input LUTs and eight flip-flops per slice. As a result, about 63,400 LUTs), 126,800 flip-flops, 4,860 Kbit (607.5 KB) block RAM, 240 DSP slices and 6 CMTs. clock_mhz is the onboard 100 MHz crystal oscillator. The fabric runs internal clocks above 450 MHz. ram_kb is the 256 MB DDR3L (16-bit at 667 MHz). gpio 81 is 32 Pmod signals (4 x 8) plus 49 shield I/O pins. adc_channels 12 counts the XADC shield inputs A0 to A5 (single-ended, 0 to 3.3 V) and A6 to A11 (differential), plus a dedicated V_P/V_N pair not counted. Shield pins are 3.3 V only. 5 V shields can damage the FPGA. Ethernet is a 10/100 PHY, listed under radios as ethernet. The board also has a USB-JTAG/UART FT2232 bridge, a DA9062 PMIC and an RJ45 jack. Board dimensions were not found in the manual text read.

Things you could build

15 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink and fade the RGB lights

    Write a small Verilog design that fades the four color lights. It is the classic first step on any FPGA.

  • Switch and button logic lab

    Turn the slide switches and buttons into inputs for logic gates you design. Watch the LEDs show each result.

  • Hello over the serial port

    Build a serial sender in hardware and send a greeting over the USB cable. Read it in a terminal on your computer.

Builder ideas

  • Reaction time game

    Light a random LED and time how fast a friend hits the button. Send each score to your computer.

  • Build a MicroBlaze computer

    Add the MicroBlaze soft processor in Vivado and run C programs on it. The board memory gives it plenty of room.

  • Garden soil monitor

    Read a soil moisture sensor through the analog inputs. Post the numbers to a computer on your home network.

    Uses: Wired network. Add: soil moisture sensor, jumper wires.

  • Tone and melody player

    Make square wave tones and play a tune through a small speaker. Each button can play a different note.

    Add: small speaker, small amplifier board.

  • Servo sweep controller

    Make a precise pulse signal that swings a servo back and forth. Use it to wave a flag or aim a little sign.

    Add: servo motor, jumper wires.

  • Frequency counter for science class

    Measure how fast a signal flips on and off. Test a buzzer, a fan sensor, or a signal generator.

    Add: jumper wires.

  • Try the fully open toolchain

    Build the openXC7 blinky demo with Yosys and nextpnr. Load it with openFPGALoader and skip Vivado for small designs.

Expert ideas

  • Network status light

    Put a small web page on the board over the Ethernet jack. Click a button on the page to change the RGB lights.

    Uses: Wired network. Add: Ethernet cable.

  • Classroom sensor logger

    Read a light or temperature sensor on the analog pins. Send the readings across the school network every minute.

    Uses: Wired network. Add: temperature sensor, jumper wires.

  • Boot Linux on a soft CPU

    Use LiteX to build a RISC-V system with the board memory. Then boot a small Linux and log in over serial.

  • Video game on a monitor

    Add a video output module to a Pmod port and draw a Pong game in pure logic. Play it with the board buttons.

    Add: VGA plug-in module, monitor.

  • Logic analyzer for the workbench

    Capture fast signals on the Pmod pins and send them to your computer. It helps you debug other projects.

    Add: jumper wires.

Key terms on this page

CPU
The CPU is the main chip part that runs program steps.
Digital
A digital signal has only two states, on or off.
Ethernet
Ethernet is wired networking through a network cable.
FPGA
An FPGA is a chip whose wiring you can rearrange with code.
Hardware description language
A hardware description language is code that describes a circuit.
LED
An LED is a small light that turns on with very little power.
Open hardware
Open hardware is a physical device whose design files are public.
Pin header
A pin header is a row of metal pins or sockets on a board.
Repository
A repository is an online folder that holds a project's files and their full history.
RISC-V
RISC-V is a free and open set of rules for how a processor works.
Shield
A shield is an add-on board that stacks on top of an Arduino-shaped board.

A toolchain is the set of programs that turn your code into firmware.
