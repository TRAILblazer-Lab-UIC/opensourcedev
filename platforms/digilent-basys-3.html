Overview

The Basys 3 is a classroom FPGA board from Digilent built around an AMD Artix-7 chip. An FPGA is a chip you rewire with code to become almost any digital circuit. Sixteen switches, sixteen lights, five buttons, and a number display all sit on the board. It suits students in a first digital logic course and their teachers.

Good fit or not?

Good for

  • Digital logic labs with no breadboard needed
  • Learning Verilog or VHDL step by step
  • Drawing simple graphics on a VGA monitor
  • Building a small processor as a class project

Not great for

  • Complete beginners without a course or a guide
  • Wireless or network projects, as it has no radio or Ethernet
  • Big soft processors, as it has no extra memory chip
  • Reading many analog sensors, as it has few analog pins

Specs in plain words

  • 33,280 logic cells is room for a simple processor and a video circuit together.
  • 225 KB of memory inside the chip holds small programs and a little screen data.
  • A 100 MHz clock ticks one hundred million times each second.
  • The four-digit display shows numbers like a microwave oven clock.
  • The VGA port connects to an older style computer monitor.
  • One micro-USB cable handles power, uploads, and a serial link to your computer.

Specs from the Basys 3 reference manual (rev C board, revised July 10 2019). The FPGA has 5,200 slices (four 6-input LUTs and eight flip-flops each), 1,800 Kbit block RAM, 5 CMTs, 90 DSP slices and an XADC. There is no external RAM. Ram_kb 225 is the FPGA block RAM (1,800 Kbit). flash_kb is the 32 Mbit Quad-SPI configuration flash. clock_mhz is the single 100 MHz oscillator. gpio 32 counts three 8-signal Pmod ports plus the 8-signal XADC Pmod. adc_channels 4 assumes four XADC analog pairs on the XADC Pmod (not confirmed in the text read). display stands for the 4-digit seven-segment display. There is no graphic screen. The 12-bit VGA port has no matching vocabulary value. The 16 user LEDs are single-color. usb_host is the HID host port (USB-A) driven by an auxiliary microcontroller. Power is switched by SW16, with an LTC3633 regulator.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Light up a switch

    Connect each slide switch to the LED above it in Verilog. It is the first lab in many digital logic classes.

  • Logic gate playground

    Build AND, OR and XOR gates from the switches and watch the LEDs answer. Students can check truth tables by hand.

  • Button counter on the display

    Count button presses on the four-digit number display. It teaches counters and how to clean up bouncy buttons.

    Uses: Screen.

  • Binary to decimal converter

    Set a number on the switches in binary. Show the same number in everyday digits on the display.

    Uses: Screen.

Builder ideas

  • Stopwatch and kitchen timer

    Build a timer that counts minutes and seconds on the display. Use the buttons to start, stop, and reset it.

    Uses: Screen.

  • Reaction time game

    Light a random LED and time how fast a player hits the button. Show the score in milliseconds on the display.

    Uses: Screen.

  • Traffic light controller

    Design a state machine that runs a pretend crossroads on the LEDs. A button can act as the walk signal.

  • Color bars on a monitor

    Drive the VGA port to draw color bars and moving shapes. It shows how screens are drawn line by line.

    Add: VGA monitor, VGA cable.

  • Tone and melody player

    Make square wave tones on a Pmod pin and play a tune through a small speaker. Each switch can pick a note.

    Add: small speaker, small amplifier board.

  • Light meter for science class

    Read a light sensor on the analog Pmod. Show the brightness as a number on the display.

    Uses: Screen. Add: light sensor, jumper wires.

Expert ideas

  • Pong on a big screen

    Build the classic Pong game fully in logic on a VGA monitor. Play it with the board buttons.

    Add: VGA monitor, VGA cable.

  • Keyboard typing display

    Plug a USB keyboard into the host port. Show each typed letter on a VGA screen.

    Uses: Plugs in USB gadgets. Add: USB keyboard, VGA monitor.

  • Mouse paint program

    Plug in a USB mouse and draw on a VGA screen. Use the switches to pick the color.

    Uses: Plugs in USB gadgets. Add: USB mouse, VGA monitor.

  • Build a tiny processor

    Design a simple CPU in Verilog and run a short program on it. Watch its registers on the LEDs and display.

How open is it?

Open Board

Digilent publishes a PDF schematic and MIT-licensed constraint files. The board layout stays closed, and no open hardware license is stated. The Artix-7 chip is proprietary, but open tools such as openXC7 and openFPGALoader can build and load simple designs.
