Overview

The Nexys A7 is a teaching board from Digilent built around an AMD Artix-7 FPGA. An FPGA is a chip you rewire with code to become almost any digital circuit. Around it sit memory, a network port, a microphone, sensors, switches, lights and a number display. It suits engineering students and teachers who want one board for a whole course, from logic gates to homemade processors. It is the same board once sold as the Nexys 4 DDR.

Good fit or not?

Good for

  • University and advanced high school courses in digital logic
  • Building soft processors that use real memory
  • Projects with sound, sensors and a VGA screen on one board
  • Trying open FPGA tools on a well-known board

Not great for

  • Complete beginners, as it needs hardware languages such as Verilog
  • Tight budgets, as it costs a few hundred dollars
  • Wireless projects, as it has no radio
  • Quick setup, as the Vivado tools are a very large download

Specs in plain words

  • About 63 thousand logic cells is room for a full soft processor plus many extra circuits.
  • 128 MB of memory gives a soft processor space to run real programs.
  • 16 MB of flash stores your design and keeps it after power off.
  • Sixteen switches, sixteen LEDs and an eight-digit display let you test ideas without extra parts.
  • Four Pmod ports take plug-in add-ons such as extra sensors or displays.
  • One USB cable powers the board, loads designs and gives a serial link to your computer.

Specs from the Nexys A7 reference manual (Digilent wiki export dated 12/25/2018, university mirror). Values are for the more common Nexys A7-100T. ram_kb is the external 1 Gib (128 MiB) DDR2. flash_kb is the 128 Mib (16 MiB) Quad-SPI configuration flash. clock_mhz is the single 100 MHz crystal oscillator. The manual lists block RAM as 1,188 Kb (100T) and 600 Kb (50T), which disagrees with AMD's usual 4,860 Kb figure for the XC7A100T. This was not resolved. gpio 32 counts the four 8-signal Pmod ports. The XADC Pmod adds analog-capable pins. The XADC is dual-channel 1 MSPS, and the number of analog pairs on the Pmod was not confirmed. As a result, adc_channels is null. display stands for the eight-digit seven-segment display. There is no graphic screen. imu is the 3-axis accelerometer. The 12-bit VGA port has no vocabulary value. usb_micro for the shared UART/JTAG port is assumed from the Nexys family and was not confirmed in the text read. The audio connector is the PWM mono output. The out-of-box demo draws about 400 mA at 5 V.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Switches and lights logic lab

    Connect the sixteen switches to the sixteen LEDs through gates you design. Students see logic rules come alive.

  • Seven segment stopwatch

    Build a stopwatch on the eight-digit display with buttons for start and reset. It teaches counters and clocks.

    Uses: Screen.

Builder ideas

  • Traffic light controller

    Use the two color LEDs as traffic lights and a button as the walk signal. It is a classic school project in timing logic.

  • Digital room thermometer

    Read the built-in temperature sensor and show the result on the number display. Watch the room warm up through the day.

    Uses: Sensors built in, Screen.

  • Shake detector for science class

    Watch the built-in motion sensor and light LEDs for small and big shakes. Students can test pretend earthquakes on a desk.

    Uses: Sensors built in.

  • Clap and voice level meter

    Read the built-in microphone and light more LEDs as sound gets louder. Find the noisiest spot in the classroom.

    Uses: Hears sound.

  • Switch keyboard synthesizer

    Give each switch its own musical note and play tones through the audio jack. Build a simple instrument from pure logic.

    Uses: Makes sound. Add: headphones or a small powered speaker.

  • USB keyboard typing game

    Plug a USB keyboard into the board and show typed letters on the display. Turn it into a speed typing challenge.

    Uses: Plugs in USB gadgets, Screen. Add: USB keyboard.

Expert ideas

  • Pong on a VGA monitor

    Draw the classic Pong game on an old monitor through the VGA port. Play it with the board buttons.

    Add: VGA monitor, VGA cable.

  • Tilt maze game

    Tilt the board to roll a ball through a maze drawn on a VGA monitor. The motion sensor steers the ball.

    Uses: Sensors built in. Add: VGA monitor, VGA cable.

  • Echo and voice effects box

    Record sound from the microphone and play it back with an echo or a robot voice. It is a fun lesson in digital audio.

    Uses: Hears sound, Makes sound. Add: headphones or a small powered speaker.

  • Build your own computer

    Load a MicroBlaze or RISC-V soft processor that uses the board's memory. Then run your own C programs on it.

  • Network temperature reporter

    Run a soft processor that sends temperature readings over the wired network. A computer down the hall can log them.

    Uses: Wired network, Sensors built in. Add: network cable.

  • Sensor data logger

    Save temperature and motion readings to a microSD card for a long experiment. Open the file later on a computer.

    Uses: Sensors built in. Add: microSD card.

How open is it?

Open Board

Digilent publishes PDF schematics, and its constraint files use the MIT license. Layout files are unpublished, and the hardware has no open license. Simple designs can be built and loaded with open tools such as F4PGA and openFPGALoader, but the Artix-7 chip itself is closed.

Hardware license: none stated (schematic marked Copyright 2018 Digilent Inc.) · Software license: MIT (Digilent XDC constraint files), Apache-2.0 (F4PGA examples, openFPGALoader)
