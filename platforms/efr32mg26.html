Overview

The EFR32MG26 is a wireless chip from Silicon Labs for smart home devices. It speaks Matter, Thread, Zigbee, and Bluetooth. It has double the memory of the MG24 and a small math engine for machine learning. Today it suits experienced builders who are comfortable with C and vendor tools.

  • Wi-Fi projects, with no Wi-Fi radio
  • Cheap tinkering, with kits starting around 35 dollars
  • Cameras or big screens

Specs in plain words

  • 512 KB of memory gives Matter room to run alongside your own code.
  • Up to 3200 KB of flash holds the firmware plus a spare copy for wireless updates.
  • A 78 MHz processor is plenty for sensors, radios, and light math.
  • The Matrix Vector Processor speeds up tiny machine learning models on select parts.
  • Deep sleep draws about 1.4 millionths of an amp. A coin cell can last a long time.
  • A built-in segment LCD driver runs simple number displays like those on a thermostat.

Chip values come from the CNX Software availability article, which lists the data sheet figures. Flash and RAM are the top options. Zephyr lists the Explorer Kit chip as the EFR32MG26B510F3200IM48 with 3200 KB and 512 KB. CNX listed 1536 KB and 256 KB for the kit chips, which conflicts with Zephyr. GPIO is the maximum across packages. The QFN48 parts expose fewer pins. The 1.4 µA figure is EM2 with 16 KB RAM retention and the RTC on LFRCO. Connectors and onboard parts are for the xG26 Explorer Kit, with two LEDs, two buttons, mikroBUS and Qwiic. The chip has no native USB. The kits use an onboard J-Link debugger.

Things you could build

Builder ideas

  • Thread temperature sensor

    Report room temperature to your smart home over Thread. A coin cell keeps it running for a long time.

    Uses: Thread or Zigbee, Sips power. Add: temperature sensor, coin cell holder.

  • Zigbee door sensor

    Make a door sensor for a Zigbee hub. Get an alert each time the back door opens.

    Uses: Thread or Zigbee, Sips power. Add: magnetic door switch.

  • Bluetooth sensor to phone

    Stream readings from a plug-in sensor to a phone app over Bluetooth. It is a good first wireless test.

    Uses: Bluetooth, Plug-in connectors. Add: Qwiic sensor board.

  • Garden soil monitor

    Check soil moisture in garden beds and send it over a Thread mesh. Water only the beds that need it.

    Uses: Thread or Zigbee, Mesh messaging, Sips power. Add: soil moisture sensor, weatherproof box, battery pack.

  • School weather station

    Log temperature, pressure, and humidity in the schoolyard. Send the data over Thread to a classroom computer.

    Uses: Thread or Zigbee, Sips power. Add: weather sensor board, weatherproof box.

  • Wearable activity tag

    Track steps or movement with a coin-cell tag. Read the totals on a phone over Bluetooth.

    Uses: Bluetooth, Sips power. Add: motion sensor, coin cell holder.

Expert ideas

  • Matter smart plug

    Build a plug controller that joins a Matter home over Thread. Switch a lamp from any major smart home app.

    Uses: Thread or Zigbee. Add: relay board, plug enclosure.

  • Segment display thermostat

    Drive a simple segment LCD that shows room temperature and a set point. Buttons raise or lower the target.

    Uses: Screen, Thread or Zigbee. Add: segment LCD panel, temperature sensor.

  • Wrist flick light switch

    Run a tiny machine learning model on motion data. A flick of the wrist turns the lights on.

    Uses: AI chip, Thread or Zigbee. Add: motion sensor.

  • Glass break listener

    Train a small sound model to spot breaking glass. Send an alert to your smart home hub.

    Uses: AI chip, Thread or Zigbee. Add: digital microphone.

  • Mesh light switch network

    Link several boards in a Bluetooth Mesh or Thread network. One switch controls lights across the building.

    Uses: Mesh messaging. Add: relay board, LED lamps.

  • Multiprotocol bridge

    Run Zigbee and Bluetooth on one chip at the same time. Let a phone set up a Zigbee device directly.

    Uses: Bluetooth, Thread or Zigbee.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 1 of 3. Wild Open shares the most.

  • Board plansNot confirmed
  • Hardware licenseNot confirmed
  • Coding toolsMostly open
  • The chip itselfClosed chip design

Code builds with free GCC tools through Zephyr under the Apache-2.0 license. The radio and protocol stacks ship as closed precompiled files under the Silicon Labs MSLA. No kit design files were found, and the chip itself is proprietary.

Software license: Simplicity SDK under the Silicon Labs MSLA with some Zlib parts, Zephyr is Apache-2.0
