Overview

The ESWIN EBC77 is a small single-board computer built around a RISC-V chip. It has four cores, a graphics chip, and an AI chip rated at 20 TOPS. Canonical makes an official Ubuntu 24.04 image for it. It suits developers who want to try RISC-V Linux and port software.

Good fit or not?

Good for

  • Trying RISC-V Linux on a small, affordable board
  • Porting and testing open-source software on a new processor family
  • Running small AI models on the built-in NPU
  • Home server jobs over Gigabit Ethernet

Not great for

  • First-time users, who face a serial console and the U-Boot shell during setup
  • Owners who want the newest Ubuntu releases, which target a newer RISC-V profile
  • Buyers on a tight budget, as reviewers found it pricey next to a Raspberry Pi 5
  • Projects that need open board files

Specs in plain words

  • Four SiFive P550 cores at 1.8 GHz give everyday desktop and server speed for light work.
  • The NPU rated at 20 TOPS can run small image and sound models much faster than the CPU alone.
  • LPDDR5 memory is fast working memory, but ESWIN does not list how much each model has.
  • Wi-Fi 5, Bluetooth, and Gigabit Ethernet cover wireless and wired networking.
  • The 40-pin header offers I2C, SPI, UART, I2S, and PWM for sensors and add-ons.
  • The board is 85 by 56 mm, about the size of a credit card.

The datasheet gives 64-bit LPDDR5 at 6400 MT/s but does not state the capacity. As a result, ram_kb is null. Press reports range up to 32 GB. There is no eMMC. The OS boots from microSD and the bootloader sits in 8 MB SPI NOR flash. USB is two USB 3.2 Gen1 Type-A and two USB 2.0 Type-A. A micro USB port carries the debug UART. The datasheet lists only Wi-Fi. By contrast, CNX Software names an AP6256 module with Bluetooth 5.0. The fan header is a 4-pin 1.0 mm PWM connector. The board has reset and force-recovery keys and an RTC with a VBAT connector.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 1 of 3. Wild Open shares the most.

  • Board plansNot published
  • Hardware licenseNot confirmed
  • Coding toolsMostly open
  • The chip itselfClosed chip design

The Linux kernel, U-Boot, and OpenSBI sources are public on GitHub under GPL-2.0 and BSD licenses. ESWIN shares a datasheet, a user guide, and a pinout. It has not published a schematic or board layout. The GPU user space, the NPU runtime, and the SiFive cores stay closed.

A GPU is a chip part built to do many small math jobs at once.

I2C is a simple way for chips to talk over two wires.
I2S
I2S is a way for chips to pass digital sound.
NPU
An NPU is a chip part made just for running AI models.
Open Board

PWM

Serial monitor
A serial monitor is a window that shows text sent from a board.
Single-board computer
A single-board computer is a full computer on one small board.
SPI
SPI is a fast way for chips to talk over four or more wires.
TOPS
TOPS stands for trillion operations per second.
UART
UART is a simple way for two devices to send text and data over two wires.
