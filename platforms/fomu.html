Overview

Fomu is a tiny board with a Lattice iCE40 FPGA that fits all the way inside a USB port. An FPGA is a chip you rewire with code to become almost any digital circuit. It comes with a small RISC-V processor already loaded, and you can start with simple MicroPython commands. It suits curious learners who want a cheap, pocket-sized step into FPGAs with fully open tools.

How the scores work

Good fit or not?

Good for

  • A first taste of FPGAs with Python
  • Learning Verilog, VHDL and soft processors step by step
  • Workshops that use the open Yosys and nextpnr tools
  • Small USB gadgets such as status lights

Not great for

  • Projects with sensors or motors, as it has almost no spare pins
  • Wireless projects, as it has no radio
  • Modern MicroPython features, as the workshop build is old

Specs in plain words

  • 5280 logic cells is room for a small RISC-V processor and a USB connection.
  • 128 KB of memory holds a small program and a modest amount of data.
  • 2 MB of flash stores your design and code, about the size of one phone photo.
  • Four touch pads and one color LED are the only built-in inputs and outputs.
  • The whole board is about the size of a fingernail.

Specs from the Fomu workshop background page, tomu.im, Adafruit's product page and CNX Software. Values are for the production PVT board. clock_mhz is the 48 MHz external oscillator. The default VexRiscv soft core runs at 12 MHz. ram_kb is the iCE40UP5K's 128 KB SPRAM. There is also 16 KB block RAM. flash_kb is the 2 MB SPI flash on PVT (Adafruit's page lists 1 MB as the minimum configuration). gpio 4 counts the four copper touch pads, which double as buttons. CNX Software notes there are no spare GPIOs. Size is about 0.38 x 0.5 in (Make) and 13 mm long (Adafruit). As a result, size_mm is approximate. USB is a soft core in the FPGA. As a result, every user bitstream must include USB logic to stay reachable, or the user must reset into the bootloader.

Things you could build

11 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Color mixing with Python

    Type short MicroPython commands to set the color of the LED. Mix red, green and blue to make any shade.

  • Morse code beacon

    Write a few lines of Python that flash a message in Morse code. Friends can decode it by watching the light.

  • Touch pad color switch

    Make each touch pad pick a different LED color. It is a gentle first look at reading inputs.

Builder ideas

  • Study timer light

    Glow green during study time and red during breaks. A tiny helper sits in your laptop and keeps you on track.

  • Desk notification light

    Send commands from a computer script to change the light color. Show a new message or a finished download at a glance.

  • Bird watching tally counter

    Tap a touch pad for each bird you spot and send the count to your computer. It makes a fun nature survey tool.

  • Touch reaction game

    Flash the LED and time how fast someone taps a pad. Keep the best score on the computer screen.

  • Your first Verilog blink

    Follow the workshop to write a hardware design that blinks the LED. It shows how chips are wired by code.

Expert ideas

  • Build your own RISC-V processor

    Use LiteX to assemble a small RISC-V processor in the FPGA. Then run C programs on a computer you put together.

  • Custom USB keyboard key

    Design a USB device that types a phrase when you touch a pad. It is a deep lesson in how USB really works.

  • Touch pad music controller

    Turn the four pads into a tiny USB music controller for a computer music app. Each pad can play a different drum sound.

How open is it?

Wild Open

Fomu is very open. Full KiCad design files are published under CC-BY-SA-4.0 and TAPR licenses, and the board is OSHWA certified. The bootloader and workshop use the Apache-2.0 license, and the whole build flow uses open tools. Only the iCE40 chip itself is closed.

Hardware license: CC-BY-SA-4.0 (repo LICENSE), TAPR OHL (LICENSE.TAPR and OSHWA entry) · Software license: Apache-2.0 (foboot bootloader, fomu-workshop)
