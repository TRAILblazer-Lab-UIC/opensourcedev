Overview

The GateMate FPGA Evaluation Board is Cologne Chip's reference board for its GateMate A1 chip. An FPGA is a chip you rewire with code to build your own digital circuits. The GateMate is designed and made in Germany. It works with a fully open toolchain, which is rare for an FPGA. It suits engineers who are evaluating the chip and hobbyists who like open tools.

Good fit or not?

Good for

  • Trying an FPGA that uses only open-source tools
  • Engineers who need a European-made FPGA for a design
  • Learning digital logic with plenty of pins and memory
  • Testing fast serial links through the SMA connectors

Not great for

  • Complete beginners, as you write hardware code in Verilog or VHDL
  • Tight budgets, with cheaper GateMate boards available from Olimex and Cologne Chip
  • Projects needing built-in Wi-Fi, Bluetooth, or a screen

Specs in plain words

  • 20,480 programmable elements give room for a small processor plus your own logic.
  • 1,280 Kbit of block RAM is fast on-chip memory, about 160 KB.
  • 8 MB of HyperRAM holds bigger buffers, such as a small image or a long data log.
  • 108 GPIO pins let you wire up many buttons, LEDs, and sensors at once.
  • One USB cable both powers and programs the board.
  • The board is 160 by 100 mm, about the size of a postcard.

ram_kb is the 64 Mbit (8 MB) HyperRAM. The FPGA has 1,280 Kbit of block RAM. flash_kb is the 64 Mbit (8 MB) MX25R6435F configuration flash. clock_mhz is the 10 MHz onboard oscillator. An optional LVDS oscillator footprint feeds the SerDes. The FPGA PLLs reach 420 MHz. gpio is the 108 accessible GPIOs from the datasheet. The chip has 162 single-ended I/O or 81 LVDS pairs. The datasheet lists 7 status LEDs plus an optional bank of 8 LEDs and 1 push button on GPIO bank EB. The USB connectors are mini USB 2.0 Type B per the datasheet. That type is not in the connector vocabulary. The board also has SMA connectors for SerDes. The A2 FPGA (40,960 CPEs) is pin compatible.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blink the status LEDs

    Write a small Verilog design that counts and blinks the onboard LEDs. It is the classic first FPGA test.

  • Button counter on a display

    Count button presses and show them on a seven segment display. It teaches counters and debouncing.

    Add: seven segment display module.

  • Logic gate classroom lab

    Students build AND, OR, and XOR gates from buttons and LEDs. They see logic run as real wires.

    Add: breadboard, push buttons, LEDs.

  • Serial hello message

    Build a UART sender in logic and print a message on your computer. It shows how devices talk bit by bit.

    Add: USB serial adapter.

Expert ideas

  • Tone generator synth

    Make square wave notes and play a tune through a small speaker. Each button can trigger a different pitch.

    Add: small speaker, small amplifier board.

  • VGA pattern generator

    Draw color bars and moving shapes on a monitor through a Pmod video adapter. It teaches how screens draw each line.

    Add: Pmod VGA adapter, VGA monitor.

  • Pong in pure logic

    Build the game Pong with no processor at all. Play it on a monitor with two buttons.

    Add: Pmod VGA adapter, VGA monitor, push buttons.

  • Build your own RISC-V computer

    Load a small RISC-V soft core into the FPGA. Run little C programs on a computer you assembled from logic.

  • Logic analyzer for your bench

    Sample many pins at high speed and stream the data to a PC. Use it to debug other gadgets.

    Add: jumper wires.

  • LED matrix art panel

    Drive a grid of color LEDs with scrolling text and patterns. Hang it in a maker space.

    Add: LED matrix panel, 5 V power supply.

  • SerDes link experiment

    Send fast data out one SMA jack and back in through a cable. Measure how clean the 5 Gb/s signal stays.

    Add: SMA cables.

  • Sensor data logger

    Read a temperature sensor over SPI and store readings in the HyperRAM. Send the log to a computer on request.

    Add: SPI temperature sensor.

Cologne Chip offers a free Altium project with schematics and the board layout, but no license is attached. The toolchain is fully open, with Yosys, nextpnr, and Project Peppercorn under ISC and openFPGALoader under Apache-2.0. The GateMate chip itself is proprietary.
