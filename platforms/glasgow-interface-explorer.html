Overview

Glasgow is a small USB tool for probing the digital wiring inside electronics. It talks to chips over common links such as serial, SPI, I2C, and JTAG. Its software builds a fresh FPGA circuit for each job, and you run it from the command line. It suits engineers, hardware hackers, and digital archivists who rescue old data.

Specs in plain words

  • 16 I/O pins in two ports let you clip onto most small chips at once.
  • Each port sets its own voltage from 1.8 to 5 volts. It can talk to old and new chips safely.
  • A USB link of about 336 megabits per second copies a large flash chip in a short time.
  • Each port can supply up to 150 milliamps. That is enough to power a small chip or sensor board.
  • Built-in meters read voltage and current on each port. One sense pin can measure up to 36 volts.

Specs are for revC3, the revision sold by 1BitSquared, Crowd Supply and Mouser. gpio is the 16 level-shifted pins on ports A and B. The LVDS connector adds 14 differential pairs with no protection or level shifting. adc_channels counts the two INA233 sense inputs, one per port. Each reads 0 to 36 V at 16 bits. The FX2 boots from a 256 Kbit I2C EEPROM and the FPGA has a 1 Mbit I2C EEPROM. No SDRAM is fitted. Interfaces are soft logic built per applet. The listed ones have shipping applets. The FPGA clock and the board size were not stated on the pages read. revD, in pre-launch, has 32 I/O pins in four ports from 1.2 V to 5 V, 300 mA per port and 24-bit analog inputs.

Things you could build

13 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Back up a flash memory chip

    Clip onto the memory chip of an old router or toy and copy everything it holds. You get a safe backup before you tinker.

    Add: test clip for chips, jumper wires.

  • Listen to a gadget's serial port

    Connect to the hidden serial pins on a router or smart plug. Watch its boot messages scroll by on your computer.

    Add: jumper wires.

  • Scan for sensors on a shared bus

    Hook up a small sensor board and ask which addresses answer. It is a quick health check for a school robotics project.

    Add: temperature sensor board, jumper wires.

Builder ideas

  • Rescue an old game cartridge

    Read the memory chip from a vintage game or computer cartridge. Save a copy before the old chip fades.

    Add: chip socket adapter, jumper wires.

  • Preserve a museum computer's software

    Dump old EPROM chips from a retro computer and archive the contents. Local history groups can keep the software alive.

    Add: chip socket adapter.

  • Find the debug pins on a mystery board

    Let the JTAG pinout tool test unlabeled pads on a circuit board. It reports which pins form the debug port.

    Add: jumper wires.

  • Program a small microcontroller

    Load a new program onto an AVR chip for a homemade synth or LED toy. The Glasgow acts as the programmer.

    Add: AVR microcontroller, breadboard.

  • Revive a bricked gadget

    Write a known good firmware image back onto a flash chip. A dead router or keyboard can come back to life.

    Add: test clip for chips.

  • Power and watch a test circuit

    Use a port supply to power a small homemade circuit. Read its voltage and current draw as it runs.

    Add: breadboard, jumper wires.

  • Log a battery voltage for science class

    Wire a battery to the sense input and read its voltage over an afternoon. Plot how it drains under a load.

    Add: battery holder, small resistor.

Expert ideas

  • Copy data off a NAND chip

    Read the large NAND memory from a broken camera or media player. Recover photos or study how it stores files.

    Add: chip socket adapter.

  • Automate chip tests with Python

    Write a Python script that runs an applet over many boards in a row. A small workshop can check each one quickly.

  • Write your own applet

    Build a new applet in Amaranth for an unusual protocol. Share it with the community once it works.
