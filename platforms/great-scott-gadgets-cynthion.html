Overview

Cynthion is a USB test tool from Great Scott Gadgets. It sits between a computer and a USB gadget and records every message they trade. It can also pretend to be a USB device with a little Python. It suits curious tinkerers, security learners, and people who build their own USB gadgets.

Good fit or not?

Good for

  • Watching USB traffic with the free Packetry viewer
  • Learning how keyboards, mice, and drives talk to a computer
  • Making custom USB devices in Python with Facedancer
  • Security classes and reverse engineering of old gadgets
  • Learning FPGA design with fully open tools

Not great for

  • People who want a plain blinking light starter board
  • Tight budgets, with a price above two hundred dollars
  • Projects that need Wi-Fi, Bluetooth, or sensors
  • Quick setup out of the box. Cables are sold separately and each port has a fixed job.

Specs in plain words

  • The FPGA is a chip you can rewire with code. Cynthion uses it to keep up with fast USB traffic.
  • High-Speed USB 2.0 support covers almost every everyday USB gadget, such as keyboards, drives, and webcams.
  • Eight megabytes of fast memory hold a stretch of captured traffic before it moves to your computer.
  • Three separate USB chips let it watch, act as a host, and act as a device.
  • Two small side ports give 16 extra signal pins for your own add-ons.
  • The milled metal case protects the board on a cluttered desk.

FPGA has 12K LUTs. RAM is a 64 Mbit HyperRAM (S27KL0642) and flash is a 32 Mbit W25Q32JV SPI flash, per the KiCad schematic and CNX Software. The schematic also lists an LFE5U-25F footprint option. GPIO count is the 16 FPGA user IOs on the two Pmod ports. Ports are CONTROL (USB-C), AUX (USB-C), TARGET C (USB-C) and TARGET A (USB-A). Six FPGA user LEDs, five status LEDs and PROGRAM, USER and RESET buttons. Retail units ship in a milled aluminum enclosure. Clock speed and board size were not found on fetched pages.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Peek at a keyboard's messages

    Plug a USB keyboard through Cynthion and open Packetry. You can watch each key press travel down the cable.

    Add: USB keyboard, USB cables.

  • See what a mouse says

    Capture the traffic from a USB mouse as you move it. It shows how a computer learns where the pointer goes.

    Add: USB mouse, USB cables.

  • Classroom USB show and tell

    Capture traffic from a few everyday gadgets on a projector. Students compare how a flash drive and a game pad talk.

    Add: USB flash drive, USB game pad, USB cables.

Builder ideas

  • Find out why a gadget fails

    Record the traffic from a USB device that will not connect. The capture shows where the conversation breaks down.

    Add: USB cables.

  • Make a pretend keyboard

    Use Facedancer in Python to make Cynthion act like a keyboard. It can type a short message into a computer.

    Uses: Plugs in USB gadgets. Add: USB cables.

  • Custom game controller

    Write a Python script that makes Cynthion appear as a game controller. Map the buttons for a favorite game.

    Uses: Plugs in USB gadgets. Add: USB cables.

  • Phrase typing helper

    Write a Python script that makes Cynthion type saved phrases as a keyboard. It can help someone who finds typing tiring.

    Uses: Plugs in USB gadgets. Add: USB cables.

  • Music controller experiments

    Emulate a simple music device in Python and send notes to a music app. It is a fun way to learn how devices describe themselves.

    Uses: Plugs in USB gadgets. Add: USB cables.

Expert ideas

  • Man in the middle lab

    Place Cynthion between a computer and a device with USBProxy. Watch and change the messages on the fly for a security class.

    Uses: Plugs in USB gadgets. Add: USB cables.

  • Rebuild an old gadget's driver notes

    Capture traffic from an old USB gadget that lost its software. The notes help the community write a new open driver.

    Add: USB cables.

  • Design your own USB device in hardware

    Use the LUNA library and Amaranth to build a USB device inside the FPGA. It is a deep dive into how chips speak USB.

  • Logic probe on the side ports

    Connect the side ports to a small circuit and record its signals. Compare them with the USB traffic in the same session.

    Add: jumper wires, breadboard.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 3 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseOpen license
  • Coding toolsFully open
  • The chip itselfClosed chip design
  • OSHWACertified open hardware

The hardware design files are published in KiCad under the CERN-OHL-P-2.0 license. The software, the LUNA library, and Packetry use the BSD-3-Clause license. The FPGA builds with fully open tools, and the board is OSHWA certified as US000641. The FPGA chip and the helper microcontroller stay closed designs from their makers.
