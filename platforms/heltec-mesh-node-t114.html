Overview

The Heltec Mesh Node T114 is a small LoRa radio board built around a Nordic nRF52840 chip. It sips very little power and has inputs for a LiPo battery and a solar panel. Most people buy it as a low-cost Meshtastic node for off-grid texting. Hobbyists can also program it with Arduino or Zephyr tools.

Good fit or not?

Good for

  • Texting friends off the grid with Meshtastic
  • Solar powered repeaters that run for a long time
  • Battery sensors that sleep most of the day
  • Low-cost nodes for a group or a club

Not great for

  • Heavy computing or Wi-Fi projects, as the chip has no Wi-Fi
  • Location sharing out of the box, as GPS is an extra module
  • Commercial copies, as Heltec forbids commercial use of its files
  • Arduino LoRaWAN work with Heltec's library, which needs a per-chip key

Specs in plain words

  • The nRF52840 runs at 64 MHz with 256 KB of memory. That is plenty for messages and sensor readings.
  • Deep sleep draws about 11 microamps. A small battery can last a very long time in a sensor that wakes now and then.
  • The LoRa radio sends short messages for miles across open ground. Buy the band your country allows, such as 915 MHz in the US or 868 MHz in Europe.
  • The optional 1.14 inch color screen is about the size of a thumbnail. It shows messages and battery level.
  • The board measures about 51 by 23 millimeters. It fits in a pocket or a small box.

Flash and RAM are the nRF52840 internal values. The V2.0 schematic also shows an external MX25R1635F 16 Mbit (2 MB) QSPI flash. The display and GNSS module are options. The display is the LH114T-IF03 ST7789 panel per the datasheet and Zephyr docs. The GPIO count is the number of plain GPIO pins on the two 13-pin headers in the datasheet pin table. The nRF52840 has 8 analog inputs, but the number routed to headers was not confirmed. Thread and 802.15.4 come from the nRF52840 and are listed in the Zephyr board support. Meshtastic does not use them. Heltec lists 9 mA active draw with GPS and TFT off, 20 mA with the TFT on and 51 mA with both on. Meshtastic low-power mode is about 23 uA. The BLE antenna is an onboard chip antenna. LoRa uses an IPEX 1.0 (U.FL) connector.

Things you could build

Starter ideas

  • Off-grid texting on hikes

    Pair a T114 with each hiker's phone over Bluetooth. Your group can text each other in places with no cell signal.

    Uses: LoRa long range radio, Mesh messaging, Bluetooth. Add: LiPo battery.

  • Solar rooftop repeater

    Mount the board in a weatherproof box with a small solar panel. It relays messages for neighbors for months with little care.

    Uses: LoRa long range radio, Mesh messaging, Sips power, Battery ready. Add: small solar panel, LiPo battery, weatherproof box.

  • Neighborhood outage check-in

    Keep a node in each home on the block. Neighbors can post a quick status note during a power or phone outage.

    Uses: LoRa long range radio, Mesh messaging, Bluetooth. Add: LiPo battery.

  • Pocket message reader

    Order the version with the color screen. Incoming texts show up on the board without a phone in hand.

    Uses: LoRa long range radio, Mesh messaging, Screen. Add: LiPo battery.

  • School radio range lesson

    Students carry nodes across campus and note where messages still arrive. They learn how hills and walls block radio.

    Uses: LoRa long range radio, Mesh messaging. Add: LiPo battery.

  • Friend finder with add-on GPS

    Plug the small GPS module into its socket. Each node then shares its spot on the phone app map.

    Uses: LoRa long range radio, Mesh messaging, Bluetooth. Add: GPS module, LiPo battery.

Builder ideas

  • Garden soil moisture alerts

    Wire a soil sensor to the header pins and send readings across the yard by radio. Your phone learns the beds are dry.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: soil moisture sensor, LiPo battery, weatherproof box.

  • Mailbox opened alert

    Fit a magnetic door switch to a far-off mailbox. The board sleeps and sends a radio note each time the lid opens.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: magnetic door switch, LiPo battery.

  • Greenhouse weather station

    Add a temperature and humidity sensor. The screen shows the reading and the radio shares it with the house.

    Uses: LoRa long range radio, Screen, Sips power. Add: temperature and humidity sensor, small solar panel, LiPo battery.

  • Wildlife trail visit counter

    Attach a motion sensor near an animal path. The board counts visits and reports totals by radio once a day.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: motion sensor, LiPo battery, weatherproof box.

  • Mood light message alert

    Program the two color LEDs to glow for new messages. A blue flash can mean a friend checked in.

    Uses: LoRa long range radio, Mesh messaging.

Expert ideas

  • Bluetooth sensor gateway

    Let the board collect readings from nearby Bluetooth sensors. It forwards them far across town over LoRa.

    Uses: Bluetooth, LoRa long range radio, Sips power. Add: Bluetooth temperature sensors.

  • Beehive weight logger

    Put a scale sensor under a hive. The board radios the weight each evening to track honey flow.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: load cell scale sensor, LiPo battery, small solar panel.

  • Smart home Thread experiment

    Uses: Thread or Zigbee.

How open is it?

Open Board

Heltec shares schematic PDFs for the board. No layout files are posted, and Heltec's documents forbid commercial reuse. The Heltec Arduino core and the Meshtastic firmware are open under GPL-3.0. The Bluetooth stack and Heltec's LoRaWAN library stay closed.

Hardware license: none stated (Heltec documents are all rights reserved, non-commercial use only) · Software license: Heltec_nRF52 Arduino core GPL-3.0, with a precompiled Heltec LoRaWAN library. Meshtastic firmware GPL-3.0.
