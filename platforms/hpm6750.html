HPM6750

HPMicro (Shanghai HPMicro Semiconductor)

A very fast dual-core RISC-V microcontroller for screens and industrial control.

Overview

The HPM6750 is HPMicro's flagship microcontroller with two RISC-V cores at up to 816 MHz. It is one of the fastest microcontrollers sold, with over 9,000 CoreMark. It has gigabit Ethernet, high-speed USB, a screen controller with a graphics engine, and camera inputs. It suits experienced developers building industrial controls, display panels, and fast motor drivers.

  • Wireless projects, as the chip has no radio of its own

Specs in plain words

  • Two cores at 816 MHz can run a screen, a network link, and motor code at the same time.
  • 2 MB of on-chip memory plus 32 MB of SDRAM on the EVK2 holds big graphics and data buffers.
  • The chip has no flash inside. Programs live on a separate flash chip on the board.
  • The screen controller drives displays up to 1366 by 768 dots at 60 frames per second.
  • The chip has two gigabit Ethernet controllers for fast wired networking.
  • The EVK2 board measures about 146 by 102 millimeters, a bit smaller than a postcard.

The chip has no internal flash. flash_kb is 0 because code runs from external QSPI NOR flash. The EVK2 carries 16 MB NOR flash and 32 MB SDRAM. The EVKMINI carries 8 MB NOR flash and 16 MB SDRAM. ram_kb is the 2 MB on-chip SRAM from the SDK board docs and NuttX. The series overview page says 1 MB built-in SRAM plus up to 512 KB ILM/DLM, which is a conflict. Connectors, onboard parts and size describe the HPM6750EVK2 (146 x 102 mm), which also has gigabit and 100 Mbit Ethernet, three USB-C ports and CAN. The EVKMINI adds an RW007 Wi-Fi module over SPI, which is not a chip radio. The supply voltage and EVK power input were not stated on fetched pages. GPIO count and ADC channel count were not published on fetched pages.

Builder ideas

  • Digital photo frame

    Decode JPEG pictures from a microSD card with the hardware codec. Show a slideshow on a screen in the hallway.

    Uses: Screen. Add: LCD screen, microSD card.

  • Wired network sensor hub

    Connect the board to a home router over Ethernet. Serve a small web page with temperature readings from around the house.

    Uses: Wired network. Add: temperature sensors, Ethernet cable.

  • Voice recorder

    Record sound from the onboard microphone to a microSD card. Play clips back through the headphone jack.

    Uses: Hears sound, Makes sound, Sensors built in. Add: microSD card, headphones.

  • Music visualizer

    Listen through the microphone and draw a live sound spectrum on the screen. The fast cores keep the bars smooth.

    Uses: Hears sound, Screen. Add: LCD screen.

  • USB keyboard terminal

    Plug a USB keyboard into the host port and type commands into the NuttX shell. It feels like a tiny computer.

    Uses: Plugs in USB gadgets, Screen. Add: USB keyboard, LCD screen.

  • Rust on RISC-V practice

    Flash an Embassy example from the hpm-hal Rust crate. Learn modern embedded Rust on a very fast chip.

  • Science lab data logger

    Sample fast signals with the 16-bit ADC and save them to a microSD card. Graph the results on a computer after class.

    Add: microSD card, sensor probes.

Expert ideas

  • Touch screen control panel

    Drive an LCD with the built-in graphics engine. Build smooth menus for a workshop machine or a home heating system.

    Uses: Screen. Add: LCD touch screen.

  • Simple security camera

    Attach a camera to the camera port and stream snapshots over Ethernet. Check the back door from a laptop.

    Uses: Camera, Wired network. Add: camera module, Ethernet cable.

  • Tiny image classifier

    Run a small neural network on camera frames like the community TinyMaix demo. The board can tell a few simple objects apart.

    Uses: Camera, Screen. Add: camera module, LCD screen.

  • Retro game console

    Port a simple arcade game to the board. The 2D engine and LCD controller keep the graphics quick.

    Uses: Screen, Plugs in USB gadgets. Add: LCD screen, USB game controller.

    Link motors and sensors over CAN FD and send status to a control room over Ethernet. This is the kind of job HPMicro built it for.

    Uses: Wired network. Add: CAN transceiver, motor driver board.

  • Smooth motor control lab

    Use the fine 2.5 nanosecond PWM timing to drive a brushless motor. Students compare control methods on a test bench.

    Add: brushless motor, motor driver board, power supply.

How open is it?

Openness level

Level 1 of 3. Wild Open shares the most.

  • Board plansNot confirmed

  • Coding toolsFully open
  • The chip itselfClosed chip design

The HPM SDK is open source under the BSD-3-Clause license. Apache NuttX supports the EVK2, and the hpm-hal Rust crate is Apache-2.0. Code builds and flashes with open tools such as GNU GCC and HPMicro's OpenOCD fork. The chip design is closed, and no board schematics or layout files were found.

Software license: BSD-3-Clause (HPM SDK), Apache-2.0 (hpm-hal Rust crate)
