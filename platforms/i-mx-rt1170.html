i.MX RT1170

NXP Semiconductors

A gigahertz microcontroller from NXP for touch screens, cameras, and fast networks.

Overview

The i.MX RT1170 is a microcontroller from NXP with a 1 GHz Arm Cortex-M7 and a 400 MHz Cortex-M4 on one chip. NXP called it the start of the gigahertz microcontroller era at its 2019 launch. It adds a 2D graphics engine, camera and display links, and fast Ethernet. It suits experienced makers who build touch screens, camera AI, or factory gear and who can spend about 150 to 200 dollars on a board.

Good fit or not?

Good for

  • Smooth touch screen menus and dashboards
  • Camera and voice projects that need fast processing
  • Wired network gadgets with Ethernet or CAN
  • Learning Zephyr, MicroPython, or embedded Rust on a fast chip

Not great for

  • Tight budgets, as boards start near 150 dollars
  • Wireless projects, as Wi-Fi needs an add-on card
  • Battery gadgets that sleep for months, as sleep current is not published
  • First-time coders, as setup takes embedded know-how

Specs in plain words

  • A 1 GHz main core is many times faster than a typical hobby board. It can redraw a screen and process sound at once.
  • A second 400 MHz core can run a separate job, such as motor timing.
  • 2 MB of on-chip memory is roomy for a microcontroller. Bigger boards add 64 MB of extra memory for images and screens.
  • The chip has no built-in storage. Each board adds a separate flash chip for your program.
  • MIPI camera and display links connect modern phone-style cameras and screens up to 720p.
  • Two Gigabit Ethernet ports and three CAN buses link it to networks, cars, and machines.

Chip values come from the NXP product page and CNX. The M4 core runs at up to 400 MHz. The chip has no internal flash. Board flash differs and sources conflict for the EVKB. NXP lists 128 Mbit QSPI plus 512 Mbit Octal flash, and Zephyr lists 512 Mbit QSPI. flash_kb is null for that reason. psram_kb holds the 64 MB of external SDRAM on the EVKB and the phyCORE-RT1170 module. It is not PSRAM. Connector and onboard values are for the MIMXRT1170-EVKB, which has an e-compass, microphones, M.2 for Wi-Fi and Bluetooth, and MIPI camera and LCD connectors. NXP's product page body says three Ethernet ports, and its feature list says two Gigabit ports. CNX lists two Gigabit plus one 10/100. Chip GPIO and ADC counts and sleep current were not found in a fetched source.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Touch screen control panel

    Build a smooth touch menu with LVGL on a MIPI display. Use it to run lights, fans, or a 3D printer.

    Uses: Screen. Add: MIPI touch display.

  • Smart home dashboard

    Show weather, room temperatures, and a calendar on a wall screen. The board pulls the data over wired Ethernet.

    Uses: Screen, Wired network. Add: MIPI touch display, Ethernet cable.

  • Internet radio player

    Stream music over Ethernet and play it through headphones. Show the station name on a screen.

    Uses: Wired network, Makes sound, Screen. Add: headphones, MIPI touch display.

  • MicroPython sensor logger

    Flash MicroPython and read sensors over I2C. Save readings to a microSD card for a science class.

    Add: temperature and humidity sensor, microSD card.

  • Digital compass display

    Read the onboard e-compass and draw a spinning compass on a screen. Take it outside for a navigation lesson.

    Uses: Sensors built in, Screen. Add: MIPI touch display.

  • USB keyboard and mouse tester

    Plug a keyboard or mouse into the USB host port. Print each key press and click to a screen.

    Uses: Plugs in USB gadgets. Add: USB keyboard.

Expert ideas

  • Retro game console

    Write simple 2D games that use the built-in graphics engine. Plug in a USB gamepad to play.

    Uses: Screen, Plugs in USB gadgets. Add: MIPI touch display, USB gamepad.

  • Camera that spots objects

    Run a small vision model with NXP eIQ tools on live camera frames. Show what it found on the screen.

    Uses: Camera, Screen. Add: MIPI camera module, MIPI touch display.

  • Voice command box

    Use the onboard microphones to hear a few spoken commands. Reply with a sound through a speaker.

    Uses: Hears sound, Makes sound, Sensors built in. Add: small speaker.

  • Digital audio effects pedal

    Feed a guitar or microphone into the audio codec and add echo or distortion. The fast core handles the math in real time.

    Uses: Hears sound, Makes sound. Add: audio cables, small speaker.

  • Network sensor hub for a maker space

    Collect readings from many sensors and serve them on a small web page over Ethernet. Anyone on the network can check the room.

    Uses: Wired network. Add: Ethernet cable, air quality sensor.

  • Motor control lab

    Drive a brushless motor with precise timing from the M7 core. The M4 core can log speed at the same time.

    Add: brushless motor, motor driver board, power supply.

  • Doorbell with a camera and screen

    Show the camera view on an indoor screen once someone presses a button. Save a snapshot to a memory card.

    Uses: Camera, Screen. Add: MIPI camera module, MIPI touch display, push button, microSD card.

  • Rust on two cores

    Learn embedded Rust with the imxrt-hal crate. Split tasks between the fast core and the helper core.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansSchematics only
  • Hardware licenseNot confirmed
  • Coding toolsFully open
  • The chip itselfClosed chip design

No RT1170 board has an open hardware license. NXP shares EVK design files behind a free account, and some board makers share schematics. The software path is open, with the BSD-3-Clause MCUXpresso SDK, Apache-2.0 Zephyr, and MIT MicroPython. The chip itself is closed.

Key terms on this page

Arm Cortex-M
Cortex-M is a family of Arm processor designs for microcontrollers.
Bus
A bus is a shared path that carries data between parts.
CAN bus
CAN bus is a sturdy wired network made for cars.
Debug probe
A debug probe is a small tool that connects a computer to a chip's insides.
Deep sleep
Deep sleep is a mode where a chip shuts down almost everything.
Microcontroller
A microcontroller is a tiny computer on a single chip.
MicroPython
MicroPython is a small version of Python made for microcontrollers.
Permissive license
A permissive license lets people use and change a work with few rules.
Resolution
Resolution is how many dots make up an image or screen.
Serial monitor
A serial monitor is a window that shows text sent from a board.
SRAM
SRAM is a fast kind of RAM built right into a microcontroller chip.
Zephyr
Zephyr is an open-source RTOS backed by the Linux Foundation.
