Overview

The Icepi Zero is an FPGA board in the size and shape of a Raspberry Pi Zero. An FPGA is a chip you rewire with code to become almost any digital circuit. This one has memory, a video port and USB, which makes it a small FPGA computer. It suits students and hobbyists who want to learn digital design or run retro computer cores.

Good fit or not?

Good for

  • Learning digital design with open tools
  • Running retro computers such as the Apple I and Acorn Atom
  • Video projects on a monitor or TV
  • Booting Linux on a soft processor
  • Pairing with a Raspberry Pi Zero

Not great for

  • Complete beginners, as setup uses a command line toolchain
  • Wireless projects, as it has no radio
  • Reading analog sensors, as it has no analog inputs
  • Older boards without care, as pin settings changed between revisions

Specs in plain words

  • 24 thousand logic cells is room for a whole retro computer or a small Linux-capable processor.
  • 32 MB of memory gives soft processors and video frames plenty of space.
  • 16 MB of flash stores your design and extra data such as a game or font.
  • The mini video port drives a normal monitor or TV with a mini HDMI cable.
  • At 65 by 30 millimeters, it is about the size of a stick of gum.
  • 28 GPIO pins on the 40-pin header connect sensors, buttons and add-ons.

ram_kb is the 256 Mbit 166 MHz SDRAM, as on the ULX3S card. The FPGA also has 112 KiB of block RAM. clock_mhz is the 50 MHz MEMS oscillator. The FPGA has PLLs for higher clocks. gpio is the 28 GPIO pins on the Pi-style 40-pin header. The video port is GPDI on a mini HDMI connector, mapped to hdmi here. USB, SD, SPI and I2C are soft logic. The repo has USB host mouse, SD and SPI examples. The README lists 4 user LEDs. CNX Software and Elecrow list 5. Both list 2 user buttons.

Things you could build

14 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink the onboard LEDs

    Build a first design that makes the LEDs blink and chase. Try it in the block editor before you write any Verilog.

  • Button logic lab for class

    Wire the two buttons to the LEDs through logic you design. Students see AND and OR gates work in real hardware.

  • Color bars on a TV

    Send a test pattern to a monitor through the video port. It shows how a screen gets drawn line by line.

    Uses: Screen. Add: mini HDMI cable, monitor.

Builder ideas

  • Run an Apple I replica

    Load the Apple I core and type programs on a vintage-style computer. It brings 1970s computing into the classroom.

    Uses: Screen, Plugs in USB gadgets. Add: mini HDMI cable, monitor, USB keyboard.

  • Boot an Acorn Atom

    Run the Acorn Atom core and explore an early British home computer. Kids can try its simple BASIC language.

    Uses: Screen, Plugs in USB gadgets. Add: mini HDMI cable, monitor, USB keyboard.

  • Mouse drawing pad

    Plug in a USB mouse and paint pixels on the screen. Kids can doodle on a computer they helped build.

    Uses: Screen, Plugs in USB gadgets. Add: USB mouse, mini HDMI cable, monitor.

  • Pong for two players

    Build the classic Pong game fully in logic and show it on a TV. Use buttons on the header as paddles.

    Uses: Screen. Add: push buttons, jumper wires, mini HDMI cable, monitor.

  • Scrolling message sign

    Show a scrolling welcome message on a spare monitor at a library or club. Change the text from the block editor.

    Uses: Screen. Add: mini HDMI cable, monitor.

  • Simple tone synthesizer

    Make square wave notes and play them through a small speaker. Each header button can play a different pitch.

    Add: small speaker, small amplifier board, push buttons.

  • Servo pointer for a science demo

    Generate precise pulses that swing a servo arm. Use it to point at the planets on a model solar system.

    Add: servo motor, jumper wires.

Expert ideas

  • Explore the Oberon system

    Run the Oberon operating system with a mouse on your monitor. It is a full windowed computer built in logic.

    Uses: Screen, Plugs in USB gadgets. Add: mini HDMI cable, monitor, USB keyboard, USB mouse, microSD card.

  • Pi Zero helper board

    Connect it to a Raspberry Pi Zero through the 40-pin header. Let the FPGA handle fast signals for the Pi.

    Add: Raspberry Pi Zero, header connector.

  • Run Linux on a soft core

    Build a LiteX system with a soft RISC-V processor and boot Linux. You get a small computer made from logic.

    Add: microSD card.

  • Garden sensor dashboard

    Read a temperature and humidity sensor on the header pins. Draw the readings as a live chart on a monitor.

    Uses: Screen. Add: temperature and humidity sensor, mini HDMI cable, monitor.

How open is it?

Wild Open

The KiCad schematics, board layouts and Gerbers are published under the Solderpad Hardware License 2.1. The example designs use the Zlib license, and OSHWA certified the board as FR000026. The full tool flow is open, but the ECP5 chip itself is closed.
