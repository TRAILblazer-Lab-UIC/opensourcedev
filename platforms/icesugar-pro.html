Overview

The iCESugar-Pro is an FPGA board from MuseLab built on a Lattice ECP5 chip. An FPGA is a chip you rewire with code to become almost any digital circuit. The module plugs into a carrier board through a laptop memory-style edge, and it has 32 MB of memory. At about 60 dollars, it is one of the cheapest boards that boots Linux on an open RISC-V soft processor.

Good fit or not?

Good for

  • Learning hardware design on a larger FPGA
  • Running LiteX RISC-V systems with Linux
  • Video and LED panel projects that need many pins
  • Using fully open FPGA tools such as Yosys and nextpnr

Not great for

  • Complete beginners, as it needs hardware languages
  • Wireless projects, as it has no radio
  • Reading analog sensors, as it has no analog inputs
  • Commercial products, as its terms limit business use

Specs in plain words

  • 24,000 logic cells is room for a small Linux-capable processor plus extra circuits.
  • 32 MB of memory gives a soft processor space to run Linux.
  • 32 MB of flash and a microSD slot store your designs and files.
  • 106 input and output pins reach the headers on the carrier board for lots of add-ons.
  • A built-in debugger shows up as a USB drive. You program the FPGA by dragging a file onto it.

ram_kb is the 32 MB SDRAM on the module. The FPGA itself has 1008 Kb of block RAM and 194 Kb of distributed RAM. clock_mhz is the 25 MHz crystal. The FPGA has one PLL per the README. gpio is the 106 usable I/O on the SODIMM edge. The Ext-Board breaks them out to headers. HDMI is listed because the repo ships an HDMI test pattern demo through the Ext-Board. It is not a dedicated HDMI chip. The Ext-Board was first designed for the Colorlight i5 module.

Starter ideas

  • Blink the RGB LED

    Drag the ready blink file onto the board's USB drive. Then change the Verilog to try new colors and speeds.

Builder ideas

  • Hello over the serial port

    Build a simple serial sender in Verilog. Watch your message appear in a terminal on your computer.

  • HDMI test pattern

    Run the HDMI demo and draw color bars on a monitor. It shows how screens are drawn line by line.

    Wire buttons and LEDs to the headers and build gates, counters, and timers. Each student sees logic run in real hardware.

    Add: push buttons, LEDs, jumper wires.

  • Synth tone maker

    Generate square and triangle waves for a small speaker. Map each button to a musical note.

    Add: small speaker, small amplifier board, push buttons.

  • Frequency counter for science class

    Measure how fast a signal flips on and off. Test a buzzer, a fan sensor, or a signal generator.

    Add: jumper wires.

Expert ideas

  • Pong on a monitor

    Build the classic Pong game fully in logic. Two players use buttons wired to the headers.

    Uses: Screen. Add: HDMI breakout add-on, monitor, push buttons.

  • Boot Linux on RISC-V

    Load the LiteX VexRiscv bitstream and Linux image from the repo. Watch a homemade processor boot Linux in a serial terminal.

    Add: microSD card.

  • Build your own soft computer

    Use LiteX to design a small system with a CPU, memory, and serial port. Then run your own C programs on it.

  • LED panel art display

    Drive a large grid of color LEDs with scrolling text and patterns. Hang it in a hallway or maker space.

    Add: LED matrix panel, 5 V power supply.

  • Logic analyzer for your bench

    Capture fast digital signals into the 32 MB memory. Send them to your computer to see how other gadgets talk.

    Add: jumper wires.

  • Custom carrier board

    Design your own board with a cheap memory-stick socket. Plug in the module and add only the parts you need.

    Add: SODIMM socket, custom circuit board.
