Overview

The ECP5 Evaluation Board is Lattice's low-cost board for its ECP5-5G FPGA family. It carries the biggest chip in the family, with 85K logic cells and four fast 5 Gb/s links. The open Yosys and nextpnr tools have worked on it from the start. It suits people who want a large FPGA for open-tool designs such as RISC-V computers.

Good fit or not?

Good for

  • Big FPGA designs with the open toolchain
  • Building soft processors such as RISC-V
  • Testing fast serial links over SMA cables
  • Learning digital logic with built-in LEDs, switches, and buttons

Not great for

  • Beginners, with hardware languages and a toolchain to install
  • USB-only power, with a 12 volt adapter required
  • Projects that need external memory, with none on the board
  • Fully open hardware, with board layout files behind a login

Specs in plain words

  • 85K logic cells is room for a small computer processor plus many extras.
  • 16 MB of flash holds your design and loads it at power on.
  • 178 I/O pins connect to LEDs, switches, and add-on headers.
  • Four 5 Gb/s links on SMA jacks carry very fast data between boards.
  • The 12 MHz clock comes from the USB chip. It stops once USB is unplugged.
  • Arduino, Raspberry Pi, and Pmod headers accept common add-on boards.

No external RAM is on the board. The LFE5UM5G-85F has about 3.7 Mbit of block RAM per the ECP5 family, unchecked against the datasheet here. flash_kb is the 128 Mbit (16 MB) SPI flash. clock_mhz is the 12 MHz clock from the FTDI chip, which works only when USB is connected. A 200 MHz differential SERDES clock is fitted, and a 50 MHz oscillator footprint is left empty. gpio is the 178 I/O listed on the product page. The programming port is mini USB-B. That type is not in the connector vocabulary. SMA connectors carry the SERDES lanes. The board shows 8 LEDs, which is not an onboard vocabulary item.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Night Rider LED sweep

    Build the Project Trellis example that sweeps light across the eight LEDs. It proves your tools and board work.

  • Switch and LED logic lab

    Turn the eight DIP switches into inputs for gates you design. Students watch the LEDs show the results.

  • Reaction timer game

    Light a random LED and time how fast a player hits a button. Show the score in binary on the LEDs.

  • Hello over the serial port

    Send a message from the FPGA through the USB chip to your computer. Watch it appear in a terminal window.

  • Tone and melody maker

    Generate square wave notes and play a tune on a small speaker. Each button plays a different note.

    Add: small speaker, small amplifier board.

Expert ideas

  • Build a RISC-V computer

    Load the Trellis PicoRV32 example with memory and a serial port. Then run small C programs on a processor you built from logic.

  • Video test pattern

    Draw color bars and moving shapes on a monitor through a video add-on. Learn how a screen is drawn line by line.

    Add: VGA add-on module, monitor.

  • Homemade logic analyzer

    Capture fast signals on the I/O pins and send them to your computer. Debug other gadgets with a tool you made.

    Add: jumper wires.

  • Retro computer recreation

    Rebuild a classic home computer or game console in logic. 85K logic cells give plenty of room.

    Add: VGA add-on module, monitor, USB keyboard adapter.

  • SERDES link tester

    Loop a 5 Gb/s channel back to itself through SMA cables. Measure errors on a high-speed link.

    Add: SMA cables.

  • Motor speed controller

    Make precise PWM signals for a small motor in hardware logic. Change the speed with the DIP switches.

    Add: motor driver board, small DC motor, battery pack.

  • Lab frequency counter

    Count how fast an outside signal toggles and show the result on a display. Use it to check clocks in science projects.

    Add: seven segment display add-on.
