Overview

The LPC1768 is a 32 bit Arm Cortex-M3 chip from NXP that dates to 2009. It powered the original mbed board, which let people program a chip by dragging a file onto a USB drive. Today it also sits inside many 3D printer and CNC boards. It suits tinkerers who like C or C++ and want Ethernet and USB on one chip.

How the scores work

Good fit or not?

Good for

  • Wired network projects with Ethernet
  • Upgrading 3D printers and CNC machines with Marlin or Smoothieware
  • Projects that need USB host, CAN bus, and many pins
  • Learning classic C and C++ on a proven chip

Not great for

  • Wireless projects, as it has no Wi-Fi or Bluetooth
  • Absolute beginners, as the old online compiler has closed
  • Python fans, as current sources show only C and C++
  • Tiny or battery powered gadgets on the big printer boards

Specs in plain words

  • The 100 MHz processor handles sensors, network traffic, and motor timing with ease.
  • 64 KB of memory holds a few thousand sensor readings at once.
  • 512 KB of flash storage fits a full 3D printer firmware.
  • Up to 70 pins let you wire many buttons, lights and sensors.
  • Ethernet lets the board join your home network with a plain cable.
  • Deep power down draws about one microamp, which lets a coin cell keep the clock alive.

Deep sleep draw1.16 microamps

Chip values come from the NXP product page and datasheet Rev 9.10. The 64 KB SRAM is split into a 32 KB main block and two 16 KB AHB blocks. The mbed LPC1768 board and Wikipedia quote 96 MHz and 32 KB, which reflects the mbed default clock and the main SRAM block only. Ethernet needs an external PHY, which the mbed LPC1768 and Arch Pro boards include. Deep power-down current is the sum of 630 nA on VDD(REG) and 530 nA on VBAT from the datasheet table at 3.0 V and 25 C. Connectors and size vary widely between the 40-pin DIP mbed board and the large 3D printer boards. As a result, size is left blank.

Starter ideas

  • Blinking light greeting

    Copy a blink program onto the mbed board like a file on a USB stick. The onboard lights flash in a pattern you choose.

  • Room temperature reader

    Wire a small temperature sensor to the board. It prints the room temperature to your computer every few seconds.

    Add: temperature sensor, jumper wires.

  • Button doorbell chime

    Connect a push button and a small speaker. Each press plays a short tune from the board's sound output.

    Uses: Makes sound. Add: push button, small speaker.

Builder ideas

  • Web page weather station

    Plug the board into your home router with a network cable. It serves a simple web page with temperature and humidity readings.

    Uses: Wired network. Add: network cable, temperature and humidity sensor.

  • Garden soil logger

    Read a soil moisture sensor each hour. The board sends the numbers over the network to a computer in the house.

    Uses: Wired network. Add: soil moisture sensor, network cable.

  • USB keyboard game controller

    Plug a USB keyboard into a board with USB host support. The keys steer a simple light game on an LED strip.

    Uses: Plugs in USB gadgets. Add: USB keyboard, LED strip.

  • Clap counter

    Attach a small microphone module. The board counts claps and lights an LED for each one.

    Uses: Hears sound. Add: microphone module, LEDs.

  • Classroom energy meter

    Measure the voltage from a small solar panel with the analog inputs. Students watch the readings change through the day.

    Add: small solar panel, resistors.

  • Upgraded 3D printer brain

    Fit a 32 bit control board built on this chip into an older 3D printer. Flash the free Marlin firmware and print smoother parts.

    Add: 3D printer control board, stepper motor drivers.

Expert ideas

  • Desktop CNC drawing machine

    Drive two stepper motors with Smoothieware on a printer board. The machine draws pictures with a pen on paper.

    Add: 3D printer control board, stepper motors, pen holder, frame kit.

  • Robot wheel speed tracker

    Read a wheel encoder with the chip's built in counter. The robot knows how far it has rolled.

    Add: motor with encoder, motor driver board.

  • Network clock with backup battery

    Fetch the time over the network and keep it in the real time clock. A coin cell keeps the clock ticking through power cuts.

    Uses: Wired network, Sips power. Add: network cable, coin cell holder, small display.

  • Car data listener

    Connect a CAN bus adapter to a test bench or hobby vehicle network. The board logs messages for study.

    Add: CAN transceiver module.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseNot confirmed
  • Coding toolsFully open
  • The chip itselfClosed chip design

Seeed shares editable Eagle files for its Arch Pro board, and NXP shares the mbed board schematic as a PDF. Mbed OS uses the Apache-2.0 license, and Marlin and Smoothieware use GPL-3.0. The chip and its Arm core stay closed, and most board files list no license.
