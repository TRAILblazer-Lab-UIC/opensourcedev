Overview

The LPC55S69 is a microcontroller chip from NXP with two Arm Cortex-M33 cores. Security is its big feature, with locked memory areas, flash encryption, and secure boot built in. Makers meet it inside open security keys such as the SoloKeys Solo 2. It suits people who already write C or Rust and want to learn chip security or audio math.

Good fit or not?

Good for

  • Learning how secure and open code are kept apart on one chip
  • Hacking on open-source security keys
  • Audio and signal math with the built-in math helper
  • Rust and Zephyr fans who want solid board support
  • Cheap experiments on an MCU-Link probe or OKdo E1 board

Not great for

  • Total beginners who want Python or drag-and-drop coding
  • Wireless projects, as the chip has no Wi-Fi or Bluetooth radio
  • Plug-and-play setup on the OKdo E1, which ships without its clock crystal

Specs in plain words

  • Two cores at up to 150 MHz let one core read sensors as the other does other work.
  • 640 KB of flash holds a large program with room to spare.
  • 320 KB of working memory is plenty for audio buffers and sensor data.
  • TrustZone, PRINCE encryption, and a key vault keep secrets locked away from regular code.
  • The PowerQuad helper speeds up audio filters and other number crunching.
  • High-speed USB can act as a device or plug in a keyboard or drive.

Chip values come from the NXP product page. GPIO is up to 64 and depends on the package (HLQFP100, VFBGA98 or HTQFP64). The second Cortex-M33 has no FPU, MPU, DSP or TrustZone. Zephyr runs the core at 96 to 144 MHz on the EVK depending on flash setup. The ADC has five differential pairs or 10 single-ended inputs. The chip has no CAN. The LPC55S1x sibling adds CAN FD. Connector and onboard values are for the LPCXpresso55S69 EVK, which has microSD, a stereo audio codec, an accelerometer, RGB LED, Arduino, mikroBUS and Pmod headers. The OKdo E1 is about 50 x 25 mm with castellated edges. No sleep current figure was found in a fetched source.

Things you could build

Builder ideas

  • Tilt-controlled light

    Read the motion sensor on the dev board. The color light changes as you tilt the board.

    Uses: Sensors built in.

  • Room sound meter

    Measure how loud a classroom gets through the day. Save the readings to a microSD card for a science project.

    Uses: Hears sound. Add: microSD card, small microphone.

  • Simple tone synthesizer

    Wire up a few buttons and make each one play a note. Kids can compose short tunes with it.

    Uses: Makes sound. Add: push buttons, headphones or small speaker.

  • Garden data logger

    Read soil moisture and temperature sensors every few minutes. Store the numbers on a microSD card for later charts.

    Add: soil moisture sensor, temperature sensor, microSD card.

  • Homemade debug probe

    Use an MCU-Link probe to program and test other boards. One cheap tool serves a whole maker club.

    Add: jumper wires.

  • Heartbeat sound visualizer

    Sample a pulse sensor with the fast analog input. Turn each beat into a beep and a light flash.

    Uses: Makes sound. Add: pulse sensor, LED.

Expert ideas

  • Build your own security key

    Flash open firmware onto a Solo 2 Hacker key. You get a login key you can read and change yourself.

    Add: open security key with a hacker version.

  • TrustZone lesson board

    Split one program into a locked secure half and an open half. Students can watch the chip block the open half from secrets.

  • Guitar effects box

    Feed a guitar into the audio input and add echo or distortion with the math helper. Play the result through headphones.

    Uses: Hears sound, Makes sound. Add: guitar cable adapter, headphones.

  • USB keyboard reader

    Plug a USB keyboard into the board. Typed words scroll across a small screen as a message sign.

    Uses: Plugs in USB gadgets. Add: USB keyboard, small screen.

  • Signed sensor station

    Sign each weather reading with the crypto helper before sending it on. A community weather map can trust the numbers.

    Add: weather sensor, serial radio module.

  • Two-core task splitter

    Run sensor reading on one core and display updates on the other. It teaches how small chips share work.

    Add: small screen.

How open is it?

Level 3 of 3. Wild Open shares the most.

The chip itself is closed NXP silicon. The SDK core is under BSD-3-Clause, and Zephyr, the Rust HAL, and Solo 2 firmware are under Apache-2.0. SoloKeys shares the Solo 2 KiCad board files under CERN-OHL-S-2.0. NXP board design files sit behind a free account.

Hardware license: CERN-OHL-S-2.0 (SoloKeys Solo 2 module), none stated (NXP EVK, MCU-Link and OKdo E1) · Software license: BSD-3-Clause (MCUXpresso SDK core), Apache-2.0 (Zephyr, lpc55-hal, Embassy, Solo 2 and Nitrokey 3 firmware)
