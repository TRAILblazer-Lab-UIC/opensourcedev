Overview

The Luckfox Lyra is a tiny Linux board built on the Rockchip RK3506G2 chip. It has three main cores for Linux and a small extra core for real-time jobs. A display connector works with Raspberry Pi DSI screens, which makes it a fit for small touch panels. It suits makers who want a cheap way into embedded Linux.

Good fit or not?

Good for

  • Small touch-screen panels and dashboards
  • Learning Buildroot and embedded Linux on a budget
  • Industrial-style control with CAN and the real-time core
  • Wired network gadgets with the Lyra Plus

Not great for

  • Wireless projects, as the board has no Wi-Fi or Bluetooth
  • Heavy desktop use, given its 128 MB of memory
  • Beginners who want an easy, polished setup
  • Shoppers in the US, with few local stores

Specs in plain words

  • Three Cortex-A7 cores at 1.2 GHz run a light Linux system with a simple screen app.
  • The extra Cortex-M0 core handles precise timing jobs alongside Linux.
  • 128 MB of memory fits a small Linux system with one or two apps.
  • The 2-lane DSI port drives a screen up to 1280 by 800 pixels.
  • 24 flexible pins can become serial, I2C, SPI, PWM, or CAN connections.
  • The board is about 51 by 21 mm, close to a stick of gum.

Core count is the three Cortex-A7 application cores. The Cortex-M0 is extra. flash_kb is the 256 MB SPI NAND on the Lyra B and Lyra Plus. The base Lyra boots from microSD only. Ethernet is on the Lyra Plus only, through a CH182H2 PHY. Size is 51 x 21 mm for the Lyra and 72 x 21 mm for the Lyra Plus per CNX Software. Waveshare lists ADC and a reserved RMII interface on the pins, but no ADC channel count was found. The board has BOOT and RESET buttons, a user LED and a 4-pin USB host connector. Siblings Lyra Ultra, Lyra Zero W and Lyra Pi use the RK3506B with more RAM and are different boards.
