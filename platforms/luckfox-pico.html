Overview

The Luckfox Pico is a very small Linux board built around a Rockchip camera chip. It has a camera connector and a small NPU, which is a chip that speeds up AI models. Prices start near 10 US dollars. It suits makers who know some Linux and want cheap vision or embedded projects.

Good fit or not?

Good for

  • Tiny network cameras
  • Simple vision AI like spotting people or objects
  • Learning how embedded Linux works
  • Projects where size and price matter most

Not great for

  • Big programs, as 64 MB of memory is very tight
  • Wireless projects, as it has no Wi-Fi or Bluetooth
  • Beginners who want a desktop and plug-in ease
  • Fully open software, as the AI tools are closed

Specs in plain words

  • One 1.2 GHz Cortex-A7 core is slow by PC standards but fine for one focused job.
  • 64 MB of memory fits a light Linux and one small program at a time.
  • The 0.5 TOPS NPU can run small image models such as a person detector.
  • The camera chip handles video up to 4 megapixels at 30 frames per second.
  • Up to 24 pins connect buttons, sensors and small screens.
  • The base board is 51 by 21 millimeters, about the size of a stick of gum.
Full spec sheet
ProcessorRockchip RV1103 (Cortex-A7 1.2 GHz plus RISC-V MCU), 1 core at 1.2 GHz
Memory64 MB
StoragemicroSD card
AI chipRockchip NPU, 0.5 TOPS INT8 (1 TOPS INT4), 4 MP ISP, H.264/H.265 encoder 0.5 TOPS
Pins24 pins, 2 analog inputs
Ways to connect partsI2C, SPI, Serial (UART), USB device, USB host, Camera port (MIPI CSI)
ConnectorsUSB-C, Pin headers, microSD slot, Camera connector
Built inbuttons
Power5 V over USB-C
Size51 x 21 mm

Values are for the base Luckfox Pico. It boots from microSD with no onboard flash. As a result, flash_kb is null. The Pico Mini B and Pico Plus add 128 MB SPI NAND. The Pico Mini has 17 GPIO and measures 28.14 x 21 mm. The Pico Plus is 72 x 21 mm and adds 10/100 Ethernet with an RJ45 jack. The base Pico has Ethernet only as test pads. CNX Software's 2023 launch article listed a 0.8 TOPS NPU, but the current wiki and Waveshare list 0.5 TOPS INT8. The SoC has a built-in audio codec exposed on pads.

Builder ideas

  • Tiny network camera

    Attach a camera and stream live video to your laptop. Watch the front door or a 3D printer.

    Uses: Camera, Runs Linux. Add: camera module, microSD card.

  • Plant growth time lapse

    Snap a photo of a seedling every hour. Stitch the shots into a short growth movie for science class.

    Uses: Camera, Runs Linux. Add: camera module, microSD card.

  • Embedded Linux learning kit

    Log in over USB and learn the command line on a real Linux board. Rebuild the system with the SDK later.

    Uses: Runs Linux. Add: microSD card, USB serial adapter.

  • Sensor logger with Python

    Wire a temperature sensor to the pins and read it with Blinka in Python. Save readings to the card.

    Uses: Runs Linux. Add: temperature sensor, jumper wires.

  • Mini screen dashboard

    Connect a small SPI screen and run an LVGL demo. Show the time, weather or sensor values.

    Uses: Runs Linux. Add: small SPI screen, jumper wires.

  • Wired network gadget

    Use the Pico Plus with its Ethernet jack as a tiny network monitor. It checks that your home internet stays up.

    Uses: Runs Linux. Add: network cable.

Expert ideas

  • Person detector

    Run an object detection model on the NPU. The board flags a person in view and logs the time.

    Uses: Camera, AI chip, Runs Linux. Add: camera module.

  • Bird feeder watcher

    Point a camera at a feeder and save a photo each time a bird lands. Build a nature album over a season.

    Uses: Camera, AI chip, Runs Linux. Add: camera module, weatherproof box, USB power bank.

  • Smart doorbell camera

    Add a button and a camera near the door. A press saves a photo of the visitor.

    Uses: Camera, Runs Linux. Add: camera module, push button.

  • USB keyboard macro box

    Read a USB keypad on the host port and send commands across the network. Trigger lights or music with one key.

    Uses: Runs Linux, Plugs in USB gadgets. Add: USB keypad.

  • Gesture counter for exercise

    Use the camera and a small AI model to count jumping jacks. Show the count on a small screen.

    Uses: Camera, AI chip, Runs Linux. Add: camera module, small SPI screen.

  • Robot eye

    Mount the board and camera on a small robot. Send simple color tracking results to the robot's motor board.

    Uses: Camera, Runs Linux. Add: camera module, robot chassis, microcontroller motor board.

How open is it?

Open Board

Luckfox posts PDF schematics for each board, but no layout files or license. The SDK on GitHub uses open parts such as Linux, Buildroot and U-Boot, with no overall license stated. The NPU runtime, media libraries and Rockchip chip stay closed.
