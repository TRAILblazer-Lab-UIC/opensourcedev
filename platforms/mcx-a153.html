Overview

The MCX A153 is an entry-level microcontroller from NXP with one Arm Cortex-M33 core at up to 96 MHz. It has 128 KB of flash, 32 KB of RAM, a USB port, and motor control timers. Makers use it on the FRDM-MCXA153 board, which costs about 15 dollars and includes a debugger. It suits people learning embedded C or Zephyr on a budget.

Good fit or not?

Good for

  • Learning embedded C with a real debugger built in
  • First steps in the Zephyr real-time operating system
  • Motor control experiments with PWM and encoders
  • Low-power sensor nodes that sleep most of the time

Not great for

  • Beginners who want Arduino or Python, as code is C only
  • Wireless projects, as the chip has no radio
  • Big programs or graphics, with only 32 KB of RAM

Specs in plain words

  • 96 MHz is plenty fast for reading sensors and driving motors.
  • 128 KB of flash holds a modest program of a few thousand lines.
  • 32 KB of RAM holds a few hundred sensor readings at once.
  • The 12-bit ADC reads analog sensors in 4,096 steps.
  • Power-down mode draws 6.5 microamps, which lets a battery last a long time.
  • The onboard MCU-Link debugger lets you pause code and step through it line by line.

Chip values come from CNX's summary of NXP's launch data and the NXP and Zephyr board pages. GPIO is up to 52 on the 64-pin LQFP package used on the FRDM board. ADC inputs are up to 24 across the family. The exact A153 count was not confirmed. Zephyr lists 24 KiB of usable RAM against 32 KB in its overview. Up to 8 KB of SRAM can run with ECC. low_power_ua is the 6.5 uA power-down figure with full SRAM retention. Deep power-down is 394 nA. The chip also has I3C, which is not in the interface list. Connector and onboard values are for the FRDM-MCXA153, which has two USB-C ports (one for the MCU-Link debugger), Arduino, FRDM and mikroBUS headers, an unpopulated Pmod header, a P3T1755 temperature sensor, an RGB LED and buttons.

Things you could build

11 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blinking RGB LED

    Run the first SDK example and change the LED colors. It is a quick check that the tools work.

  • Desk temperature logger

    Read the onboard temperature sensor every minute. Print the readings to a computer for a home science chart.

    Uses: Sensors built in.

  • Custom USB keypad

    Use the USB port to act as a keyboard. Wire up a few buttons as shortcut keys for drawing or music apps.

    Add: push buttons, jumper wires.

  • Fan speed controller

    Drive a small DC fan with the PWM outputs. Speed it up as the onboard sensor reads a warmer room.

    Uses: Sensors built in. Add: small DC fan, motor driver board.

  • Click board sensor station

    Plug a sensor board into the mikroBUS socket. Read light, air quality, or distance with little wiring.

    Add: mikroBUS sensor board.

  • Garden soil monitor

    Read a soil sensor with the fast 12-bit ADC. Blink the LED red when a pot needs water.

    Add: soil moisture sensor.

  • Simple synth tone maker

    Make tones on a PWM pin and play them through a small speaker. Buttons pick the notes.

    Add: small speaker, push buttons.

Expert ideas

  • Robot wheel speed reader

    Read a wheel encoder with the quadrature decoder. Measure how far a small robot travels.

    Add: DC motor with encoder, motor driver board.

  • Coin cell sensor node

    Use the deep sleep modes to wake once a minute and take a reading. A small battery can last a long time.

    Uses: Sips power. Add: coin cell holder, jumper wires.

  • Zephyr first steps

    Build the Zephyr blinky sample for this board. Learn how a real-time operating system runs tasks.

  • Brushless motor lab

    Use FlexPWM and the comparators to spin a small brushless motor. It is a classic motor control exercise.

    Add: small brushless motor, motor driver board, power supply.

NXP shares the board schematic and design files behind a free account, with no open hardware license stated. The MCUXpresso SDK is open under BSD-3-Clause, and Zephyr uses Apache-2.0. The chip itself, NXP's IDE, and the MCU-Link firmware stay closed.
