Overview

The Milk-V Jupiter is a motherboard in the standard Mini-ITX size, built on the eight-core SpacemiT K1 or M1 RISC-V chip. It fits ordinary PC cases and power supplies. It runs Bianbu, Ubuntu, and Fedora. It suits developers and curious tinkerers who want a real RISC-V computer for testing and learning.

Good fit or not?

Good for

  • Trying RISC-V Linux on a full-size desktop setup
  • Porting and testing software on RISC-V
  • Home servers with two Gigabit Ethernet ports
  • Learning about vector instructions on real hardware

Not great for

  • Daily desktop use, with speed around old Core 2 Duo level
  • Smooth video, with YouTube playing well only at low quality
  • Wiring sensors, with no general GPIO header
  • Easy buying, with every ARACE version shown unavailable

Specs in plain words

  • Eight RISC-V cores at 1.6 GHz handle servers and builds, but feel slow for a modern desktop.
  • 4, 8, or 16 GB of memory is enough for a desktop, a browser, and a few services.
  • 2 TOPS of AI comes from extra instructions in the CPU. It runs small image models.
  • The M.2 slot takes a fast NVMe drive, although reviews measured it at one PCIe lane.
  • The board measures 170 by 170 mm. That is a standard small PC motherboard.

Clock is the K1 default of 1.6 GHz. The M1 runs at 1.8 GHz by default. RAM is the 8 GB K1 model. A 4 GB K1 and a 16 GB M1 were also sold. The board has SPI boot flash and an eMMC connector but no eMMC fitted by default. As a result, flash_kb is null. The 2 TOPS figure comes from AI instructions in the CPU. It is not a separate NPU. M.2 NVMe is PCIe 2.0 x2 on paper, but Jeff Geerling measured x1. No general GPIO header was listed. Other headers are a PWM fan connector, CR1220 RTC socket, front panel header, two SATA power outputs and a UART debug header.

Things you could build

12 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • First RISC-V desktop

    Flash Ubuntu or Bianbu, plug in a screen and keyboard, and browse the web on a RISC-V computer. It shows a new kind of chip at work.

    Uses: Runs Linux, Screen. Add: HDMI monitor, USB keyboard and mouse, 12 V power supply.

Builder ideas

  • Home file server

    Add an NVMe drive and share family photos over the home network. Two Ethernet ports give room for a fast wired link.

    Uses: Runs Linux, Wired network. Add: NVMe drive, network cable.

  • Network ad blocker

    Run a network-wide ad blocker on the board. Every device in the house gets cleaner web pages.

    Uses: Runs Linux, Wired network. Add: network cable.

  • Classroom RISC-V lab

    Let students compile small C and Python programs on real RISC-V hardware. They can compare the vector instructions with an emulator.

    Uses: Runs Linux. Add: HDMI monitor, USB keyboard and mouse.

  • Retro game corner

    Run simple emulators for old game consoles and plug in a USB controller. Older 2D games suit its modest speed.

    Uses: Runs Linux, Screen, Plugs in USB gadgets. Add: USB game controller, HDMI monitor.

  • Music jukebox for the shop

    Play a music library through the audio jack into a pair of speakers. Pick songs from a phone over Wi-Fi.

    Uses: Runs Linux, Makes sound, Wi-Fi. Add: powered speakers.

  • Weather data station

    Plug a USB weather sensor into the board and log readings to a database. Graph the week on a web page.

    Uses: Runs Linux, Plugs in USB gadgets. Add: USB weather sensor.

  • Self-hosted community wiki

    Host a wiki for a club or maker space on the board. Members can reach it over the local network.

    Uses: Runs Linux, Wired network. Add: NVMe drive.

  • Bluetooth sensor hub

    Collect readings from Bluetooth temperature tags around the house. Save them on the board and show trends.

    Uses: Runs Linux, Bluetooth. Add: Bluetooth temperature tags.

Expert ideas

  • Port your favorite app

    Build an open-source program from source and see what breaks on RISC-V. Share your fixes with the project.

    Uses: Runs Linux.

  • Home lab router

    Use the two Gigabit ports to build a test router and firewall. It is a safe place to learn networking.

    Uses: Runs Linux, Wired network. Add: network cables.

  • Small AI image sorter

    Try SpacemiT's AI instructions on a small image model. Sort a folder of garden photos into flowers and weeds.

    Uses: Runs Linux, AI chip.
