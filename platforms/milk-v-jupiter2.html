Overview

The Milk-V Jupiter2 is a small single-board computer built on the SpacemiT K3 chip. It has eight RISC-V cores that follow the new RVA23 profile and eight extra AI cores. It ships as a kit in an aluminum case with a fan. It suits developers who want an early RVA23 Linux desktop and a place to test AI on RISC-V.

Good fit or not?

Good for

  • Running RVA23 Linux distributions like Ubuntu 26.04
  • Testing small AI models on RISC-V
  • Fast networking with a 10 Gigabit SFP+ port
  • A smooth RISC-V desktop with working Vulkan graphics

Not great for

  • Tight budgets, with kits from about $399
  • Large AI models, with slow memory for anything above about 3 billion parameters
  • Wiring sensors, with no Pi-style GPIO header
  • Fully open AI work, with closed AI libraries

Specs in plain words

  • Eight cores at up to 2.4 GHz feel smooth on a desktop, but each core trails current Arm boards.
  • 8, 16, or 32 GB of memory runs a desktop, a browser, and a small AI model at once.
  • 60 TOPS is the INT4 rating for the AI cores. Real models depend on SpacemiT's closed library.
  • Onboard UFS storage of 128 or 256 GB works like a fast built-in drive.
  • The board is 100 by 86 mm, about the size of a large coaster.
  • USB-C power up to 65 W means a laptop charger can run it.

RAM comes in 8, 16 and 32 GB versions. The 16 GB middle option is shown. UFS is 128 or 256 GB depending on version. The 128 GB value matches the reviewed unit. The 60 TOPS figure is for INT4 on the A100 AI cores. The page names no separate NPU. Cellular needs an M.2 B-Key modem and a Nano SIM. CAN-FD and EtherCAT come through two RT I/O FPC connectors. The board has no Pi-style GPIO header, and the microSD slot is on the module version only. The official page uses both X100 and A100 for the main cores. CNX and the review name X100 as the main cores.

    Uses: Runs Linux, AI chip. Add: USB webcam.

    Uses: Runs Linux, Makes sound. Add: USB-C monitor or TV adapter, powered speakers.

Level 1 of 3. Wild Open shares the most.

The OS images use an open Linux 6.18 kernel, and the GPU works with Vulkan 1.3. No schematics, layout files, or hardware license were found. The SpacemiT AI libraries are closed, and the chip design is proprietary.

Software license: Kernel GPL-2.0. SpacemiT ONNX Runtime and TCM libraries are closed binaries
