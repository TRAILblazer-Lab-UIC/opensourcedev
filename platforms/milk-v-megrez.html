Milk-V Megrez

Milk-V

A mini-ITX RISC-V motherboard with an AI engine for desktop builds.

Overview

The Milk-V Megrez is a mini-ITX motherboard that fits a normal small PC case. Its ESWIN chip has four RISC-V cores and an AI engine rated near 20 TOPS. It comes with 8 to 32 GB of fast memory soldered on. It suits developers who want a RISC-V desktop or a workstation for trying on-device AI.

Specs in plain words

  • Four P550 cores are faster per clock than many older RISC-V boards.
  • The AI engine at 19.95 TOPS can run image and language models on the board.
  • 16 GB of memory holds many browser tabs, a code editor, and a small AI model at once.
  • Mini-ITX size means it fits common small PC cases and uses a normal ATX power supply.
  • The PCIe slot accepts a graphics card or a network card.
  • SATA ports let you add ordinary hard drives or SSDs.

RAM comes in 8, 16 and 32 GB versions. The 16 GB launch model is shown. Storage is on microSD, an eMMC module, M.2 SATA or the SATA port, and SPI flash holds the bootloader. As a result, flash_kb is null. Milk-V pages list 1.8 GHz. By contrast, the riscv.org listing says 1.6 GHz. The docs include a frequency adjustment page. As a result, the default clock may be lower than 1.8 GHz. The M.2 E-Key slot takes a Wi-Fi and Bluetooth card over SDIO and UART. Wi-Fi is not on the board. The board has no Pi-style GPIO header. The JTAG port is listed as a debug interface.

Builder ideas

  • Build a RISC-V desktop PC

    Put the board in a mini-ITX case with an ATX power supply and storage. You get a real desktop that runs a RISC-V Linux system.

    Uses: Runs Linux, Screen, Plugs in USB gadgets. Add: mini-ITX case, ATX power supply, SATA SSD, HDMI monitor, USB keyboard and mouse.

  • Home media server

    Store movies on a SATA drive and stream them to TVs over the network. Two network ports give room for a home lab.

    Uses: Runs Linux, Wired network. Add: SATA hard drive, network cable.

  • Classroom Jupyter server

    Host Jupyter notebooks for a coding class. Students open them in a browser on the school network.

    Uses: Runs Linux, Wired network. Add: network cable.

  • Family game and music corner

    Hook up a monitor and speakers for simple open-source games and music. A USB gamepad makes it couch friendly.

    Uses: Runs Linux, Screen, Makes sound, Plugs in USB gadgets. Add: HDMI monitor, powered speakers, USB gamepad.

  • Science data cruncher

    Load sensor logs from a school project and chart them with Python. The large memory handles big data files with ease.

    Uses: Runs Linux.

  • Community archive box

    Uses: Runs Linux, Wired network. Add: SATA hard drive.

Expert ideas

  • Native compile station

    Build big programs such as LLVM or Node.js right on the board. It saves you from cross-compiling on another computer.

    Uses: Runs Linux. Add: SATA SSD.

  • Private chat assistant

    Run a small language model with Ollama on the 32 GB version. Ask it questions without sending data to the cloud.

    Uses: Runs Linux, AI chip. Add: SATA SSD.

  • Photo sorter with AI

    Use the NPU to tag family photos by what they show. Search your pictures by words like beach or dog.

    Uses: Runs Linux, AI chip. Add: SATA hard drive.

  • Webcam object counter

    Plug in a USB webcam and run a detection model on the NPU. Count cars on your street or visitors at a door.

    Uses: Runs Linux, AI chip, Plugs in USB gadgets. Add: USB webcam.

  • Home lab router

    Use the two Gigabit Ethernet ports to build a firewall for your network. Watch traffic and block unwanted sites.

    Uses: Runs Linux, Wired network. Add: two network cables.

  • Graphics card experiments

    Add a graphics card to the PCIe slot and test it on RISC-V. Share what works with the community forum.

Milk-V shares the schematic, part placement sheets, and outline drawings on GitHub. No board layout files are published, and the repo has no license file. Linux, U-Boot, and OpenSBI build from open sources under GPL-2.0 and BSD-2-Clause. The GPU, the AI engine tools, and the chip itself stay closed.
