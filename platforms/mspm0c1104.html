Overview

The MSPM0C1104 is a very small and very cheap Arm chip from Texas Instruments. TI called it the world's smallest microcontroller at its March 2025 debut. Its tiniest version is about the size of a fleck of pepper. It suits people who want to learn low-level C or Rust and build simple single-job gadgets.

How the scores work

Good fit or not?

Good for

  • Simple jobs like reading one sensor or blinking lights
  • Learning bare-metal C or Rust with Embassy
  • Battery gadgets that sleep most of the time
  • Replacing old 8-bit chips in small designs

Not great for

  • Beginners, as there is no Arduino or Python support
  • Projects with lots of data, as working memory is only 1 KB
  • Wireless projects, as it has no radio or USB
  • Hand soldering the smallest package, which is a tiny ball grid

Specs in plain words

  • 24 MHz is plenty fast for blinking lights, reading buttons, and checking sensors.
  • 16 KB of storage holds a small program of a few hundred lines.
  • 1 KB of working memory fits only a few dozen numbers at once.
  • The 12-bit analog input reads sensor voltages in about 4,000 steps.
  • In standby it sips about 5 millionths of an amp and still remembers its data.
  • The smallest package is about 1.6 by 0.9 millimeters.

Chip values come from the TI product page. GPIO and ADC counts are for the 20-pin packages. The 8-pin packages have 6 GPIO and 3 ADC channels, and the 16-pin package has 14 GPIO and 8 ADC channels. low_power_ua is STANDBY with SRAM retention. SHUTDOWN draws 200 nA. RUN draws 87 uA per MHz. size_mm is the smallest DSBGA (YCJ) package. The LaunchPad board size was not found. Board values are for the LP-MSPM0C1104 LaunchPad, which uses the 20-pin VSSOP chip and also has a footprint for the 20-pin WQFN. The LaunchPad has an XDS110 debug probe, a backchannel UART, one user button, one red LED, a reset button and 20-pin BoosterPack headers. The chip has no USB. The LaunchPad's micro-USB port goes to the XDS110 probe.

Things you could build

10 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blinking night light

    Blink or fade an LED with the built-in timers. It makes a soft glow for a hallway.

    Add: LED, resistor.

  • Button light switch

    Press a button to step through light patterns on a few LEDs. It is a good first project in C.

    Add: push button, LEDs.

  • Plant thirst alarm

    Read a soil moisture probe with the analog input. A red LED lights up when the soil is dry.

    Add: soil moisture sensor, LED.

  • Fan speed controller

    Use the PWM timer to set a small fan's speed. A knob on the analog input picks the speed.

    Add: small fan, transistor, knob.

  • Servo flag waver

    Drive a hobby servo with a PWM output. It waves a flag at set times for a classroom demo.

    Add: servo motor.

  • Door open counter

    Count door openings with a magnetic switch. Read the total over the serial port on a laptop.

    Uses: Sips power. Add: magnetic door switch.

  • Tiny LED color mixer

    Mix red, green, and blue light with three PWM outputs. Three knobs set the color for an art piece.

    Add: RGB LED, three knobs.

Expert ideas

  • Coin cell temperature tag

    Wake once a minute to read the built-in temperature sensor. Sleep the rest of the time to save a coin cell.

    Uses: Sips power. Add: coin cell holder.

  • Sensor helper chip

    Read an analog sensor and pass clean numbers to a bigger board over I2C. It frees the bigger board for other work.

    Add: analog sensor, main board.

  • Custom tiny circuit board

    Design your own small board with the TSSOP or VSSOP version of the chip. It can replace an old 8-bit chip in a gadget.

    Add: custom circuit board, soldering iron.
