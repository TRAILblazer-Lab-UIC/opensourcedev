Nordic Thingy:53

Nordic Semiconductor

A pocket sensor box with Bluetooth, Thread, and machine learning demos.

Overview

The Nordic Thingy:53 is a small battery-powered sensor box built on the dual-core nRF5340 chip. It packs air, light and color, motion, and compass sensors plus a microphone and a buzzer into one case. It speaks Bluetooth, Thread, Zigbee, and Matter. It ships ready to run machine learning demos from a phone app, which makes it handy for quick smart home and sensor trials.

Good fit or not?

Good for

  • Trying sensor and machine learning demos with no code
  • Smart home projects with Matter, Thread, or Zigbee
  • Battery-powered sensor prototypes in a neat case
  • Learning Zephyr with a sensor-rich board

Not great for

  • Wi-Fi projects without the separate nRF7002 add-on board
  • Beginners who want Arduino or Python, as code is written in C
  • Wired debugging without an extra J-Link or Nordic dev kit
  • Projects that need many free pins

Specs in plain words

  • Two processor cores split the work. One runs your app and one runs the radio.
  • 1 MB of storage holds a full sensor app with room for updates.
  • 512 KB of working memory fits small machine learning models.
  • The 1500 mAh battery lets it run unplugged and charges over USB-C.
  • A radio booster gives Bluetooth and Thread a longer range across a home.
  • The 4-pin plug takes Qwiic, STEMMA QT, and Grove add-ons with no soldering.

RAM and flash are the application core values. The network core adds 64 KB RAM and 256 KB flash, and the board adds external QSPI NOR flash. Zephyr names the sensors as a Bosch BME680 environmental sensor, BMI270 IMU, ADXL362 accelerometer and BMM150 magnetometer. The color sensor part was not confirmed from a fetched page. The speaker entry is a 4 kHz buzzer. The 4-pin JST port is described by Nordic as Stemma, Qwiic and Grove compatible. Battery was 1350 mAh on v1.0.0 and earlier boards. Wi-Fi needs the separate nRF7002 Expansion Board. Size was not found.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansFull design files
  • Hardware licenseNot confirmed
  • Coding toolsMostly open
  • The chip itselfClosed chip design

Nordic shares the full Altium design files, Gerbers, and case models for free. Its license allows reuse only with Nordic chips. That falls short of true open hardware. The nRF Connect SDK and Zephyr are open source, but parts of the Bluetooth stack ship as closed binaries. The nRF5340 chip design stays closed.

Hardware license: Nordic 5-Clause (BSD-style, use restricted to Nordic chips) · Software license: LicenseRef-Nordic-5-Clause (nRF Connect SDK) and Apache-2.0 (Zephyr)
