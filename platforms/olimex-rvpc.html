Overview

The RVPC is a tiny retro computer kit from Olimex that costs about one euro. You solder it together yourself. It plugs into a VGA monitor and a PS/2 keyboard. A built-in monitor program lets you explore RISC-V machine code by hand.

Good fit or not?

Good for

  • Learning to solder with an easy through-hole kit
  • Seeing how a computer works at the machine code level
  • Classroom builds on a very small budget
  • Retro computing fans who like small puzzles

Not great for

  • Adding sensors or extra parts with zero free pins
  • Color graphics on its one-color VGA output
  • Anyone without an old VGA monitor and PS/2 keyboard
  • General computing tasks such as web or files

Specs in plain words

  • The CH32V003 chip runs at 48 MHz, which is fast enough to draw a simple VGA picture.
  • 2 KB of memory holds about one short page of text.
  • 16 KB of flash holds one small program or game at a time.
  • Six pins drive the VGA port, the keyboard, and the buzzer, with none left over.
  • The board is 50 by 30 mm, about the size of a matchbox.

The SO8 CH32V003 has 6 usable GPIOs, and all are used. VGA takes 3, PS/2 takes 2 and the buzzer takes 1. As a result, none are free for expansion. The RGB lines are merged. As a result, the VGA output is one color. A commenter on CNX estimated about 320 x 240 effective resolution. The VGA and PS/2 ports do not fit the connector vocabulary. The headers entry is the 2-pin programming header. The onboard speaker entry is a buzzer.

Starter ideas

  • Solder your first computer

    Build the through-hole kit with a soldering iron. You end up with a working computer you put together yourself.

    Add: soldering iron, solder.

  • Classroom soldering day

    Give each student a kit at about one euro each. Everyone takes home a computer they built.

    Add: soldering irons, solder.

Builder ideas

  • Peek inside memory

    Use the built-in monitor to read and change memory bytes. You see how a computer stores numbers.

    Add: PS/2 keyboard, VGA monitor.

  • Play falling-block puzzle

    Flash the Tetris demo and play on a VGA monitor. Friends can take turns for high scores.

    Uses: Makes sound. Add: one-wire SWIO programmer, PS/2 keyboard, VGA monitor.

  • Towers of Hanoi lesson

    Run the Towers of Hanoi demo in class. Students watch a classic puzzle solved step by step.

    Add: one-wire SWIO programmer, VGA monitor.

  • Tiny BASIC computer

    Load the community BASIC interpreter. Kids type short programs like the home computers of the past.

    Add: one-wire SWIO programmer, PS/2 keyboard, VGA monitor.

  • Buzzer tune player

    Write a short C program that plays a melody on the buzzer. Change the notes to make your own song.

    Uses: Makes sound. Add: one-wire SWIO programmer.

Expert ideas

  • Hand-typed machine code

    Type a short RISC-V program in hex and run it. The screen shows what each instruction did.

    Add: PS/2 keyboard, VGA monitor.

  • Typing reaction game

    Show a random letter on screen and beep. The player races to press the matching key.

    Uses: Makes sound. Add: one-wire SWIO programmer, PS/2 keyboard, VGA monitor.

  • Pixel art screen
