Overview

The OrangeCrab is a small FPGA board in the Adafruit Feather shape, designed by Greg Davill. An FPGA is a chip you rewire with code to become almost any digital circuit. The OrangeCrab is discontinued, and new boards are hard to find in 2026. It stands out for its open design files, large memory and a USB-C port that connects straight to the FPGA.

  • Wireless projects, as it has no radio

Specs in plain words

  • The 25F chip has about 24,000 logic cells. That is room for a full soft processor plus extra circuits.
  • 128 MB of memory on the 25F is enough for a soft processor to run large programs or even a tiny Linux.
  • 16 MB of flash stores your design and some data after you unplug.
  • A microSD slot holds extra files, such as logged readings or a boot image.
  • The board measures about 23 by 51 millimeters, roughly the size of a stick of gum.
  • A battery plug and charger let it run from a small rechargeable cell.

Values are for the 25F variant, the most common one. The 85F has 84K LUTs, 3744 Kb block RAM, 156 multipliers and 4 PLLs. ram_kb is the 128 MB DDR3L. The README lists 512 MB DDR3L as the larger option. The FPGA also has 1008 Kb block RAM and 194 Kb distributed RAM. clock_mhz is the 48 MHz onboard oscillator. The FPGA has 2 PLLs. The ADC is built from an analog mux plus an FPGA RC and comparator. As a result, adc_channels is left null. USB is soft logic in the FPGA. The JTAG pads are a 0.1 inch breakout. The Lattice page mentions micro USB, but the r0.2 boards use USB-C.

Things you could build

13 ideas sized to what this board can do. Starter ideas suit first-time builders.

Builder ideas

  • Blink the RGB LED

    Write a short Verilog design that cycles the onboard color LED. Load it over USB with dfu-util.

  • Button color mixer

    Use the onboard button to step through colors on the RGB LED. It is a gentle first taste of state machines.

  • Battery powered light badge

    Run the board from a small rechargeable battery and animate a strip of LEDs. Wear it at a maker fair or concert.

    Uses: Battery ready. Add: small lithium battery, LED strip.

  • Servo sweep for a robot arm

    Make precise pulse signals for several servos at once. Use them to move a small cardboard robot arm.

    Add: servo motors, jumper wires.

  • Frequency counter for science class

    Measure how fast a signal flips on and off. Test a buzzer, a fan sensor or a signal generator.

    Add: jumper wires.

Expert ideas

  • Build a RISC-V computer

    Use LiteX to put a RISC-V soft processor on the FPGA. Then run your own C programs on a computer you assembled.

  • CircuitPython on a soft core

    Load a LiteX system that runs CircuitPython. Then write simple Python scripts on a chip you built from logic.

  • Linux on a homemade processor

    Use the large memory on the 85F model to boot a tiny Linux on a soft core. It shows how a whole computer fits in one chip.

    Add: microSD card.

  • Pocket logic analyzer

    Capture fast signals from another gadget and send them to your computer. It helps you spy on how chips talk.

    Add: jumper wires.

  • Portable data logger for the trail

    Read a temperature sensor on a hike and save the readings to a microSD card. The battery charger keeps it going between trips.

    Uses: Battery ready. Add: small lithium battery, temperature sensor, microSD card.

  • Custom USB gadget

    Turn the board into your own USB device, such as a special keyboard or game pad. The USB port connects straight to the FPGA.

    Add: push buttons.

  • Synth voice in hardware

    Build oscillators and filters in logic and play notes through a small speaker. Each note runs on its own circuit at once.

    Add: small speaker, small amplifier board.

  • LED matrix art panel

    Drive a grid of color LEDs with patterns and scrolling text. Hang it in a classroom or hallway.

    Add: LED matrix panel, 5 V power supply, jumper wires.

How open is it?

Wild Open

The full KiCad design files are public under the CERN OHL 1.2 license. The board holds OSHWA certification AU000015, and its gateware and software use the MIT license. The design tools are open, but the Lattice ECP5 chip itself stays closed.
