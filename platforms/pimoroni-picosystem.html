Overview

PicoSystem is a pocket game console from Pimoroni with a Raspberry Pi RP2040 chip inside. It has a small square color screen, a D-pad, four action buttons, a speaker, and a rechargeable battery. The milled metal case makes it feel like a real handheld. It suits anyone who wants to learn game programming in MicroPython, CircuitPython or C++.

Good fit or not?

Good for

  • Learning to make simple video games
  • Coding lessons with a fun result on screen
  • Porting and playing small retro style games
  • Taking homemade games on the go

Not great for

  • Wireless projects, as it has no radio
  • Adding sensors or motors, as it has no reachable pin header
  • Large 3D games, as the chip is small
  • Buyers in the US, as some stores have run out

Specs in plain words

  • Two 133 MHz cores are fast enough for smooth retro style games.
  • 264 KB of working memory holds a small game level and its sprites.
  • 16 MB of storage has room for many games, pictures and sound effects.
  • The 1.54 inch screen is about the size of a postage stamp, with 240 by 240 dots.
  • The 525 mAh battery gives about six hours of play and charges over USB-C.
  • The whole console is about as long as a credit card and a bit thicker than a phone.
Full spec sheet

Ways to connect partsSPI, USB device, Screen bus, Debug port
ConnectorsUSB-C
Built inscreen, buttons, speaker, color LED, battery charger
Power5 V over USB-C or the internal 525 mAh LiPo battery
Size96.6 x 42.7 mm

The flash chip is a W25Q128JV (16 MB) per the schematic. No user GPIO header is exposed. Debug pins are broken out on the PCB but you must remove the case to reach them. As a result, gpio and adc_channels are null. The schematic shows an MCP73831 LiPo charger and an AP2502 LED driver for the backlight. Size is 96.6 x 42.7 x 15.5 mm including buttons, per Pimoroni.

How open is it?

Openness level

Level 2 of 3. Wild Open shares the most.

  • Board plansSchematics only

Pimoroni publishes a schematic PDF with no license and no board layout files. The PicoSystem API and the 32blit SDK are open source under the MIT license, and the Pico SDK uses BSD-3-Clause. The console has no radio and needs no closed firmware. The RP2040 chip design itself is closed.
