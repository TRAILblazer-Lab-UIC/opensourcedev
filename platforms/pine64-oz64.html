Overview

The Oz64 is a low-cost single-board computer from Pine64. It uses the Sophgo SG2000 chip. Its main core can run as RISC-V or Arm, picked with a switch before boot. It suits tinkerers who want to explore RISC-V Linux, Apache NuttX, or small camera projects.

Good fit or not?

Good for

  • Exploring RISC-V and Arm on one board
  • Camera projects with two MIPI camera sockets
  • Network gadgets with Ethernet, Wi-Fi, and Bluetooth
  • Running a real-time system beside Linux on a second core

Not great for

  • Beginners, as the docs still call the board pre-production
  • Desktop use with no HDMI port and only 512 MB of memory
  • People who want a big community or lots of tutorials

Specs in plain words

  • The 1 GHz main core runs a light Linux system for servers and scripts.
  • 512 MB of memory is enough for small services but tight for a desktop.
  • The 0.5 TOPS NPU can run small vision models such as basic object spotting.
  • Wi-Fi 6, Bluetooth 5.2, and 100 Mbps Ethernet cover most home network jobs.
  • The board is 85 by 56 mm, about the size of a credit card.
  • It draws power from a 5 V 2 A barrel plug.

Only one of the two 1 GHz cores runs at a time. As a result, cores counts the active main core, the 700 MHz C906 and the 8051. The Pine64 docs page lists a quad-core Cortex-A53, which conflicts with the SG2000 design and with CNX Software. As a result, that line looks like an error. The header size conflicts. The device page says 40-pin. By contrast, the docs page and CNX Software say 26 pins. As a result, gpio is null. The 0.5 TOPS NPU figure comes from CNX Software. Pine64 pages do not state it. Storage is a microSD card or an optional eMMC module. As a result, flash_kb is null. CNX Software also lists an ATECC608A secure element, an RTC connector, a 3.5 mm audio jack and a built-in microphone. PoE needs an optional expansion board.

    Uses: Hears sound, Makes sound, Runs Linux. Add: headphones, power supply.

    Measure the sound level with the onboard microphone. Chart the noise through the school day.

    Uses: Hears sound, Sensors built in, Runs Linux. Add: power supply, microSD card.

    Plug a USB drive into the USB-A port. Share files with other computers on the home network.

    Uses: Plugs in USB gadgets, Wired network, Runs Linux. Add: USB flash drive, power supply.

    Uses: Wired network, Runs Linux. Add: temperature sensor, jumper wires, power supply.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansSchematics only
  • Hardware licenseNot confirmed
  • Coding toolsMostly open
  • The chip itselfClosed chip design

Pine64 publishes the schematic and part placement PDFs, but no license is stated and no layout files are listed. Linux and Apache NuttX are open, though the NPU SDK and Wi-Fi firmware come from vendors. The SG2000 chip is closed, even though its C906 core design is public as OpenC906.
