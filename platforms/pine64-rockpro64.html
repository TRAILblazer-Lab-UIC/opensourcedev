Overview

The Pine64 RockPro64 is a Linux computer built on the six-core Rockchip RK3399 chip. Its standout feature is an open PCIe slot for NVMe drives, SATA cards and network cards. People often turn it into a home file server or a private cloud box. It suits makers who are comfortable with Linux and want lots of storage.

Specs in plain words

  • Six processor cores at up to 1.8 GHz feel like an older budget laptop.
  • 2 or 4 GB of memory runs a light desktop or a few home servers at once.
  • The PCIe x4 slot takes an adapter for a fast NVMe drive or extra SATA ports.
  • The Gigabit Ethernet port moves big files across a wired home network quickly.
  • The 12 volt barrel jack needs a 3 amp supply, or 5 amps for power-hungry cards.
  • The board is about 13 by 8 centimeters, close to the size of a postcard folded in half.

RAM is the 4 GB LTS model. A 2 GB model was also sold. Pine64 lists the A72 cores at 1.8 GHz. By contrast, CNX Software lists up to 2.0 GHz. The board has a 128 Mbit SPI boot flash and a socket for an optional eMMC module up to 128 GB. As a result, flash_kb is null. Size is 133 x 80 x 19 mm per CNX Software, the same footprint as the original PINE A64. The exact GPIO count on the 40-pin header was not confirmed. Wi-Fi 802.11ac and Bluetooth come only through an optional add-on module. As a result, they are not listed as radios.

How open is it?

Openness level

Open CodeOpen BoardWild Open

Level 2 of 3. Wild Open shares the most.

  • Board plansSchematics only
  • Hardware licenseNot confirmed
  • Coding toolsFully open

Pine64 publishes schematic PDFs, board outline drawings, and a 3D model. No board layout files are listed, and the files carry no stated license. The software comes from community distributions, with Linux and U-Boot under GPL-2.0. The RK3399 chip design is closed.
