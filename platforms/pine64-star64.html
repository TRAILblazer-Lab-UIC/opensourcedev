Overview

The Star64 is a RISC-V single-board computer from Pine64. It uses the StarFive JH7110 chip with four cores and 4 or 8 GB of memory. It adds a full-size PCIe slot, two Ethernet ports, and onboard Wi-Fi. Pine64 calls the software alpha. It suits experts who want to port systems and learn RISC-V.

Good fit or not?

Good for

  • Learning how RISC-V Linux works
  • Porting kernels, distros, and real-time systems
  • Network projects with two Gigabit Ethernet ports
  • Testing PCIe cards on a RISC-V chip

Not great for

  • Beginners. Pine64 says it is for expert users.
  • A daily desktop. HDMI can be flaky on some 4K monitors.
  • Plug-and-play USB. Stock StarFive kernels turn USB off without a patch.
  • Wi-Fi in mainline Linux. The docs say the chip lacks mainline support.

Specs in plain words

  • The four RISC-V cores at 1.5 GHz run a light desktop or a small server.
  • 8 GB of memory gives room for many services at once.
  • The PCIe slot is one lane wide. It is plenty for an SSD or a network card.
  • Two Ethernet ports let the board sit between your modem and your home network.
  • 16 MB of SPI flash holds the boot loader. The board can also start from microSD or eMMC.
  • The board is a little smaller than a postcard.

The 8 GB model is shown. The docs also list 2 GB and 4 GB memory options, and the store sells 4 GB and 8 GB. flash_kb is the 16 MB SPI NOR boot flash. eMMC is an optional plug-in module up to 128 GB. The 40-pin header lets any non-power pin take any function from the JH7110 pin mux table. As a result, a fixed GPIO count is not given. The docs name a Fn-Link 6252B module. By contrast, the bringup notes and CNX Software name an RTL8852BU USB Wi-Fi 6 module. The board has a boot-source DIP switch.

Things you could build

Builder ideas

  • Learn RISC-V Linux

    Boot DietPi or Armbian and explore a RISC-V system from the command line. Compare it with an Arm or x86 computer.

    Uses: Runs Linux. Add: microSD card, 12 V power supply.

  • Network ad blocker

    Run a DNS ad blocker on the board. Every device at home sees fewer ads.

    Uses: Wired network, Runs Linux. Add: Ethernet cable.

  • Classroom computer architecture lab

    Let students compare RISC-V machine code with other chips. The board makes an open instruction set feel real.

    Uses: Runs Linux, Screen. Add: HDMI monitor, USB keyboard.

  • Music player for the workshop

    Play music through the audio jack from a file share on the network. Pick songs from a phone over Wi-Fi.

    Uses: Makes sound, Wi-Fi, Runs Linux. Add: powered speakers.

  • Weather station on the GPIO header

    Wire a temperature and pressure sensor to the 40-pin header. Log the readings and chart them each week.

    Uses: Runs Linux. Add: temperature and pressure sensor, jumper wires.

Expert ideas

  • Two-port home router

    Use the two Gigabit Ethernet ports to build a small router or firewall. Watch the traffic on your home network.

    Uses: Wired network, Runs Linux. Add: Ethernet cables.

  • Fast storage with a PCIe card

    Fit an NVMe or SATA card in the open-ended PCIe slot. Store backups and media for a small home server.

    Uses: Runs Linux. Add: PCIe NVMe adapter card, NVMe SSD.

  • Try a real-time OS

    Boot Apache NuttX on the board. Blink an LED from the 40-pin header and learn how a small OS works.

    Add: LED, resistor, jumper wires, 3.3 V serial adapter.

  • Port an operating system

    Bring up a new kernel or distro on the JH7110 chip. Share your patches with the community.

    Uses: Runs Linux. Add: 3.3 V serial adapter.

  • Garden camera logger

    Connect a MIPI camera and take a photo every hour. Build a time-lapse of the garden season.

    Uses: Camera, Runs Linux. Add: MIPI CSI camera.

  • Build a custom Linux with Yocto

    Build a lean Linux image with Yocto for a single job. Learn how embedded Linux products are made.

    Uses: Runs Linux.

  • Bluetooth sensor hub

    Collect readings from Bluetooth sensors around the house. Show them on a small web page.

    Uses: Bluetooth, Wi-Fi, Runs Linux. Add: Bluetooth temperature sensors.

How open is it?

Openness level

Level 2 of 3. Wild Open shares the most.

Pine64 publishes the production and prototype schematics as PDFs. No layout files are offered and no hardware license is stated. Linux and U-Boot are open under GPL-2.0, and the RISC-V instruction set is an open standard. The JH7110 chip, its SiFive cores, and its Imagination GPU driver stay closed.
