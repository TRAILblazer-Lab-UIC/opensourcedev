Overview

The StarPro64 is a single-board computer from Pine64 with a RISC-V processor. It has four cores, up to 32 GB of fast memory, and an AI chip rated near 20 TOPS. Pine64 says it can run a 7B language model on that chip. It suits developers and tinkerers who want to test RISC-V and local AI on alpha software.

Good fit or not?

Good for

  • Running small language models at home with no cloud service
  • Learning and testing software on RISC-V chips
  • Fast storage and add-on cards through the PCIe slot
  • Network projects that need two wired ports

Not great for

  • First-time users, as the software is still marked alpha
  • Plug-and-play setups, as the heatsink is sold separately
  • Battery projects, as it needs a 12 V wall supply
  • Shoppers in the US, as only the Pine64 store lists it

Specs in plain words

  • 32 GB of memory is as much as many desktop computers. It leaves room for a 7B AI model.
  • An AI chip rated at 19.95 TOPS handles trillions of simple math steps each second for vision and language models.
  • Four SiFive P550 cores run at up to 1.8 GHz. Reviewers compare the speed to an older phone chip.
  • A PCIe Gen3 x4 slot accepts a fast drive or an add-on card.
  • Wi-Fi 6, Bluetooth 5.3, and two Gigabit Ethernet ports cover wireless and wired networking.
  • The board measures about 133 by 80 mm, a little larger than a postcard folded in half.

The 32 GB model is shown because it is the only version on sale. The device page lists 8, 16 and 32 GB options. flash_kb is the 16 MB GD25LQ128E SPI NOR boot flash. eMMC is an optional plug-in module. The Pine64 docs list 1.8 GHz. By contrast, Liliputing, CNX Software and the NuttX docs give 1.4 GHz. The Wi-Fi and Bluetooth module is an AIC8800D80. Interface list for the 40-pin header is taken from the Star64 sibling and the Pi2 header naming, and a heatsink is needed but not included.
