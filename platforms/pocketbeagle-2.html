Overview

PocketBeagle 2 is a tiny Linux computer from BeagleBoard.org, about the size of a matchbox. It runs Debian on four Arm cores and adds a real-time core plus PRU helpers for precise timing. A small helper chip gives it eight analog inputs. It suits students, teachers, and makers who want to learn embedded Linux on fully open hardware.

Good fit or not?

Good for

  • Learning embedded Linux in a classroom
  • Robots and gadgets that need exact timing
  • Battery-powered projects with the built-in LiPo charger
  • Reading analog sensors without an extra chip
  • Studying fully open board design files

Not great for

  • Internet projects without an add-on network adapter
  • Desktop use, as it has no video port
  • Heavy AI or video work with only 512 MB of memory
  • Newcomers who want a first program in minutes

Specs in plain words

  • Four processor cores at up to 1.4 GHz run Linux tools and Python scripts comfortably.
  • 512 MB of memory fits small programs and servers, but a desktop would feel cramped.
  • The real-time core and PRU cores react to pins in tiny fractions of a second.
  • Eight 12-bit analog inputs read knobs and sensors in 4,096 steps each.
  • 72 pre-soldered pins give 52 digital inputs and outputs for wires and add-on boards.
  • The board is 55 by 35 millimeters, a bit smaller than a credit card.
Full spec sheet

Memory512 MB
StoragemicroSD card
AI chipAM6254 3D GPU and dual PRU cores
Pins52 pins, 8 analog inputs
Ways to connect partsI2C, SPI, Serial (UART), USB device, USB host, SD card bus, Debug port
ConnectorsUSB-C, Pin headers, microSD slot, Battery plug
Built inbuttons, battery charger
Power5 V at 1 A over USB-C or cape header VIN, or LiPo battery
Size55 x 35 mm

Values are for Rev A1 with the AM6254. Rev A0 used the dual-core AM6232 without a GPU and is no longer sold. The eMMC footprint is not populated. As a result, the board boots from microSD and flash_kb is null. The 8 analog inputs are provided by the MSPM0L1105, which emulates the ADC and a 4 KB EEPROM over I2C. The MSPM0L1105 is a 32 MHz Cortex-M0+ with 32 KB flash and 4 KB SRAM. There is no Wi-Fi, Bluetooth or Ethernet.

Starter ideas

  • Blinking light first project

    Wire an LED to a header pin and blink it from a short Python script. It is a gentle first step into Linux hardware.

    Uses: Runs Linux. Add: LED, resistor, jumper wires.

  • Plant thirst alarm

    Read a soil moisture sensor on an analog input. A buzzer chirps once the pot gets dry.

    Uses: Runs Linux. Add: soil moisture sensor, buzzer, jumper wires.

  • Classroom light meter

    Read a light sensor on an analog pin and log values to the microSD card. Students graph sunlight across a school day.

    Uses: Runs Linux. Add: light sensor, jumper wires.

Builder ideas

  • Pocket data logger

    Run the board from a LiPo battery and log temperature readings on a hike. Download the file to a laptop later.

    Uses: Battery ready, Runs Linux. Add: LiPo battery, temperature sensor.

  • Small rover robot

    Drive two motors through a motor driver board. The real-time core keeps the wheels steady.

    Uses: Battery ready, Runs Linux. Add: motor driver board, two small DC motors, robot chassis, LiPo battery.

  • Servo puppet show

    Move several servo motors with smooth timed pulses. Build a puppet that nods and waves on cue.

    Uses: Runs Linux. Add: servo motors, servo power supply, cardboard puppet.

  • Beehive weight scale

    Read a load cell under a hive and log its weight each hour. Rising weight shows the bees are storing honey.

    Uses: Battery ready, Runs Linux. Add: load cell, load cell amplifier, LiPo battery, weatherproof box.

  • USB keyboard music box

    Plug in a USB MIDI keyboard and turn key presses into lights on the pin header. Each note gets its own color.

    Uses: Plugs in USB gadgets, Runs Linux. Add: USB MIDI keyboard, LEDs, resistors.

  • Embedded Linux lab kit

    Teach students how Linux talks to pins, buses, and drivers. The open design files show every part of the board.

    Uses: Runs Linux. Add: microSD card, breadboard, jumper wires.

Expert ideas

  • Knob-controlled light art

    Read four knobs on the analog inputs and change the colors of an LED strip. The PRU cores keep the strip timing precise.

    Uses: Runs Linux. Add: LED strip, knobs, power supply.

  • Science fair timer gate

    Use two light gates to time a rolling ball. The fast real-time core measures each pass to the microsecond.

    Uses: Runs Linux. Add: two light gate sensors, jumper wires.

  • Zephyr real-time projects

    Write firmware for the Cortex-M4F core and load it from Linux. Fast control loops run beside the main system.

    Uses: Runs Linux.

  • USB networked sensor post

    Add a USB Wi-Fi adapter and send garden readings to a home computer. The board runs on a battery between charges.

    Uses: Plugs in USB gadgets, Battery ready, Runs Linux. Add: USB Wi-Fi adapter, soil moisture sensor, LiPo battery.

The full design files are public, including the schematic, PCB layout, drawings, and a 3D model. They use the CC BY-SA 4.0 license, as do the docs. Linux, Debian images, and Zephyr support are open, but the GPU likely needs closed TI files. The TI chip designs are closed.
