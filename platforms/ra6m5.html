RA6M5

Renesas Electronics

A Renesas microcontroller with Ethernet, CAN FD, and fast USB for connected projects.

Overview

The RA6M5 is a Renesas microcontroller with a 200 MHz Arm core and strong security features. It packs Ethernet, two CAN FD buses, and fast USB in one chip. Makers find it on the Arduino Portenta C33 and the SparkFun Thing Plus RA6M5. It suits learners who start in Arduino and grow into networked or industrial projects.

Good fit or not?

Good for

  • Arduino projects that need more speed and memory
  • Wired network projects over Ethernet
  • CAN bus projects for cars, robots, and machines
  • Data logging to a microSD card
  • Long-lived products, as Renesas plans support until 2041

Not great for

  • Wi-Fi projects on the chip alone, as it has no radio
  • AI or camera projects, as it has no AI engine or camera port
  • Finding beginner tutorials made just for this chip

Specs in plain words

  • A 200 MHz core runs Arduino sketches many times faster than a classic Uno.
  • 512 KB of memory holds thousands of sensor readings at once.
  • 2 MB of flash stores large programs and can update itself in the background.
  • Up to 26 analog inputs read sensors such as light, soil moisture, and temperature.
  • Two CAN FD buses talk to cars, motor drivers, and factory gear.
  • 10/100 Ethernet links the board to a home or school network with a cable.

gpio and adc_channels are maximums for the 176-pin package from the Renesas page. Flash is 1, 1.5 or 2 MB by part. Boards here use 2 MB parts. Renesas quotes 107 uA per MHz running CoreMark from flash. No standby figure was read. The chip has no radio. The Portenta C33 adds an ESP32-C3 module for Wi-Fi and BLE. The Thing Plus adds a DA14531MOD for BLE. Size is the Thing Plus Feather footprint of 2.9 x 0.9 inches. The Portenta C33 is 66.04 x 25.40 mm. Connectors and onboard items reflect the Thing Plus, which has Qwiic, LiPo charger and microSD.

Things you could build

15 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink the RGB LED

    Open the Blink example in the Arduino IDE and upload it. Then change the colors and the timing.

  • Plant thirst alarm

    Read a soil moisture sensor on an analog pin. Flash the LED once the pot gets too dry.

    Add: soil moisture sensor.

  • Plug-in weather logger

    Snap a temperature and humidity sensor onto the Qwiic port. Save a reading every minute to a microSD card.

    Uses: Plug-in connectors. Add: Qwiic temperature and humidity sensor, microSD card.

  • Classroom light meter

    Plug in a light sensor and print readings to the serial plotter. Students compare a window seat and a dark corner.

    Uses: Plug-in connectors. Add: Qwiic light sensor.

  • Reaction time game

    Light the LED at a random moment and time a button press. Show the best score on a small screen.

    Uses: Plug-in connectors. Add: push button, Qwiic OLED screen.

Builder ideas

  • Battery field logger

    Run the Thing Plus from a LiPo battery and log sensor data outside. Leave it by a pond for a week of readings.

    Uses: Battery ready, Plug-in connectors. Add: LiPo battery, Qwiic temperature sensor, microSD card, weatherproof box.

  • Wired home dashboard

    Serve a small web page over Ethernet that shows room temperature. Open it from any computer in the house.

    Uses: Wired network. Add: Ethernet cable, temperature sensor.

  • Garden watering timer

    Switch a small pump through a relay on a schedule. Add a moisture sensor to skip watering on wet days.

    Add: relay module, small water pump, soil moisture sensor.

  • USB keyboard music box

    Plug a USB keyboard into the board's host port. Each key plays a tone through the analog output and a speaker.

    Uses: Plugs in USB gadgets. Add: USB keyboard, small speaker, small amplifier board.

  • Pendulum timer for science class

    Time each swing of a pendulum with a light gate. Graph how string length changes the period.

    Add: light gate sensor, string, small weight.

  • Heart rate display

    Read a pulse sensor through the Qwiic port and show beats per minute on a small screen. Use it after a gym class run.

    Uses: Plug-in connectors. Add: Qwiic pulse sensor, Qwiic OLED screen.

  • Community makerspace door log

    Record button presses or door openings with a time stamp. Share the log page over the wired network.

    Uses: Wired network. Add: door switch, Ethernet cable.

Expert ideas

  • Car data reader

    Connect a CAN transceiver and read messages from a vehicle or e-bike bus. Show speed or battery level on a screen.

    Add: CAN transceiver board, small screen.

  • Small factory machine monitor

    Watch sensors on a workshop machine and report over Ethernet. Use the secure crypto engine to sign each report.

    Uses: Wired network. Add: current sensor, Ethernet cable.

  • Robot arm over CAN bus

    Control several motor drivers that share one CAN bus. Each joint listens for its own commands.

    Add: CAN transceiver board, CAN motor drivers, servo motors.

Level 3 of 3. Wild Open shares the most.

The SparkFun Thing Plus RA6M5 has full Eagle design files under CC BY-SA 4.0. The Arduino core is MIT, the Renesas FSP drivers are BSD-3-Clause, and MicroPython and Zephyr support the chip. The chip itself is a closed Renesas design, and some FSP add-ons ship as closed binaries.

An analog signal can take any value in a range.
Bus
A bus is a shared path that carries data between parts.
CAN bus
CAN bus is a sturdy wired network made for cars.
Microcontroller
A microcontroller is a tiny computer on a single chip.
MicroPython
MicroPython is a small version of Python made for microcontrollers.
MIPI CSI
MIPI CSI is a fast link between a camera and a processor.

A motor driver is a chip or board that powers a motor for a microcontroller.
