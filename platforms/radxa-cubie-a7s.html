Overview

The Radxa Cubie A7S is a single-board computer about 51 millimeters square. It runs on the Allwinner A733 chip with eight Arm cores and a 3 TOPS AI helper. It has Gigabit Ethernet, Wi-Fi 6, Bluetooth 5.4, and a PCIe connector for a fast drive. It suits makers who know some Linux and want a small edge AI or server board.

Good fit or not?

Good for

  • A small Debian computer for learning Linux
  • Compact file servers with an NVMe drive
  • Camera projects that use the AI helper
  • Tight spaces, with the board about the size of a coaster

Not great for

  • Plug-and-play screens, with video only through USB-C DisplayPort
  • Beginners, with Linux setup and few tutorials so far
  • Projects that need mainline Linux or open graphics drivers
  • Tight budgets, with prices up since launch

Specs in plain words

  • Eight cores split into two fast cores and six efficient cores. That is enough to browse the web and run small servers.
  • The 3 TOPS AI helper runs small vision models for spotting people, pets, or objects.
  • 4 GB of memory runs a light desktop, and bigger models go up to 16 GB.
  • The PCIe connector matches the Raspberry Pi 5 style and accepts NVMe drive adapters.
  • USB-C DisplayPort can drive one 4K screen at 60 Hz with the right adapter.
  • A 4-lane camera connector takes MIPI camera modules.

The 4 GB model is shown because it is the most common SKU in stores. RAM goes up to 16 GB, and stores list 4, 6, 8 and 12 GB. flash_kb is null because most units have no eMMC and boot from microSD. Optional eMMC goes up to 256 GB. Core count excludes the E902 helper core. Video output is DisplayPort over USB-C only. As a result, the hdmi interface is not listed. The Wi-Fi module is a Quectel FCU760K per CNX Software. The 15-pin header is not pre-soldered. The 30-pin header carries I2C, SPI1, four UARTs, PWM and JTAG.
