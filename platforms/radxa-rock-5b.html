Radxa ROCK 5B

Radxa

A fast eight-core Linux board with an NVMe slot and a 6 TOPS AI helper.

Overview

Radxa ROCK 5B is a palm-sized Linux computer built on the eight-core Rockchip RK3588. It has a 6 TOPS AI helper, a fast NVMe slot and a 2.5 gigabit network port. It can drive up to four screens and record video through an HDMI input. It suits makers who want a powerful home server, desktop or AI test bench.

Good fit or not?

Good for

  • Home servers and network file storage
  • Smooth 8K video playback
  • Running small AI vision models on a camera
  • Multi-screen signs and dashboards
  • Learning Linux on a fast board with Armbian support

Not great for

  • Absolute beginners who want plug-and-play ease
  • Wireless projects without an extra M.2 Wi-Fi card
  • Shoppers who need stock today. Most stores showed it sold out.
  • Fully open hardware fans, as only schematics are public

Specs in plain words

  • Eight processor cores at up to 2.4 GHz feel close to a modest laptop.
  • 4, 8 or 16 GB of memory runs a desktop, a browser and several servers at once.
  • 6 TOPS means the AI helper does about 6 trillion small math steps each second.
  • The PCIe 3.0 x4 slot takes a fast NVMe SSD for storage and booting.
  • The 2.5 gigabit port moves files about two and a half times faster than common home ports.
  • The board is about 10 by 7.5 centimeters, close to a large playing card.

RAM comes in 4, 8 and 16 GB versions. Ram_kb shows the 8 GB board. There is no soldered eMMC. Flash_kb is null because storage is an eMMC module, microSD or NVMe. Wi-Fi and Bluetooth need an optional M.2 E-key module. As a result, only Ethernet is listed as a radio. The E-key slot carries PCIe 2.1 x1, USB, SATA, SDIO, PCM and UART. M.2 SATA SSDs are not supported. It has two USB 3.0 and two USB 2.0 Type-A ports. The docs list the USB 3.0 ports as host or OTG. The 40-pin header functions and GPIO count were not confirmed. As a result, I2C, SPI and UART are not listed. Radxa docs list 100 x 75 mm. CNX Software described it as Pico-ITX at 100 x 72 mm.

How open is it?

Open Board

Radxa publishes schematic PDFs for each board revision, plus parts placement, 2D drawings and a 3D model. No board layout files are published, and the hardware files have no stated license. The build scripts use GPL-3.0 and the Linux kernel uses GPL-2.0. The RK3588 chip is closed, and the AI tools include closed Rockchip files.

Hardware license: none stated for hardware files (docs site text is CC BY 4.0) · Software license: GPL-3.0 (radxa-build/rock-5b), Linux kernel GPL-2.0
