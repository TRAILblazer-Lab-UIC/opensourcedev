Overview

Raspberry Pi 400 is a complete Linux computer built into a compact keyboard. Inside sits a board based on the Raspberry Pi 4 with 4 GB of memory. It suits families, schools and first-time coders who want a cheap desktop. A big metal heat spreader keeps it cool with no fan.

Good fit or not?

Good for

  • A low-cost first computer for browsing and homework
  • Learning Python and Scratch at home or in class
  • Retro games and media on a TV
  • Simple electronics projects through the rear pin header
  • Small home servers on a wired network

Not great for

  • Camera projects, as it has no camera connector
  • Plugging in HATs directly, as the pin header faces backward and upside down
  • Portable or battery gadgets
  • Fully open hardware, as no schematic is published

Specs in plain words

  • Four cores at 1.8 GHz feel like a basic home computer for browsing and coding.
  • 4 GB of memory runs a desktop, a browser and a few programs at once.
  • It has no built-in storage, and the system lives on a microSD card or USB drive.
  • Two micro-HDMI ports can drive one 4K screen or two screens at once.
  • Wi-Fi, Bluetooth and a Gigabit network port cover home connections.
  • The whole computer is about as long as a ruler and as thin as a paperback book.

Only one RAM configuration exists (4 GB). flash_kb is null because there is no eMMC. It boots from microSD or USB. The bootloader lives in an SPI EEPROM. The 40-pin header is horizontal and rotated 180 degrees compared with a bare Pi. Gpio counts GPIO2 to GPIO27 as on other 40-pin Pis. There are no MIPI camera or display connectors and no power button. Fn plus F10 turns it on and off. Operating temperature is 0 to 50 C.

How open is it?

Open Code

The Linux kernel, Raspberry Pi OS and the graphics drivers are open source, and the kernel uses GPL-2.0. Raspberry Pi publishes no schematic or layout for this model and states no open hardware license. The Broadcom main chip, its boot firmware and the keyboard controller firmware stay closed.

Hardware license: none (proprietary) · Software license: GPL-2.0 (Linux kernel), proprietary redistributable boot firmware
