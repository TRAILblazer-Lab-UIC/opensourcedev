Overview

Raspberry Pi Compute Module 5 packs the brain of a Raspberry Pi 5 onto a small module. It has no ports of its own and plugs into a carrier board. It suits product designers, engineers and advanced makers who build their own boards. Its open IO board design files make a handy starting point for custom hardware.

Good fit or not?

Good for

  • Turning a Pi project into a finished product
  • Custom handhelds, kiosks and smart appliances
  • Industrial gadgets in hot or cold places
  • Small computer clusters and network boxes
  • Learning board design from the published IO board files

Not great for

  • First-time makers, as it needs a carrier board to do anything
  • Quick weekend projects with only a cable
  • Battery gadgets that must run for weeks
  • Fully open hardware, as the module design and main chip are closed

Specs in plain words

  • Four cores at 2.4 GHz give it the same speed as a Raspberry Pi 5.
  • Memory comes in 2 to 16 GB, and 4 GB handles most gadgets well.
  • Most versions have 16, 32 or 64 GB of built-in storage, and the Lite version uses an SD card on the carrier.
  • At 55 by 40 mm it is smaller than a playing card.
  • Two camera or screen lanes let one gadget watch with two cameras.
  • Wi-Fi and Bluetooth come only on the wireless versions.

RAM and eMMC vary by variant. Values shown are 4 GB RAM and 32 GB eMMC, a mid-range wireless configuration. The module has no user connectors of its own. All I/O goes through two high-density board-to-board connectors. As a result, connectors and onboard are empty. The datasheet lists 28 GPIO at 1.8 V or 3.3 V. The product page says up to 30. SDIO is exposed on CM5 Lite only, for external eMMC or an SD card. Wi-Fi and Bluetooth are present only on the wireless variants. Power draw is about 1.3 mA with PMIC_EN low, about 3 mA when shut down by software, 400 mA idle and 900 mA typical under load. The module can supply 600 mA at 3.3 V and 1.8 V to peripherals. Module thickness is 4.7 mm.

Builder ideas

  • Desktop computer on the IO board

    Clip the module onto the official IO board and add a screen. You get a Pi 5 style desktop for learning.

    Uses: Runs Linux, Screen. Add: IO board, power supply, screen, keyboard, mouse.

  • Home media center

    Build a quiet media player that streams shows to the TV in 4K. The module hides inside a small case.

    Uses: Screen, Runs Linux, Wi-Fi. Add: IO board, case, power supply.

  • Family file server

    Add a fast drive to the IO board slot and share files across the house. Photos and backups stay at home.

    Uses: Runs Linux, Wired network. Add: IO board, SSD drive, network cable.

  • School weather station hub

    Gather wind, rain and temperature data from the roof. Show live graphs on a hallway screen.

    Uses: Runs Linux, Wi-Fi, Screen. Add: IO board, weather sensor board, screen.

  • Wildlife trail camera

    Watch a trail with a camera module and save clips of passing animals. A small AI model can label each visitor.

    Uses: Camera, Runs Linux. Add: IO board, camera module, weatherproof box.

  • Home ad blocker and network helper

    Run a filter that hides ads on every device at home. A small carrier board makes it a neat appliance.

    Uses: Wired network, Runs Linux. Add: carrier board, case.

Expert ideas

  • Custom handheld game console

    Design a small carrier with buttons and a screen for classic games. The module gives it plenty of speed.

    Uses: Screen, Plugs in USB gadgets, Runs Linux. Add: custom carrier board, small screen, buttons, battery pack.

    Connect two camera modules through the IO board and compare their views. The robot learns how far away things are.

    Uses: Camera, Runs Linux. Add: IO board, two camera modules.

    Ask spoken questions and hear answers from a local AI model. Your voice stays on your own device.

  • Factory machine monitor

    Read machine sensors and show status on a shop floor screen. The module handles cold and heat from -20 to 85 C.

    Uses: Runs Linux, Screen, Wired network. Add: carrier board, industrial sensors, screen.

  • Museum touchscreen kiosk

    Build an exhibit screen that visitors tap to learn about local nature. The module tucks behind the display.

    Uses: Screen, Runs Linux. Add: carrier board, touchscreen display, mounting frame.

  • Robot with object spotting

    Mount the module on a rover and run a model that spots objects in live video. Steer around chairs and pets.

  • Bluetooth sensor gateway

    Collect readings from many Bluetooth sensors around a building. Send them to a dashboard over the network.

    Uses: Bluetooth, Wired network, Runs Linux. Add: carrier board, Bluetooth sensors.

How open is it?

Open Board

The official CM5 IO board ships as full KiCad design files, but no license is stated for them. The Linux kernel and Raspberry Pi OS are open source under GPL-2.0. The module itself, the Broadcom main chip and the startup firmware stay closed.

Hardware license: none stated (CM5 IO Board KiCad files published without a license) · Software license: GPL-2.0 (Linux kernel), proprietary redistributable boot firmware

Key terms on this page

Bootloader
A bootloader is a small program that runs first at startup.
Carrier board
A carrier board holds a compute module and adds ports.
Compute module
A compute module is the brain of a computer on a small card.
Development board
A development board is a chip mounted on a friendly board for testing ideas.
Frequency band
A frequency band is a slice of radio space set aside for certain uses.
KiCad
KiCad is a free and open-source app for designing circuit boards.
Module
A module is a small ready-made board that does one job.
Open source
Open source means the source files are public under a license.
Operating system
An operating system is the main software that runs a computer.
Pin header
A pin header is a row of metal pins or sockets on a board.
Raspberry Pi
Raspberry Pi is a line of low-cost single-board computers from a UK charity and company.
Raspberry Pi OS
Raspberry Pi OS is the official Linux system for Raspberry Pi boards.
