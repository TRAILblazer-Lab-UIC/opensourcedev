Overview

The Raspberry Pi Debug Probe is a small USB tool for people who program microcontroller boards. It loads code onto a board and lets you pause and inspect that code as it runs. It also works as a USB serial adapter for reading messages from a board. It suits Pico users ready to move past trial and error.

Good fit or not?

Good for

  • Flashing and step debugging Raspberry Pi Pico and Pico 2 boards
  • Reading serial messages from a board over a separate cable
  • Classrooms teaching how to find bugs in C code
  • Rescuing boards that stopped showing up over USB
  • Debugging other 3.3 V Arm Cortex-M boards

Not great for

  • Projects on its own, as it has no free pins for sensors
  • Boards with 5 V or 1.8 V signals without extra care
  • People who code only in a browser or with blocks
  • Fans of USB-C, as it uses an older micro USB port

Specs in plain words

  • The RP2040 chip inside is the same brain as the first Pico.
  • SWD is a two-wire link that lets your computer pause and peek inside a running chip.
  • CMSIS-DAP is a common debug standard. Many free tools already know how to talk to it.
  • The separate UART port acts like a text chat line between your board and your computer.
  • At 22 by 32 mm it is about the size of a matchbox.
  • The 3.3 V signal level matches the Pico and many other small boards.

The probe is a tool. As a result, specs describe its onboard RP2040 brain. Flash is a Winbond W25Q16JV (2 MB) per the schematic and CNX Software. Target ports are two 3-pin JST-SH (1.0 mm) connectors, labelled D for SWD and U for UART. These are not in the connector vocabulary. Nominal I/O voltage is 3.3 V. The schematic shows 74AUP1T17 single buffers on the signal lines. Level shifting for other voltages is not advertised. There is a BOOTSEL button, a red power LED and four activity LEDs. CNX notes an unpopulated 3-pin header (GPIO0, GPIO1, GND). No user GPIO is exposed in normal use. As a result, gpio is null. Operating temperature is -20 to +70 C. Size is the 22 x 32 mm form factor from the product brief.

The debugprobe firmware is open source under the MIT license. It builds with the open Pico SDK, and the computer side uses open OpenOCD and GDB. Raspberry Pi shares a schematic PDF and a drawing, but the board layout is unpublished and has no hardware license. The RP2040 chip itself is closed.
