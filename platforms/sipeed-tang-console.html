Sipeed Tang Console

Sipeed

A pocket-sized FPGA board that plays classic games by rebuilding old consoles in hardware.

Overview

The Tang Console is a small FPGA board from Sipeed. An FPGA is a chip you rewire with code to become almost any digital circuit. The dock takes a swappable brain module called the Tang Mega 60K or the bigger Tang Mega 138K. Retro gamers know it best as a cheap rival to the MiSTer. Community game cores recreate old consoles in hardware.

Good fit or not?

Good for

  • Playing classic console games with ready-made cores
  • Building a handheld retro console with a battery
  • Learning FPGA design on a capable board
  • Advanced work with PCIe, USB 3.0 and fast data links

Not great for

  • Fully open tool flows, as the open tools handle only simple designs
  • Complete beginners who want to design their own circuits
  • Wireless projects, as it has no radio
  • Shoppers on a budget, as marketplace prices often run high

Specs in plain words

  • The 60K module has about 60,000 logic cells. That is room for whole retro consoles like the SNES.
  • The 138K module has more than twice the logic and a built-in RISC-V processor.
  • 512 MB of memory on the 60K holds game data and video frames with room to spare.
  • HDMI output lets it plug straight into a TV or monitor.
  • A battery connector with charging makes a handheld build possible.
  • Two PMOD ports and two 40-pin headers take add-ons such as buttons, screens and sensors.

Values are for the 60K SOM, the cheaper and lower-capacity option. The 138K SOM has 138,240 LUT4, 6,120 Kbit block SRAM, 298 DSP multipliers, 12 PLLs, 1 GB DDR3 (two 512 MB chips) and 64 Mbit flash (128 Mbit on units from the October 2025 anniversary update). 60K SOM resources: 59,904 LUT4 and flip-flops, 468 Kbit distributed SRAM, 2,124 Kbit block SRAM in 118 blocks, 118 18x18 multipliers, 4 SERDES transceivers at 270 Mbps to 8.8 Gbps, 8 PLLs, hard PCIe 2.0 controller, 512 MB DDR3 at 1100 Mbps, 64 Mbit flash. SOM size 35 x 45 mm. clock_mhz is the 50 MHz crystal seen on the dock schematic. gpio is the wiki figure of up to 2x38 I/O on the two 40-pin headers. PMOD pins are extra. adc_channels counts the 2 differential ADC inputs, one of which measures battery voltage. The USB-C port serves the BL616 debugger and power, and the schematic shows a USB 3.0 Type-A style receptacle wired to the SERDES lanes in device mode. Exact connector use per port should be checked on the board. Press coverage quoted "4 GB" and "8 GB" of DDR3. These are 4 Gbit and 8 Gbit per the Sipeed wiki. The Sipeed wiki is inconsistent on the 138K package (PG484A vs FPG676A). The IDE settings say PBG484A.

Things you could build

15 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Play classic console games

    Load a ready-made TangCores game core and plug in a screen and a gamepad. You can play NES, SNES or Mega Drive games with no coding.

    Uses: Screen. Add: microSD card, HDMI monitor or TV, gamepad.

  • Living room retro corner

    Set it up under the TV with a case and two controllers. Family game night gets a library of old favorites.

    Uses: Screen. Add: acrylic case, HDMI cable, gamepad.

Builder ideas

  • Handheld retro game player

    Add a small screen, a battery and a printed case. The board charges the battery and turns into a handheld console.

    Uses: Battery ready, Screen. Add: small LCD screen, single-cell lithium battery, 3D printed case, gamepad.

  • Play your own GBA cartridges

    Use the cartridge slot add-on and a GBA core to play your own old cartridges. It keeps a game collection alive.

    Uses: Screen. Add: GBA cartridge slot add-on, HDMI monitor or TV, gamepad.

  • Blink and count with Verilog

    Write a tiny hardware design that blinks the RGB LED and counts button presses. It is the classic first step into FPGA design.

  • Video pattern generator

    Draw color bars and moving shapes on an HDMI screen. It teaches how a picture is drawn line by line.

    Uses: Screen. Add: HDMI monitor.

  • LED wall art

    Drive a big grid of color LEDs with moving patterns. Hang it in a hallway or a maker space.

    Add: LED matrix panel, 5 V power supply, jumper wires.

Expert ideas

  • Pong built from logic

    Build Pong fully in logic circuits and play it on a TV. No processor runs the game at all.

    Uses: Screen. Add: HDMI monitor, PMOD button module.

  • Chiptune synthesizer

    Build sound circuits that mimic old game consoles. Play the tones through the speaker output.

    Add: small speaker.

  • Design your own game console

    Invent a made-up retro console with its own graphics and sound chips. Write a tiny game for it.

    Uses: Screen. Add: HDMI monitor, gamepad.

  • Run a RISC-V computer

    Use the hard RISC-V core on the 138K model or a soft core on the 60K. Then run small C programs on it.

  • FPGA helper for a Raspberry Pi 5

    Connect the board to a Raspberry Pi 5 over PCIe. The FPGA can take on fast custom jobs for the Pi.

    Add: Raspberry Pi 5, PCIe ribbon cable.

  • Science class logic analyzer

    Capture fast digital signals from a project and send them to a computer. Students can see how chips talk to each other.

    Add: jumper wires.

  • Battery voltage meter

    Read the battery level with the built-in analog input. Show it as a bar on screen for your handheld build.

    Uses: Battery ready, Screen. Add: single-cell lithium battery, small LCD screen.

  • High-speed link experiments

    Try the fast SERDES lanes for USB 3.0 or PCIe designs. It is a deep project for advanced learners.

How open is it?

Open Board

Sipeed publishes PDF schematics, a 3D model and a mechanical drawing. The board layout files stay closed, and no hardware license is stated. The open Apicula, Yosys and nextpnr flow can only handle very simple designs on this board. Real work needs Gowin's closed EDA software, and the Gowin chip itself is closed.

Hardware license: none stated · Software license: MIT (Apicula), Apache-2.0 (sipeed/TangMega-138K-example), no license file on sipeed/TangMega-60K-example or nand2mario/tangcores
