Overview

The Tang Primer 25K is a tiny FPGA board from Sipeed. An FPGA is a chip you rewire with code to become almost any digital circuit. A core board smaller than a postage stamp plugs into a dock with USB and three PMOD ports. It suits students and hobbyists who want to learn Verilog with low-cost add-ons.

Good fit or not?

Good for

  • Learning digital logic and hardware design
  • Classes that use the open Yosys, nextpnr, and Apicula tools
  • Low-cost video, camera, and game projects with PMOD add-ons
  • Building the core board into your own custom gadget

Not great for

  • Complete beginners, as it needs hardware languages
  • Wireless projects, as it has no radio
  • Memory-hungry designs, as it has no RAM unless you add the SDRAM module
  • Easy shopping, as some US shops have retired it

Specs in plain words

  • 23,040 logic cells is room for a small soft processor plus extra circuits.
  • 64 Mbit of flash stores your design and keeps it after power goes off.
  • 75 input and output pins give lots of room for buttons, lights and sensors.
  • The USB-A port is a simple slow USB host for game controllers and keyboards.
  • Three PMOD ports take plug-in modules for HDMI, cameras and joysticks.

Specs from the Sipeed wiki and CNX Software. size_mm is the dock. The core board is 23 x 18 mm (CNX gives 23 x 17.8 mm). FPGA resources: 23,040 LUT4 and flip-flops, 1,008 Kbit block SRAM in 56 blocks, 28 18x18 multipliers, 6 PLLs, 8 I/O banks, 75 user I/O and 4-lane MIPI I/O. Distributed SRAM is 180 Kbit on Device Version B and 0 on Version A (wiki). ram_kb is null because there is no RAM on the board by default. An optional 40-pin SDRAM module plugs into the header. flash_kb is the 64 Mbit NOR flash for the bitstream. clock_mhz is the 50 MHz crystal (CNX). gpio 75 is the core board count. The MIPI high-speed pins are not routed on the dock. The USB-A port acts as a USB 1.1 host implemented in the FPGA. i2c and spi are soft interfaces used by PMOD modules. CNX lists 3 LEDs on the dock. Their type was not confirmed.

Things you could build

13 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink your first LED

    Write a tiny Verilog design that blinks an LED on the dock. It shows how hardware design differs from normal code.

  • Button logic lab

    Wire the two buttons to the LEDs through logic gates you design. Students can build AND, OR and XOR gates by hand.

Builder ideas

  • Reaction time game

    Light an LED at a random moment and time how fast a player presses a button. Show the score on a small display.

    Add: seven segment display module.

  • Hello over the serial port

    Build a simple serial sender in Verilog. Watch your message appear in a terminal on your computer.

  • Video test pattern on a monitor

    Draw color bars and shapes on a screen with the PMOD HDMI module. It teaches how screens are drawn line by line.

    Add: PMOD HDMI module, HDMI monitor.

  • Retro NES-style game player

    Run an NES-class game core with the HDMI and SDRAM modules. Plug a USB game controller into the dock.

    Uses: Plugs in USB gadgets. Add: PMOD HDMI module, SDRAM module, USB game controller, HDMI monitor.

  • LED matrix art

    Scroll text and patterns across the PMOD LED matrix. Put a message board on your desk.

    Add: PMOD LED matrix module.

  • Joystick drawing toy

    Move a dot around a screen with a joystick module. Leave a colored trail like a digital sketch pad.

    Add: PMOD joystick module, PMOD HDMI module, HDMI monitor.

  • Servo sweep controller

    Make a precise pulse that swings a servo back and forth. Use it to wave a flag in a school display.

    Add: servo motor, jumper wires.

Expert ideas

  • Camera image to screen

    Stream pictures from the PMOD camera to an HDMI screen. Then add simple filters such as black and white.

    Add: PMOD camera module, PMOD HDMI module, SDRAM module, HDMI monitor.

  • Build a RISC-V computer

    Load a small soft RISC-V core into the FPGA. Then run little C programs on a chip you assembled.

  • Weather station on a soft core

    Read a temperature and humidity sensor over I2C. Send the readings to your computer every minute.

    Add: temperature and humidity sensor.

  • Custom carrier board

    Design your own board around the tiny core module with the published footprint files. Fit FPGA power into a small gadget.

    Add: custom printed circuit board.

How open is it?

Open Board

The design tools can be fully open. The Apicula, Yosys, nextpnr, and openFPGALoader flow supports this board. Sipeed publishes PDF schematics and footprint files, but no board layout or hardware license, and the Gowin chip is closed.

Hardware license: none stated · Software license: MIT (Apicula), Apache-2.0 (openFPGALoader), no license file on sipeed/TangPrimer-25K-example
