Overview

The SLZB-06 is a Zigbee coordinator from SMLIGHT. It acts as the main radio for a Zigbee smart home. It talks to bulbs, plugs and sensors and passes their messages to a home server over a network cable, USB or Wi-Fi. It suits people who already run Home Assistant or Zigbee2MQTT and want a stronger, better placed radio.

Not great for

  • General coding projects, as it has no free sensor pins in normal use
  • Buyers in the US, as no US store price was confirmed
  • Anyone wanting open hardware files, as none are published

Specs in plain words

  • The Zigbee radio has a built-in signal booster and a screw-on antenna. It reaches gadgets across a large house.
  • Power over Ethernet means one network cable brings both power and data.
  • The ESP32 bridge chip runs the web settings page and the network link.
  • The body is about 160 mm long, close to the length of a pen.
  • The original model is now legacy. The newer SLZB-06U replaces it with an updated bridge chip.

The main values are for the ESP32 bridge. CNX Software names it ESP32-DOWDQ5-V3, which is read here as the ESP32-D0WD V3 die, with 520 KB SRAM. ESP32 flash size was not stated on any fetched page. The CC2652P1FRGZR radio runs at 48 MHz with 352 KB flash and 80 plus 8 KB SRAM, per CNX Software. SMLIGHT gives 160 x 22 x 24 mm and CNX gives 160 x 26 x 22 mm. Wi-Fi coordinator mode was in alpha (v0.9.8) when the product page FAQ was written. The CC2652P can run Thread with other firmware. The 06U page markets Matter-over-Thread. The successor SLZB-06U uses an ESP32-S3, a WIZnet W5500 Ethernet chip, 4 LEDs and one button, at 160 x 24 x 28 mm.

How open is it?

Open Code

SMLIGHT publishes no schematic, board files or hardware license. The default SLZB-OS firmware is closed. An open firmware under GPL-3.0 and an ESPHome option are also offered. The Zigbee chip runs open Z-Stack builds from the Koenkk project on top of the TI radio stack.

Hardware license: none stated · Software license: Open-source ESP32 firmware GPL-3.0 (smlight-dev/slzb-06-firmware), slzb-esphome GPL-3.0, Koenkk Z-Stack-firmware repo MIT on the TI SDK, default SLZB-OS firmware proprietary
