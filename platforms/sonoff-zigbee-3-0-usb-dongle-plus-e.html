Overview

The SONOFF Zigbee 3.0 USB Dongle Plus E is a small radio stick. It plugs into a Raspberry Pi or home server. It lets free software such as Home Assistant talk to Zigbee lights, buttons and sensors. It suits anyone building a smart home that stays local and costs little.

Good fit or not?

Good for

  • Running a local smart home with Home Assistant or Zigbee2MQTT
  • Connecting cheap Zigbee sensors, plugs, and bulbs from many brands
  • Keeping home data off cloud servers
  • Building a mesh network that reaches the far rooms of a house

Not great for

  • Using on its own, as it needs a host computer
  • Thread or Matter projects, as that support is unconfirmed
  • Writing your own radio firmware, as that needs vendor tools
  • Very large networks, as the stick talks to about 30 devices directly

Specs in plain words

  • Zigbee is a low power radio for smart home gadgets. Battery sensors can last a long time on it.
  • 20 dBm output is a strong signal for this kind of stick. It reaches across a typical house.
  • The external antenna screws on the back. You can swap it for a bigger one.
  • About 30 devices can link straight to the stick. Another 30 or so can join through plug-in devices.
  • The stick is about 7.5 cm long, close to the length of a pinky finger.
  • It draws very little power from one USB port.

Memory and clock come from CNX Software's spec summary. The exact chip part number comes from the Zigbee2MQTT adapter page. The EFR32MG21 also has a Bluetooth 5.1 LE radio, but the shipped firmware uses only Zigbee. The 802.15.4 radio can in principle run Thread with OpenThread RCP firmware. This was not confirmed on an official page. Inside is a 7-pin IO header with programming pins plus boot and reset buttons and Zigbee and power LEDs. The USB plug type was not stated on a fetched page. Usb_a is assumed from photos of the stick form factor. The ITEAD store page also lists 111 x 40 x 17 mm, which appears to be the package size. Coordinator mode supports about 30 direct child devices plus 30 more via routers, per the ITEAD store page.

How open is it?

Openness level

Level 1 of 3. Wild Open shares the most.

  • Board plansNot published

The host software is open. Zigbee2MQTT and the universal-silabs-flasher tool use the GPL-3.0 license. ITEAD shares firmware images on GitHub, but they are closed binaries with no license. No schematic or hardware license was found, and the Silicon Labs radio chip and its SDK stay closed.
