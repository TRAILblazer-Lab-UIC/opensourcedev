StarFive VisionFive 2 Lite

StarFive

A credit-card-sized RISC-V Linux computer for learning and small servers.

Field marks: It wears the familiar Raspberry Pi shape, yet a lone network jack and a tiny M.2 slot give away its RISC-V roots.

Overview

The VisionFive 2 Lite is a low-cost RISC-V computer the size of a Raspberry Pi. It runs Ubuntu or Debian Linux from a microSD card. It suits learners and tinkerers who want to explore RISC-V on a budget. An M.2 slot for fast storage sets it apart from many boards this size.

Good fit or not?

Good for

  • Learning Linux on a RISC-V chip
  • Small home servers with fast NVMe storage
  • Low-power projects that run all day
  • Electronics projects through the 40-pin header

Not great for

  • First-time computer users, as updates can break the system
  • Heavy desktop use, as speed is close to an older Raspberry Pi 3B+
  • Fast wireless, as the Wi-Fi tested slow in reviews
  • Any camera beyond the IMX219 sensor

Specs in plain words

  • Four cores at up to 1.25 GHz feel like an older Raspberry Pi 3B+.
  • Memory comes in 2, 4, or 8 GB, and 4 GB is a comfy middle choice.
  • The M.2 slot takes a small NVMe drive for quick storage.
  • The base 2 GB version has no Wi-Fi, and the others add Wi-Fi 6 and Bluetooth.
  • It draws about 3 watts at idle, less than a night light.
  • The board is about the size of a credit card.

RAM is sold in 2, 4 and 8 GB versions. The value shown is the 4 GB version, the one most often listed with Wi-Fi. The base 2 GB model has no Wi-Fi. Wi-Fi 6 and Bluetooth 5.4 come on the Wi-Fi versions. flash_kb is null because the base board boots from microSD. An eMMC option (64 GB at Waveshare, 8 GB version only) exists, and U-Boot sits in QSPI flash. gpio is the 28 GPIO-labelled pins on the 40-pin header per the Waveshare wiki. USB is three USB 2.0 host ports, one USB 3.0 host port sharing the PCIe lane with M.2, and USB device mode on USB-C. The official brief lists the GPU at up to 400 MHz while the Waveshare wiki says 600 MHz. The official value is used. The onboard button is a boot key. Operating temperature is 0 to 50 C.

How open is it?

Open Board

The Linux kernel, U-Boot, and OpenSBI are open source under GPL-2.0 and BSD licenses. StarFive shares the schematic and a placement file, but states no hardware license. The JH7110S chip and the GPU firmware stay closed.

Hardware license: None stated · Software license: GPL-2.0 (Linux kernel), GPL-2.0+ (U-Boot), BSD-2-Clause (OpenSBI). SDK repo has no license file
