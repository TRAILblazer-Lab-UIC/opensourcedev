Overview

The STM32H5 is a performance microcontroller family from STMicroelectronics, launched in 2023. It runs an Arm Cortex-M33 core at up to 250 MHz with built-in security features. The biggest chips hold 2 MB of flash and 640 KB of memory, plus wired Ethernet. It works with Arduino, MicroPython, and Zephyr. Growing makers have several friendly paths in.

How the scores work

Good fit or not?

Good for

  • Wired network gadgets and home dashboards
  • Fast control of motors and robots
  • Projects that need lots of memory
  • MicroPython on the Nucleo-H563ZI
  • Secure gadgets on the H573 chips

Not great for

  • Wireless projects, as the chips have no radio
  • Big network jobs on the small H503, which has only 32 KB of memory
  • Absolute beginners, as setup takes a few extra steps
  • Tight budgets for the touch screen Discovery kit at about 156 US dollars

Specs in plain words

  • 250 MHz handles heavy math many times faster than a classic UNO.
  • 640 KB of working memory on the H563 holds a web server and plenty of sensor data.
  • 2 MB of flash storage fits a large program with web pages and images.
  • The Ethernet port joins your home network with a plain network cable.
  • TrustZone splits memory into a locked area for secrets and an open area for your code.
  • 139 pins on the biggest board leave room for many buttons, lights, and sensors.

Chip values are for the STM32H563ZI on the Nucleo-H563ZI with 2 MB flash and 640 KB SRAM in LQFP144. GPIO (139) is the maximum per the Zephyr board page. The H503 has 128 KB flash and 32 KB SRAM. The H533 has 512 KB flash and 272 KB SRAM. The 2026 H5E5 adds up to 4 MB flash per Wikipedia. The ADC channel count and the lowest standby current were not read from an ST datasheet. Ethernet is on the H563 and H573 only. The I2S entry also covers the two SAI audio ports. The CORDIC and FMAC math units are not AI accelerators. Run efficiency is 61 uA/MHz in SMPS mode per ST's launch release.

Things you could build

16 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • First blinking light

    Upload the Blink example from the Arduino IDE. One of the three lights on the Nucleo board flashes on and off.

  • Live MicroPython lab

    Load MicroPython on the Nucleo-H563ZI and type commands over USB. Blink lights and read sensors in a few lines.

  • Plant thirst alarm

    Read a soil moisture sensor in a flower pot. A buzzer chirps once the soil gets dry.

    Add: soil moisture sensor, buzzer.

Builder ideas

  • Home weather web page

    Plug the Nucleo-H563ZI into your router with a cable. It serves a web page with live temperature and humidity.

    Uses: Wired network. Add: network cable, weather sensor.

  • Garden watering timer

    Check soil moisture in garden beds each morning. The board runs a small pump and posts the results on your home network.

    Uses: Wired network. Add: soil moisture sensors, small water pump, relay board, network cable.

  • Science class data logger

    Sample light, sound, or voltage with the fast ADC. Save the readings to a microSD card for graphs later.

    Add: microSD card module, light sensor.

  • USB barcode scanner station

    Plug a USB barcode scanner into the host port. The board logs books or tools checked out of a school library.

    Uses: Plugs in USB gadgets. Add: USB barcode scanner, USB socket breakout, small screen.

  • Touch screen music player

    Use the STM32H573I-DK touch screen to pick songs from a microSD card. The audio codec plays them through headphones.

    Uses: Makes sound. Add: microSD card, headphones.

  • Clap-controlled lamp

    Listen through the Discovery kit's microphone. Two claps switch a lamp on or off.

    Uses: Hears sound. Add: relay board, lamp.

  • Retro handheld game

    Write a simple game for a small color screen. Buttons move the player and a speaker plays the sound effects.

    Uses: Makes sound. Add: small color screen, buttons, I2S amplifier board, small speaker.

Expert ideas

  • Bird feeder snapshot camera

    Connect a small camera module to the camera port. The board saves a photo to a microSD card each time motion is seen.

    Uses: Camera. Add: camera module, motion sensor, microSD card module.

  • Guitar effects pedal

    Pass a guitar signal through an audio codec board. The math helpers add echo and distortion in real time.

    Uses: Hears sound, Makes sound. Add: audio codec board, audio jacks, foot switch.

  • Community air quality node

    Read a dust sensor outside a school or library. The board shares the numbers on a wired network for the neighborhood.

    Uses: Wired network. Add: dust sensor, weatherproof box, network cable.

  • Brushless motor robot

    Drive brushless motors with the fast timers and math helpers. The robot follows a line around the floor.

    Add: brushless motors, motor driver boards, line sensor, battery pack.

  • CAN bus robot arm

    Link each joint to a CAN FD network. The board sends moves to every joint from one program.

    Add: CAN transceiver boards, servo motors, twisted pair wire.

  • Secure door keypad

    Store door codes in protected memory on the H573. A keypad and a lock motor guard a shed or clubhouse.

    Add: keypad, electric lock, relay board.

Key terms on this page

Arm Cortex-M
Cortex-M is a family of Arm processor designs for microcontrollers.
Bootloader
A bootloader is a small program that runs first at startup.
Driver
A driver is software that lets a computer or chip use a piece of hardware.
Ethernet
Ethernet is wired networking through a network cable.
Flash memory
Flash memory is storage that keeps its data with the power off.
Library
A library is ready-made code you can add to your project.
Microcontroller
A microcontroller is a tiny computer on a single chip.
MicroPython
MicroPython is a small version of Python made for microcontrollers.
Permissive license
A permissive license lets people use and change a work with few rules.
Toolchain
A toolchain is the set of programs that turn your code into firmware.
USB Power Delivery
USB Power Delivery is a way for a charger and device to agree on extra power.
Zephyr
Zephyr is an open-source RTOS backed by the Linux Foundation.
