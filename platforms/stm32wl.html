STM32WL

STMicroelectronics

A low-power chip with a built-in LoRa radio for long-range sensors.

Overview

The STM32WL is a chip from STMicroelectronics with a LoRa radio built in. LoRa sends small messages over long distances while using very little power. Most makers meet it inside small modules from Seeed or RAKwireless. It suits builders of remote sensors who know some C or Arduino code.

How the scores work

Good fit or not?

Good for

  • Battery sensors that report from far away
  • LoRaWAN networks such as community gateways
  • Farm, garden, and weather monitoring
  • Projects that need to sleep for months on batteries

Not great for

  • Beginners with no coding background
  • Wi-Fi, Bluetooth, or video projects, as it has only a sub-GHz radio
  • Big data or fast updates, as LoRa sends only tiny messages
  • Plug and play use, as Wio-E5 boards need a separate debugger for some tools

Specs in plain words

  • The LoRa radio can reach several kilometers in open country with a good antenna.
  • A 48 MHz chip is quick enough to read sensors and run the radio.
  • 64 KB of working memory fits a sensor program and the LoRaWAN code with a little room left over.
  • 256 KB of storage holds your program and a small amount of saved data.
  • Shutdown mode draws about 31 billionths of an amp, which lets a pair of AA batteries last a very long time.
  • Up to 43 pins connect sensors, switches, and other parts.

Chip values come from the ST text in the Zephyr NUCLEO-WL55JC board doc and the CNX Software launch article. cores is 1 for the single-core STM32WLE5 used in the Wio-E5, RAK3172 and Olimex boards. The STM32WL55 on the Nucleo adds a Cortex-M0+. Flash and RAM are for the common 256 KB / 64 KB JC and CC parts. Smaller 64 KB and 128 KB flash parts exist. I2S is available on one of the two SPI blocks. There is no USB on the chip. Boards use a USB-to-UART bridge or an ST-LINK. The ADC channel count could not be confirmed because the ST datasheet would not load. low_power_ua is the 31 nA Shutdown figure from a datasheet search snippet. The Seeed wiki quotes 2.1 uA sleep for the Wio-E5 module in WOR mode. Connectors and onboard values are for the Seeed Wio-E5 Dev Kit. The Nucleo uses USB Micro-B, Arduino Uno and morpho headers, 3 LEDs and 3 user buttons.

Builder ideas

  • Far field soil sensor

    Put a soil sensor in a distant garden bed or field. The board sends moisture readings over LoRa to your home.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: soil moisture sensor, AA battery holder, weatherproof box.

  • Mailbox alert

    A door switch wakes the board each time the mailbox opens. It sends a short radio message to a receiver indoors.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: magnetic door switch, AA battery holder.

  • Rain gauge reporter

    Count tips from a rain gauge bucket. The board reports each day's rainfall to a LoRaWAN network.

    Uses: LoRa long range radio, Sips power. Add: tipping bucket rain gauge, weatherproof box.

  • Water tank level meter

    An ultrasonic sensor measures the water in a farm tank. The board sends the level a few times a day.

    Uses: LoRa long range radio, Sips power. Add: ultrasonic distance sensor, battery pack.

  • Community air sensor

    Mount an air quality sensor on a school roof. Neighbors share readings through a community LoRaWAN network.

    Uses: LoRa long range radio, Plug-in connectors. Add: air quality sensor, outdoor box.

  • Greenhouse frost warning

    Read the temperature inside a greenhouse. A radio alert goes out as the air nears freezing.

    Uses: LoRa long range radio, Plug-in connectors. Add: temperature sensor.

  • Livestock gate monitor

    A switch on a pasture gate reports open or closed. Farmers learn about an open gate before animals wander.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: magnetic door switch, battery pack.

  • LoRaWAN coverage tester

    Carry the board around town and send test pings. Map where the network reaches.

    Uses: LoRa long range radio, Battery ready. Add: battery pack.

Expert ideas

  • Beehive weight tracker

    Weigh a beehive with a load cell. Beekeepers check honey growth from far away without opening the hive.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: load cell, load cell amplifier, battery pack.

  • Hiking trail counter

    A motion sensor counts walkers on a trail. Park staff see daily totals without a walk to the sensor.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: motion sensor, battery pack, outdoor box.

  • Point to point text link

    Pair two boards to send short messages across a valley or a large campus. Each board shows replies on a serial screen.

    Uses: LoRa long range radio. Add: second board, antennas.

  • River level watcher

    Hang a distance sensor over a creek. The board sends the water height for flood watch.

    Uses: LoRa long range radio, Sips power, Battery ready. Add: ultrasonic distance sensor, solar panel, battery pack.

How open is it?

Wild Open

ST shares the chip libraries and the LoRaWAN stack under the BSD-3-Clause license. The optional Sigfox and security parts use a closed ST license. The Olimex dev kit is certified open hardware under CERN-OHL-1.2 with the number BG000121. The chip and radio designs stay closed.

Hardware license: CERN-OHL-1.2 (Olimex LoRa-STM32WL-DevKit, OSHWA BG000121), CERN (Penguino LoRa-E5 STM32WL, OSHWA AZ000003), no license stated for Seeed Wio-E5 and ST Nucleo files · Software license: BSD-3-Clause (STM32WL HAL, SubGHz_Phy, LoRaWAN stack), Apache-2.0 (CMSIS, Zephyr), SLA0044 (Sigfox, KMS, Secure Engine)
