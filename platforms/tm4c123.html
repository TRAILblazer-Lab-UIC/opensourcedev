Overview

The TM4C123 is a Texas Instruments microcontroller from the Tiva C line. Its LaunchPad board is a classic tool in university embedded systems courses. It suits students who want to learn C and how a chip works at a low level. Strong motor control, USB, and CAN bus features make it stand out.

Good fit or not?

Good for

  • College courses on embedded C and real-time systems
  • Motor control and robot projects
  • CAN bus experiments like those inside cars
  • USB device and USB host projects

Not great for

  • Wireless projects, as it has no Wi-Fi or Bluetooth
  • Beginners, as the Arduino-like Energia tool is no longer maintained
  • Hobbyists who want lots of fresh tutorials, as most have moved to newer boards

Specs in plain words

  • An 80 MHz chip with a math helper handles motor math and sensor reading quickly.
  • 32 KB of working memory fits small control programs and a modest buffer of readings.
  • 256 KB of storage holds your program with room to spare for class projects.
  • Two fast analog readers can take a million samples a second for sound or signal work.
  • Hibernation draws about 1.6 millionths of an amp, which suits long battery life.
  • USB works as a device or a host, which lets the board act as a keyboard or read a memory stick.

Chip values are for the TM4C123GH6PM in the 64-pin LQFP from the TI product page. Other TM4C123 parts have 32 to 256 KB flash and 12 to 32 KB RAM. GPIO is up to 43 depending on configuration. The LaunchPad exposes most pins on BoosterPack headers. Board values are for the EK-TM4C123GXL LaunchPad with an onboard ICDI debugger, RGB LED, two user switches and a reset switch. low_power_ua is the standby figure quoted by CNX Software at launch. Board dimensions were not confirmed from a fetched page.

Things you could build

11 ideas sized to what this board can do. Starter ideas suit first-time builders.

Starter ideas

  • Blink the RGB light

    Turn the onboard light red, green, and blue in turn. It is the classic first program for this board.

  • Button reaction timer

    Light the LED after a random pause and time a button press. Print the result to a computer screen.

Builder ideas

  • Small robot motor driver

    Use the motion control outputs to drive two small motors. Build a simple wheeled robot for class.

    Add: motor driver board, two small DC motors, robot chassis, battery pack.

  • USB keyboard gadget

    Program the board to act as a USB keyboard. Each button types a shortcut on your computer.

    Add: push buttons.

  • Classroom light meter

    Read a light sensor with the analog inputs. Log readings to a computer for a science lab.

    Add: light sensor.

  • Servo pan and tilt stand

    Drive two servo motors from the PWM pins. Aim a small flashlight or sign with button presses.

    Add: two servo motors, pan and tilt bracket.

Expert ideas

  • Wheel speed reader

    Connect a wheel encoder to the quadrature inputs. Measure how fast and how far a motor turns.

    Add: motor with encoder, motor driver board.

  • Car style CAN network

    Link two boards over CAN bus like parts inside a car. Each board shares sensor readings with the other.

    Add: two CAN transceiver boards, second board, jumper wires.

  • USB memory stick reader

    Use USB host mode to read a file from a memory stick. Show its contents over the serial link.

    Uses: Plugs in USB gadgets. Add: USB OTG adapter, USB memory stick.

  • Battery saving weather logger

    Wake from hibernation every few minutes to read a temperature sensor. Store readings in the built-in EEPROM.

    Uses: Sips power. Add: temperature sensor, battery pack.

  • Simple oscilloscope view

    Sample a signal with the fast analog inputs. Send the numbers to a computer and draw them as a wave.

    Add: jumper wires.

How open is it?

Open Board

TI publishes the LaunchPad design files in EAGLE format, but no open license is stated. Code builds with open tools such as GCC, OpenOCD, and Zephyr under the Apache-2.0 license. Code Composer Studio is a free download from TI. The chip design stays closed.

Hardware license: No open license stated for TI LaunchPad files (TI evaluation terms), GPL-3.0 (Roadrunner community board) · Software license: TI TivaWare license (BSD-style driverlib, unverified), Apache-2.0 (Zephyr)
